## 摘要
个性化演示生成需要的不仅是对当前提示或模板的条件约束：智能体必须跨任务保留稳定的用户偏好，在多轮修订中保留新引入的偏好和约束，并可靠地执行局部编辑。我们提出MemSlides，一种用于个性化演示智能体的分层记忆框架，它将长期记忆与工作记忆分离，并进一步将长期记忆分为用户画像记忆和工具记忆。用户画像记忆存储面向意图的画像，用于第0轮个性化；工作记忆在修订轮次中携带活跃偏好和会话约束；工具记忆存储可重复使用的执行经验，以实现可靠的局部编辑。MemSlides将此记忆设计与有范围的幻灯片局部修订相结合，从而有针对性地更新最小受影响区域，而非重复重新生成整个演示文稿。在控制实验中，用户画像记忆改进了多画像、多意图画像库上的角色一致性判断；工具记忆注入在诊断性匹配对设置中改善了闭环修改行为；定性案例展示了工作记忆传递偏好的能力。综合来看，这些结果表明，在演示文稿创作中实现有效的个性化取决于在生成和局部修订过程中分离持久的用户画像、会话级工作记忆和可重复使用的执行经验。

## Abstract
Personalized presentation generation requires more than conditioning on a current prompt or template: agents must preserve stable user preferences across tasks, retain newly introduced preferences and constraints during multi-turn revision, and carry out local edits reliably. We propose MemSlides, a hierarchical memory framework for personalized presentation agents that separates long-term memory from working memory and further divides long-term memory into user profile memory and tool memory. User profile memory stores intent-conditioned profiles for round-0 personalization, working memory carries active preferences and session constraints across revision rounds, and tool memory stores reusable execution experience for reliable localized editing. MemSlides pairs this memory design with scoped slide-local revision, so targeted updates act on the smallest affected region instead of repeatedly regenerating the full deck. In controlled experiments, user profile memory improves persona-alignment judgments on a multi-persona, multi-intent profile bank, tool-memory injection improves closed-loop modify behavior in diagnostic matched-pair settings, and qualitative cases illustrate working memory's ability to carryover preferences. Taken together, these results suggest that effective personalization in presentation authoring depends on separating persistent user profiles, session-level working memory, and reusable execution experience across generation and localized revision.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：现有演示文稿生成代理（如DeepPresenter、SlideTailor）虽然能生成结构完整、视觉精美的幻灯片，但在**个性化**方面存在严重不足。具体表现为：

  - 局部编辑（如修改某张幻灯片中的具体文字或样式）往往导致全盘重生成，破坏已对齐的内容。
- **研究动机**：现代演示创作需要频繁的交互式修订，用户偏好通常在修订过程中逐渐暴露，而非一次性指定。因此，需要一个能够**区分不同生命周期**的记忆机制，分别处理持久偏好、会话约束和可复用执行经验。
- **整体含义**：有效的个性化演示生成依赖于**分离持久的用户画像、会话级工作记忆和可重用执行经验**。MemSlides通过分层记忆框架实现了这一目标。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 核心思想
- **分层记忆框架**：将记忆分为**长期记忆**和**工作记忆**。长期记忆进一步分为**用户画像记忆**（存储跨任务的稳定偏好，按意图和维度组织）和**工具记忆**（存储可复用执行经验，包括回合范围任务经验和操作范围工具链经验）。工作记忆携带当前会话的活跃偏好、临时约束和编辑状态。
- **局部化修订策略**：采用**Plan-Act-Guard**流程，将修订范围限制在最小受影响区域（单张幻灯片或一组幻灯片），避免全盘重生成。每次修订通过执行合同（scope decision）明确目标区域，然后应用最小有效编辑（如批处理CSS更新、语义批处理样式、快照绑定补丁），最后通过守卫机制（如覆盖检查）确保修改完整且不扩散。

### 2.2 关键技术细节
- **用户画像记忆的生命周期**：
  - 在第0轮（初始生成）前，根据用户消息中的意图选择对应的画像桶，提取约束，将兼容的偏好注入工作记忆。
  - 修订过程中，工作记忆随反馈更新（新增偏好、冲突覆盖、保兼容）。
  - 任务结束时，通过**意图感知的整合**（非直接提升）更新长期画像，避免临时请求固化为持久偏好。
- **工具记忆的组织**：
  - **回合范围任务经验**：在任务开始时可用，在修改回合中缓冲，每轮根据代理教训、工具错误和自动提取模式更新。
  - **操作范围工具链经验**：将原始的推理-工具调用-观察链分割为可复用片段，按操作上下文索引，在类似工具调用前检索并注入。
- **局部修订的Plan-Act-Guard**：
  - **Plan**：将修订请求转化为显式执行合同，记录推断的范围、目标幻灯片路径、活动规则ID、选择器提示和覆盖要求。局部请求绑定到单张幻灯片；全局规则扩展至所有幻灯片；混合请求保留全局规则和局部例外。
  - **Act**：根据合同选择编辑工具。共享选择器的幻灯片优先使用批处理CSS更新；语义相同的元素跨不同结构使用语义批处理样式；单一现有幻灯片使用布局优先的修复表面和非空补丁操作；页面插入/删除保持为显式页面级操作。
  - **Guard**：补丁调用绑定到快照内容哈希；过期快照触发重新绑定提示而非立即重写；当要求覆盖时，直到所有目标幻灯片被修改或明确确认为止，阻止提前结束。

- **问题导向的方法设计**：从多轮修订中个性化暴露的实际痛点出发，设计了显式记忆生命周期和局部修订执行协议，而非对提示工程进行修补。
- **清晰的记忆分离**：区分长期记忆（用户画像、工具经验）和工作记忆（会话状态），避免信息混淆和不确定性失效。画像记忆按意图和维度组织，支持细粒度路由和冲突解决。
- **创新的局部修订策略**：Plan-Act-Guard流程将局部编辑约束为合同执行，减少全盘重生成导致的非必要改变和上下文压力。通过快照绑定、覆盖检查等守卫机制保证可靠性。
- **严谨的实验设计**：
  - 盲评分离了记忆条件与评判者信息。
  - 匹配对控制变量实现了对工具记忆的因果推断。
  - 多模型、多人物的覆盖提高了结果的鲁棒性。
- **良好的可解释性**：提供了定性例证（图5、6、8、9）直观展示内存效果，以及详细的附录表格支持可重复性。

## 8. 不足与局限

- **实验覆盖范围有限**：
  - 所有实验在**受控设置**下进行，使用人工构建的人物库和代理编辑请求，而非真实用户部署。真实场景中的用户行为、偏好模糊性和冲突可能更复杂。
  - 人物库仅10种职业，每个职业仅3个意图，且偏好字段经过种子填充（seeded completion），可能不够自然。
- **未涉及隐私与伦理**：
  - 论文承认存储的用户画像可能编码敏感习惯或组织约束，且错误记忆整合可能保留过时偏好。但本研究未提供用户可见的记忆检查、编辑、删除控制，也未研究隐私过滤机制。
- **模型依赖性高**：
  - 结果依赖于特定LLM版本（GPT-5、GLM-5、Gemini 3.1 Pro）。不同版本或开源模型可能表现不同。且使用相同模型作为评判者可能引入偏好。
- **工具记忆评估的配对限制**：
  - 仅使用9个配对，且部分配对（如Gemini第一个配对）出现闭环完成率下降，且无编辑时间不可用。符号检验显示并非所有指标显著。
- **工作记忆证据为定性**：工作记忆偏好传递仅通过两个定性案例展示，缺乏定量指标（如准确率、覆盖率）。
- **计算资源未详尽报告**：虽然记录了API调用和本地工具时间，但未提供标准化GPU计算量或成本，难以复现精确环境。
- **缺乏真实用户研究**：没有实际用户参与评估生成幻灯片是否真正满足偏好，也未研究长期使用后画像的收敛性。
