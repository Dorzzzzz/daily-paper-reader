## 摘要
强化学习提升了大型语言模型的推理能力，但将仅结果奖励应用于视频多模态大语言模型，对于哪些视觉证据应支持答案的指导有限。受多感官整合（其中一致线索可增强感知估计的显著性和可靠性）启发，我们提出了共识帧GRPO，一种无需时间标注、面向证据感知视频推理的过程级奖励框架。CF-GRPO从内在视频线索（包括时间覆盖、场景转换线索和查询条件化的视觉相关性）构建共识帧先验。然后，它从视觉和响应表示中计算模型侧帧使用分数，并通过共识帧奖励优化它们的一致性。通过显著性感知的稀疏聚合和分布锐化，CFR无需人工时间标注即可提供高对比度的奖励信号。实验表明，VideoCFR在复杂视频推理基准测试中取得了竞争性性能，并在多个指标上优于代表性的视频多模态大语言模型和强化学习基线，同时共识先验提供了训练期间强调的证据帧的可解释视图。实现代码见https://github.com/1Pansy/VideoCFR。

## Abstract
Reinforcement learning has improved the reasoning ability of large language models, but applying outcome-only rewards to video multimodal large language models (Video-MLLMs) provides limited guidance on which visual evidence should support the answer. Inspired by multisensory integration, where consistent cues can enhance the salience and reliability of perceptual estimates, we introduce Consensus Frame GRPO (CF-GRPO), a temporal-annotation-free process-level reward framework for evidence-aware video reasoning. CF-GRPO constructs a consensus frame prior from intrinsic video cues, including temporal coverage, scene-transition cues, and query-conditioned visual relevance. It then computes a model-side frame-use score from visual and response representations and optimizes their agreement through the Consensus Frame Reward (CFR). With salience-aware sparse aggregation and distribution sharpening, CFR provides a high-contrast reward signal without requiring human temporal annotations. Experiments show that VideoCFR achieves competitive performance across complex video reasoning benchmarks and improves several metrics over representative Video-MLLM and RL baselines, while the consensus prior provides an interpretable view of the evidence frames emphasized during training. The implementation is available at https://github.com/1Pansy/VideoCFR.

## 2. 方法论

### 2.1 核心思想
提出 **Consensus Frame GRPO (CF-GRPO)**，一种无需时序标注的过程级强化学习框架。它在GRPO基础上补充了**共识帧奖励（CFR）**，通过鼓励模型侧帧使用分布与从视频内在线索构建的共识先验（consensus prior）对齐，提供帧级别的证据反馈。

### 2.2 关键技术细节

#### （1）共识先验的构建（Consensus Prior Construction）
结合三种互补的线索，为采样的K帧分配权重：
- **均匀时间覆盖（Uniform Coverage）**：保证全局时序覆盖，作为基线。
- **场景转换（Scene Transitions）**：计算相邻采样帧HSV直方图的Bhattacharyya距离，识别视觉突变（场景边界）。
- **查询条件化的视觉相关性（Query-conditioned Visual Relevance）**：使用预训练的视觉-语言编码器，评估每帧与用户查询的图文相似度，选取最相关的帧。

框架融合权重公式：
``` 
w_i = w_base + I(i∈S_scene)·λ_scene + I(i∈S_sem)·λ_sem
```
归一化得到共识先验分布 P(i)。

#### （2）模型侧帧使用分数（Model-side Frame-use Score）提取与锐化
- 将每帧的视觉patch tokens通过**显著性感知稀疏聚合（Salience-aware Sparse Aggregation）**（channel-wise max pooling）得到帧级向量。
- 计算帧向量与生成响应隐藏状态的余弦相似度，平均所有响应token得到原始分数S_i。
- 使用**温度锐化（Temperature Sharpening）**的softmax得到平滑的帧使用分布w_attn(i)：
```
w_attn(i) = exp(S_i/τ) / Σ_j exp(S_j/τ)
```

#### （3）共识帧奖励（CFR）
CFR定义为共识先验与模型侧帧使用分布的点积：
```
R_cf = Σ_i P(i) · w_attn(i)
```
该标量奖励两者重叠程度，高重叠意味着更好证据对齐。

#### （4）总奖励与优化
复合奖励函数：
```
R_total(o) = R_acc + R_struct + λ·R_cf + R_temp
```
- R_acc：答案准确性
- R_struct：格式与长度惩罚（鼓励简洁）
- R_temp：时序一致性奖励（有序输入优于打乱输入则奖励）

## 6. 主要结论与发现

1. **VideoCFR在多个视频推理和通用理解基准上取得竞争性结果**，尤其在推理导向基准（如VideoMMMU、MMVU(MC)）上超越多数基线。
2. **CFR奖励组件贡献显著**：替换为均匀先验、去除语义或场景先验均导致性能下降，表明多源共识先验的有效性。
3. **稀疏聚合和温度锐化有助于提升奖励区分度**：稀疏聚合保留局部高响应信号；锐化使帧使用分布更尖锐，增强过程信号。
4. **训练中共识对齐得分上升**（从0.47升至0.62），且与准确率稳定同步，表明证据对齐被优化。
5. **模型注意力集中到共识帧上**：共识帧仅占14.1%的帧槽，却获得19.5%的top注意力事件，富集比1.48×，而非共识帧仅0.94×。
6. **帧预算增加的效果因任务而异**：有些基准受益于更多帧（VideoMME、VSI-Bench），有些则在较少帧时峰值（VideoMMMU、MVBench），需任务自适应。

## 7. 优点

- **无需人类时序标注**：通过多源内在线索构建共识先验，节省标注成本。
- **过程级奖励设计新颖**：将证据对齐问题转化为分布匹配，补充了结果奖励。
- **稀疏聚合与锐化机制**：有效突出关键视觉信息，增强奖励信号对比度。
- **可解释性强**：共识先验和注意力富集分析提供了模型关注证据的直观视图。
- **架构无关性**：不改变Video-MLLM基础架构，易于集成到现有训练流程。
- **实验分析全面**：从性能、消融、训练动态到注意力机制，多角度验证方法有效性。

## 8. 不足与局限

- **共识先验仍是估计而非真实标注**：当必要证据隐晦、视觉细微或分散在多个帧中时，先验可能不可靠。
- **仅覆盖视觉与文本查询模态**：忽略音频、字幕、语音等模态，限制了在跨模态视频理解上的应用。
- **训练额外开销**：计算共识先验、模型侧分数、分组GRPO等带来额外计算成本（48小时8卡A800）。
- **帧预算非普适最优**：增加帧数不总是提升性能，需任务定制，缺乏自适应策略。
- **诊断分析无法替代人工证据标注评估**：注意力富集等内部统计不能完全代表真实证据对齐质量。
- **未探索更长上下文或更大模型**：仅基于7B规模模型与16帧默认设置，泛化性验证不足。
