## 摘要
我们提出了\textbf{回声记忆}，一种对动作条件世界模型中记忆机制的受控研究。这些模型从首帧、文本提示和相机动作序列生成多段视频，但它们的核心失败通常是记忆而非局部图像合成：当相机离开并返回后，场景或显著对象可能悄然改变。现有的记忆设计难以比较，因为增益与骨干网络、训练、检索和评估差异纠缠在一起。回声记忆固定了动作到视频的接口，仅改变生成器存储和读取历史的方式。在共享视频扩散骨干、优化器、相机动作表示、采样器和评估流程下，我们比较了原始上下文、基于压缩的记忆、具有不同读出路径的空间摘要以及状态空间递归。这个匹配矩阵分离了四个通常混淆的轴：\emph{容量}、\emph{压缩}、\emph{读出}和\emph{递归}。我们还通过三分支协议评估记忆：重播质量、域内循环重访和开放域返回探测。这些分支通常结论不一致，表明重播保真度不足以作为记忆世界的代理。由此得出三个发现。原始上下文是强大的容量基线，并且比改善重播指标更能改善开放域返回。紧凑性并非容量的免费替代：激进的空間和混合压缩记忆失去了返回所需的显著证据。最后，块状状态空间递归是我们矩阵中最强的开放域返回机制，表明隐式记忆的结构与使用它的决策同样重要。这些结果为研究超越孤立重播指标的动作世界模型中的记忆提供了一个简洁的协议。

## Abstract
We present \textbf{Echo-Memory}, a controlled study of memory mechanisms in action-conditioned world models. These models generate multi-segment videos from a first frame, text prompt, and camera-action sequence, but their central failure is often memory rather than local image synthesis: after the camera leaves and returns, the scene or salient object may silently change. Existing memory designs are hard to compare because gains are entangled with backbone, training, retrieval, and evaluation differences. Echo-Memory fixes the action-to-video interface and varies only how history is stored and read by the generator. Under a shared video diffusion backbone, optimizer, camera-action representation, sampler, and evaluation pipeline, we compare raw context, compression-based memory, spatial summaries with different read-out paths, and state-space recurrence. This matched matrix separates four otherwise conflated axes: \emph{capacity}, \emph{compression}, \emph{read-out}, and \emph{recurrence}. We also evaluate memory through a three-branch protocol: replay quality, in-domain loop revisit, and open-domain return probes. The branches routinely disagree, showing that replay fidelity is not a sufficient proxy for remembering a world. Three findings follow. Raw context is a strong capacity baseline and improves open-domain return far more than it improves replay metrics. Compactness is not a free substitute for capacity: aggressive spatial and hybrid-compression memories lose the salient evidence needed for return. Finally, block-wise state-space recurrence is the strongest open-domain return mechanism in our matrix, showing that the structure of implicit memory matters as much as the decision to use it. These results provide a compact protocol for studying memory in action world models beyond isolated replay metrics.

## 1. 论文的核心问题与整体含义（研究动机和背景）

动作世界模型（Action World Model）接收首帧、文本提示和相机动作序列，生成多段连续视频。其核心失效模式往往不是局部图像合成，而是**记忆失效**：当相机离开场景再返回时，场景或显著对象可能悄然改变，系统未能“记住”之前的世界状态。现有记忆设计方案（如基于上下文的检索、压缩、空间摘要、状态空间递归等）在文献中均有报告，但难以公平比较，因为性能增益常与骨干网络、训练配方、检索策略和评估协议等无关因素纠缠在一起。因此，论文旨在通过**严格控制所有其他变量、仅改变记忆表示**的方式，隔离并揭示不同记忆机制对动作世界模型“重访一致性”的真实影响。

## 2. 论文提出的方法论：核心思想、关键技术细节

**核心思想**：将记忆设计视为一个**统一接口**问题——固定视频扩散骨干、数据接口、相机动作编码、采样器和评估流水线，仅变化历史信息的存储和读取方式。通过构建一个受控的“记忆矩阵”，分离出四个通常混淆的设计轴：**容量（capacity）、压缩（compression）、读出（read-out）和递归（recurrence）**。

**关键技术细节**：
- **骨干网络**：采用预训练的**视频 Diffusion Transformer (DiT)**，每帧使用单独的 VAE 潜码表示。
- **动作表示**：12维相对相机RT（9维旋转 + 3维平移），以当前段首帧为参考帧。
- **统一记忆接口**：每个变体由一个内存配置文件指定（存储类型、上下文长度K、压缩规则、读出路径、递归结构等）；训练循环、采样器和评估流水线对每个变体暴露相同的接口。
- **记忆家族**：
  - **上下文记忆（Context）**：直接追加历史帧（原始上下文，K=1/5/20）。
  - **压缩记忆（Compression）**：通过 token 加权或时间长度缩减来压缩历史（weight-only, length r=2/4, hybrid）。
  - **空间记忆（Spatial Memory）**：将全帧堆栈替换为紧凑空间摘要（网格状场景表示），通过不同读出路径（无注入、文本KV拼接、专用交叉注意力）实验。

- **训练目标**：单阶段 rectified flow 回归损失，仅监督目标帧，条件包含文本、记忆上下文和动作。

## 6. 论文的主要结论与发现

1. **原始上下文是强容量基线**：增加 K 值（1→5→20）显著提升开放域返回（VLM: 12.25→50.75→58.63），而对重放指标提升较小。原始历史主要帮助语义返回而非局部像素保真度。
2. **紧凑性不能替代语义记忆**：空间记忆在重放 PSNR 上最优，但开放域 VLM 极低（6.00）；混合压缩也丢失身份证据。紧凑表示需对象级保留和明确读出路径。
3. **读出与存储同等重要**：空间记忆的“无注入”行在重放上甚至优于有读出行，说明重放改进可能来自正则化而非有用记忆；专用交叉注意力读出提高开放域得分但远未闭合差距。
4. **结构化递归是最强的开放域偏置**：块状状态空间递归（block-wise SS）在开放域 VLM 达到 69.00，超过原始上下文 K=20（58.63），尽管其重放 PSNR 较低（9.59 vs. 12.54）。递归结构比是否使用递归本身更重要。
5. **重放质量不是记忆质量的代理**：多个行在重放和返回上排名不一致，表明两个能力是分离的。论文强调应使用三分支评估，而非单一标量。

## 8. 不足与局限

- **数据集单一**：仅使用一个数据集（Context-as-Memory），相机统计、场景类型、噪声水平等可能有偏，结论在更嘈杂或不同分布下的泛化性未知。

- **VLM 判断偏差**：开放域评估依赖单一 VLM，虽经交叉验证但仍有系统性偏差（如对特定物体、颜色、视角的偏好）；人类标注样本量有限。

- **规模限制**：8 GPU × 5k 步的规模在当下属于中等偏低，更强骨干（如更大 DiT）或更长训练可能改变结论。
