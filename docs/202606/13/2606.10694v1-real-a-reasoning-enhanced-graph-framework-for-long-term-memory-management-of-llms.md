## 摘要
大型语言模型（LLM）越来越多地需要与用户进行长时间跨度的交互。然而，由于有限的上下文窗口，LLM无法保留所有历史交互，因此长期记忆管理对于在上下文限制之外存储、更新和检索历史信息至关重要。尽管最近的记忆系统尝试通过外部存储历史信息来解决这一问题，但现有方法存在三个关键局限性：基于平面的文本记忆组织无法捕捉记忆之间的显式关系；结构化记忆系统通常会破坏性地覆盖演变中的事实；以及当前检索机制在证据不完整时仍保持查询无关且被动。REAL将长期对话记忆构建为一种时间感知和置信度感知的有向属性图，其中每个原子事实以实体、关系、有效时间区间、置信度分数和探索意图标签表示。在记忆构建过程中，REAL采用非破坏性的时间更新策略，保留并行的事实版本及其有效区间，从而实现对事实演变的忠实追踪。在检索过程中，REAL锚定与查询相关的根实体，解耦其探索意图，并执行由语义评估器引导的混合波束搜索，以提取紧凑的记忆子图。它还进一步融入反事实推理，通过隐式逻辑关系修复不可靠的检索状态并恢复缺失的记忆证据。综合实验表明，REAL在长期记忆性能上显著优于基于平面文本、基于图以及现有记忆基线的方法，平均提升22.72%。

## Abstract
Large Language Models (LLMs) are increasingly expected to interact with users over long time horizons. However, due to their finite context window, LLMs cannot retain all past interactions, making long-term memory management essential for storing, updating, and retrieving historical information beyond the context limit. Although recent memory systems attempt to address this issue by storing historical information externally, existing approaches suffer from three key limitations: flat text-based memory organizations fail to capture explicit relations among memories, structured memory systems often destructively overwrite evolving facts, and current retrieval mechanisms remain query-agnostic and passive when evidence is incomplete. REAL constructs long-term conversational memory as a temporal and confidence-aware directed property graph, where each atomic fact is represented with entities, relations, valid-time intervals, confidence scores, and exploration intent labels. During memory construction, REAL adopts a non-destructive temporal update strategy that preserves parallel fact versions and their validity intervals, enabling faithful tracking of fact evolution. During retrieval, REAL anchors query-relevant root entities, decouples their exploration intents, and performs semantic evaluator-guided hybrid beam search to extract compact memory subgraphs. It further incorporates counterfactual inference to repair unreliable retrieval states and recover missing memory evidence through implicit logical relations. Comprehensive experiments demonstrate that REAL substantially improves long-term memory performance over flat-text, graph-based, and existing memory baselines, achieving an average improvement of 22.72\%.

    2.  **C2：破坏性更新**：当事实发生变化时（如用户偏好改变），系统会直接覆盖旧事实，抹去了事实的演化轨迹，丢失了宝贵的历史信息。
    3.  **C3：被动且查询无关的检索**：检索策略通常是固定的（如简单的向量相似度搜索），既不根据查询意图动态调整，也无法在证据不足时进行主动推理以恢复缺失信息。

### **论文提出的方法论：核心思想与关键技术**

*   **核心思想**：REAL框架包含两个核心阶段：**记忆构建（Memory Construction）** 和 **记忆检索（Memory Retrieval）**。

*   **关键技术细节（构成一个端到端流程）**：

    1.  **记忆构建：构建时序感知与置信度感知的有向属性图**
        *   **原子事实提取**：将每个对话轮的文本内容，通过LLM提取为原子事实，每个事实为一个六元组: `(头实体, 关系, 尾实体, [开始时间, 结束时间], 置信度, 探索意图)`。
        *   **非破坏性时序更新**：
            *   **单值关系**（如“当前居住城市”）：当有新事实与旧事实冲突时（例如城市改变），不覆盖旧事实，而是将旧事实的`结束时间`设为新事实的`开始时间`，从而**保留并行版本**，完整记录事实的演化史。
            *   **多值关系**（如“喜欢吃的食物”）：直接添加新事实作为平行边。
        *   **置信度分层**：每条事实都有置信度分数 (c)。在检索时，只有置信度高于阈值 (θstable) 的事实才被视为核心证据，减少噪音干扰。
        *   **探索意图标签**：为每条事实赋予一个意图标签（如：因果CAUSAL、时序TEMPORAL、演化EVOLUTION），用于指导后续的检索方向。

    2.  **记忆检索：推理增强的自适应检索策略**
        *   **根实体锚定与意图解耦**：首先从用户查询中提取出根实体，并为每个实体推断其探索意图（与记忆构建中的意图标签对应）。
        *   **语义评估器引导的混合束搜索（Hybrid Beam Search）**：针对每个根实体，维护`k`个记忆路径（波束），进行多步迭代搜索。
            *   **候选节点扩展**：每步扩展时，通过**时序过滤**、**置信度阈值**和**探索意图兼容性**三个级联过滤器，从众多邻居节点中筛选出高质量候选。
            *   **路径评分**：使用语义评估器（实际是调用一个LLM）对每条候选路径进行评分，评分标准包括：
                *   **查询相关性 (SQR)**：路径内容与查询的语义相关度。
                *   **逻辑连贯性 (SLC)**：路径中实体和关系序列的合理性和一致性。
                *   **实体特定答案充分性 (SAS)**：当前路径是否已包含足够信息来回答查询中涉及该根实体的那部分问题。
            *   **停止/扩展/反事实推理决策**：通过比较当前路径与扩展后路径的评分，决定是**停止**（当前路径已足够支持回答）、**扩展**（向更优路径前进）还是启动**反事实推理**。
            *   **反事实推理（Counterfactual Inference）**：当正常扩展进入“死胡同”（无有效邻居、相关度过低或逻辑混乱）时，启动此模块。它基于预设的规则（如对称性、上下位关系、时序后继等，见表I）生成替代的探索假设，以从隐式逻辑关系中恢复缺失证据。
        *   **全局波束剪枝**：在每个扩展步骤后，从候选池中只保留评分最高的`k`个路径。

    3.  **答案生成**：将检索到的最终记忆子图进行序列化（包含路径、时间戳、置信度等信息），并作为上下文与用户查询一起输入LLM生成最终答案。
