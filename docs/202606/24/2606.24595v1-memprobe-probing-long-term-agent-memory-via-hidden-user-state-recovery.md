## 摘要
长期记忆有望使LLM智能体在跨会话中变得更加强大，保持对用户准确且不断发展的理解。然而在实践中，这种记忆主要通过下游行为来评估，例如后续回答、个性化质量或任务成功，这仅间接测试了理解能力，而记忆制品本身几乎未受审计。我们认为长期记忆应被评估为可审计的交互后制品：在常规辅助之后，能从智能体留下的记忆中重建出什么样的结构化用户状态？我们通过MEMPROBE实现了这一观点，该基准测试中，配备记忆的智能体辅助模拟用户，每个用户携带一个隐藏的、基于分类的用户状态库，经过一系列泄露控制的任务轨迹，之后在完全存储和top-k访问两种条件下从智能体产生的记忆中重建该状态库。MEMPROBE基于合成真实标签以实现高效可扩展的测量，涵盖50个模拟用户，每个用户有31个隐藏维度（共1,550个恢复目标），并测试了5种代表性记忆系统。对最先进的记忆智能体进行测试，我们发现成功的辅助和可恢复的记忆表现为不同的能力。任务完成率几乎饱和，即使对于无记忆基线也是如此，而类别平衡恢复率保持中等（约0.6），在top-k检索下进一步下降。MEMPROBE是首个直接研究记忆恢复的基准测试，它重建系统保留的用户状态并对照真实标签进行评分。我们将恢复视为未来记忆智能体优化的具体目标，而MEMPROBE则是迈向训练智能体记住用户、随着相处时间增长而更加忠实的环境的一步。

## Abstract
Long-term memory promises LLM agents that grow more capable across sessions, maintaining an accurate, evolving understanding of the user that interaction forms. In practice, however, this memory is evaluated mostly through downstream behavior, such as later answers, personalization quality, or task success, which tests that understanding only indirectly and leaves the memory artifact itself largely unaudited. We argue that long-term memory should instead be evaluated as an auditable post-interaction artifact: after ordinary assistance, what structured user state can be reconstructed from the memory the agent leaves behind? We instantiate this view in MEMPROBE, a benchmark in which a memory-equipped agent assists simulated users, each carrying a hidden, taxonomy-anchored user-state bank, across a trajectory of leak-controlled tasks, after which that bank is reconstructed from the agent's resulting memory under both full-store and top-k access. Built on synthetic ground truth for efficient, scalable measurement, MEMPROBE spans 50 simulated users with 31 hidden dimensions each (1,550 recovery targets) and tests 5 representative memory systems. Testing state-of-the-art memory agents, we find that successful assistance and recoverable memory behave as distinct capabilities. Task completion nearly saturates, even for a memoryless baseline, while category-balanced recovery stays moderate (about 0.6) and drops further under top-k retrieval. MEMPROBE is the first benchmark to study memory recovery directly, reconstructing the user state a system retains and scoring it against ground truth. We see recovery as a concrete objective for future memory agents to optimize, and MEMPROBE as a step toward an environment where agents are trained to remember their users, growing more faithful the longer they know them.

## 1. 核心问题与整体含义

现有 LLM 智能体长期记忆的评估大多依赖下游行为（如任务完成率、个性化回答质量、后续问答准确率），这种方式两方面的缺陷：(1) 只间接测试记忆是否被使用，不审计记忆制品本身；(2) 任务成功完全可能来自上下文猜测或检索命中，无需实际形成用户模型。作者发现无记忆基线也能几乎饱和完成所有任务，说明任务成功不等于记忆质量。论文提出一种新范式：**将长期记忆视为交互后可审计的制品**，通过恢复隐藏的用户状态来直接衡量记忆的质量。该研究旨在证明“成功的辅助”和“可恢复的记忆”是两个独立能力，并为未来训练更忠实的记忆智能体提供明确目标。

## 2. 方法论

### 核心思想
构建一个包含 **合成用户 + 隐藏状态银行 + 泄漏控制任务** 的基准 MEMPROBE。模拟用户携带 31 个隐藏的用户状态维度（分 5 类：技能、知识、情节、自我模型、辅助偏好），在与记忆智能体交互过程中，通过低泄漏任务自然暴露信息，但不直接说出目标值。交互结束后，从智能体留下的存储全量（`dump_all`）或系统自己的 top-k 检索（`retrieve`）中重建每个隐藏维度，并与真实标签对比评分。

### 关键技术细节
- **用户状态生成**：使用 DeepPersona 生成用户档案，从 O*NET、Conway 自传记忆模型、HEXACO 等固定分类池中选择 31 个维度，每个维度生成简短标签和解释。
- **泄漏控制**：每个维度对应一个日常辅助任务，任务设计确保不直接泄露目标值。盲法反钓鱼审查器确保任务文本本身无法推断目标。
- **交互流程**：用户模拟器与 agent 进行多轮对话（最多 25 轮），agent 可读写自己的记忆。任务完成后评分 agent 的偏好（D）、回合数（C）、任务完成（A）以及记忆恢复分数。
- **恢复评分**：使用 slot-filling reader 基于记忆生成预测，再由 LLM 法官按 5 级量表（0,0.25,0.5,0.75,1.0）对比真实标签。最终采用 **类别平衡恢复分数 B**（先按 5 类分别平均，再平均 5 类均值）。
- **失败归因**：对得分 <0.75 的维度进行三级归因：① 任务能否自然引出该维度（任务设计失败）；② 对话是否已披露足够证据（记忆失败）；③ 若未披露，归因于 agent 引导失败或模拟器太严格。
- **两个访问模式**：`dump_all` 测是否写入，`retrieve` 测是否可检索。

### 算法流程（文字描述）
1. 对每个用户 u，预先生成隐藏状态向量 (u₁,…,u₃₁)。
2. 为每个维度生成一个低泄漏任务，用户与 agent 交互 T=31 轮，期间 agent 向记忆写入片段 mₜ。
3. 交互结束后，对每个维度 i，使用固定查询 qᵢ 检索记忆（`retrieve`）或直接获取全部记忆（`dump_all`），填入标签。
4. 用 LLM 法官对比预测与真实标签，给出评分。
5. 聚合得到类别平衡恢复分数 B，并运行失败归因。

## 3. 实验设计

### 数据集/场景
- **合成用户**：50 名模拟用户，每用户 31 个隐藏维度 → 共计 **1,550 个恢复目标**。
- **任务**：每个用户 31 个日常辅助任务（共 1550 个对话轨迹），内容涵盖家居、财务、健康、社交等。
- **无外部真实用户数据集**，完全在合成环境中进行。

### 对比方法
| 系统 | 描述 |
|------|------|
| **nomem** | 无记忆基线 |
| **longctx_full** | 存储每轮对话原文，使用句嵌入余弦检索 |
| **amem** (A-Mem) | Zettelkasten 风格的笔记链接与演化 |
| **mem0** (Mem0) | 提取和合并会话记忆，检索式 |

## 6. 主要结论与发现

1. **任务成功不等于良好记忆**：所有系统任务完成率 >99.8%，无记忆基线也近饱和；但记忆恢复分数仅 0.61–0.62（`dump_all`），`retrieve` 下降至 0.47–0.54。行为表现无法区分记忆质量。
2. **存储证据不等于可检索**：`longctx_full` 在 `dump_all` 下最好（0.624），但 `retrieve` 下降明显；`amem` 在 `retrieve` 下最优（0.540），系统排名随访问模式变化。
3. **检索感知的整合是关键瓶颈**：系统能保留原始交互痕迹，但未将其凝练为紧凑的用户状态，导致检索时难以召回。
4. **情节记忆最难恢复**：辅助偏好恢复最好（约 0.77），情节记忆最差（约 0.42–0.45 in dump），且 `retrieve` 下降更大。情节记忆需要绑定事件、上下文和后果，当前系统普遍欠缺。
5. **memt 的特化检索在某些维度有局部优势**（如自我模型），但总体 `retrieve` 未显著超越其他系统。
6. **全存储 auditability 问题**：memt 存储过大（p90 约 596 项 × 1288 字符），全量序列化超出上下文窗口，导致 `dump_all` 评分极低（0.130），但 `retrieve` 正常显示实际内容。

## 7. 优点

- **直接审计记忆制品**：首次将“记忆作为可审计交互后制品”操作化，提出恢复分数指标，跳脱下游行为间接评测。
- **结构化隐藏状态**：基于成熟分类学（O*NET、Conway、HEXACO）构建 31 维隐藏状态，覆盖技能、知识、情节、自我、偏好，评估全面。
- **严格的泄漏控制**：盲法反钓鱼审查器确保任务文本不泄露目标，强制 agent 必须通过记忆记录才能恢复。
- **归因机制**：三级归因（任务、披露、引导）精确区分记忆失败与其他因素，避免误判。
- **开源可复现**：发布了完整代码、数据、评估轨迹、评判输出，支持元分析。
- **人类验证**：对模拟器信号和归因标签进行了人工审核，验证了自动判断的可靠性。

## 8. 不足与局限

- **合成用户泛化性**：仅使用基于美国英语的 DeepPersona 配置文件，缺乏跨语言、跨文化、高度隐私保护或快速变化的真实用户行为。
- **任务难度有限**：均为日常简单任务，任务完成近饱和，未能测试更复杂、长程规划场景下的记忆表现。
- **评判依赖 LLM**：所有评分、归因均使用 GPT-5.4-mini，可能存在偏见、方向性标签极性混淆（案例 3 展示），虽有人工抽查但并非金标准。
- **计算成本高**：总 token 消耗巨大（约 6.9 亿），对资源有限团队复现门槛高。memt 本地推理已使用 A100，但 API 调用成本未量化。
- **记忆类别不平衡**：情节记忆数量（7/31）与其他类相同，但恢复难度高，可能导致整体分数偏低；分类平衡处理部分缓解但无法消除类别本质差异。
- **未评估用户偏好型技能**：agent 能否学会针对特定用户的提问风格等技能型记忆未被直接测试。
- **memt 的 full-store auditability** 问题本身是一个局限：当存储过大时，无法直接全量审计，需要更高效的序列化或采样策略。
