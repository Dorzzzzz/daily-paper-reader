## 摘要
多模态大语言模型在短时音视频理解方面取得了显著进展，但长时音视频理解仍然受到有限上下文窗口和严重信息冗余的挑战。为解决这些瓶颈，我们提出AVOC，一个面向全模态大语言模型的长时音视频理解框架。AVOC在模态编码器与大语言模型主干之间引入了一个可学习的令牌压缩模块。我们将多模态令牌压缩重新定义为一个top-K检索问题：给定固定的上下文预算，该模块必须检索一个紧凑的令牌子集，该子集最能支持回答用户查询。我们从三个经典的信息检索准则中汲取灵感，以从大型候选池中选择信息单元：相关性、重要性和多样性。AVOC将每个准则实例化为针对音视频理解的定制机制，并将它们集成到统一的检索式压缩管线中。实验表明，AVOC在长时音视频基准测试上取得了最先进的性能，在OmniVideoBench和LVOmniBench上分别以平均准确率超越第二名模型4.9和5.5个百分点。此外，AVOC在时长长达一小时的音视频“大海捞针”任务中保持了稳健的性能。

## Abstract
Multimodal Large Language Models have achieved remarkable progress in short-form audio-video understanding, yet long-form audio-video comprehension remains challenged by limited context windows and severe information redundancy. To address these bottlenecks, we propose AVOC, a framework for long-form audio-video understanding in Omni-modal Large Language Models. AVOC introduces a learnable token compression module between the modality encoders and the LLM backbone. We reframe multimodal token compression as a top-$K$ retrieval problem: given a fixed context budget, the module must retrieve a compact subset of tokens that best supports answering the user query. We draw inspiration from three classical Information Retrieval criteria for selecting informative units from a large candidate pool: relevance, importance, and diversity. AVOC instantiates each criterion as a tailored mechanism for audio-video understanding, and integrates them into a unified retrieval-style compression pipeline. Experiments show that AVOC achieves state-of-the-art performance on long-form audio-video benchmarks, surpassing the second-best model by 4.9 and 5.5 points in average accuracy on OmniVideoBench and LVOmniBench, respectively. Moreover, AVOC maintains robust performance on Audio-Video Needle-in-a-Haystack task at durations up to one hour.

- **问题**：多模态大语言模型（MLLM）在短时音视频理解上表现优异，但面对小时级长视频时，受限于**有限的上下文窗口**和**严重的信息冗余**。现有内容无关采样（如稀疏采样）会丢失关键短暂事件；而基于主导模态的压缩方法（如OmniZip、OmniSIFT）采用非对称设计，以单模态引导另一模态压缩，当主导模态信号稀疏时容易丢弃重要信息。
- **背景需求**：真实场景（电影、会议、教程）需要模型能够同时理解视觉和音频流并进行长程推理，但当前模型缺乏高效、对称的压缩机制。

### 2. 论文提出的方法论

#### 核心思想
将多模态令牌压缩重新定义为**top-K检索问题**：给定固定的上下文预算K和大量候选令牌，模型必须检索一个紧凑的子集，使其最好地支持回答用户查询。借鉴信息检索中三个经典准则：**相关性**（query-conditioned relevance）、**重要性**（query-agnostic importance）、**多样性**（result diversity）。

#### 关键技术细节
1. **相关性（Relevance）**：文本引导交叉注意力评分。
   - 将文本查询作为搜索查询，多模态令牌作为候选库。
   - 计算文本令牌与多模态令牌之间的点积注意力得分，每个多模态令牌的得分是对所有文本令牌收到的注意力logits取平均。
   - 公式：`score_rel(x_i) = (1/N_text) * Σ_j A_rel_{j,i}`。

2. **重要性（Importance）**：双向视频-音频交叉注意力评分（在时间块内）。
   - 对每个时间块，分别计算视频到音频、音频到视频的交叉注意力。
   - 每个令牌的得分是对另一模态所有令牌的注意力logits取平均。
   - 提供与查询无关的固有信息量估计，补充相关性。

3. **多样性（Diversity）**：时间感知最大边际相关性（TA-MMR）。
   - 避免传统MMR无差别惩罚全局相似令牌导致错误抑制时间上重复但语义不同的远距离事件。
   - 候选令牌的冗余度仅在其局部时间窗口（半径W）内计算，只惩罚时间临近的相似令牌。
   - 公式：`TA-MMR(x_i) = (1-λ)·score(x_i) - λ·max_{x_j' in S_select ∩ Window(τ_i)} sim(x_i, x_j')`。
   - 每个模态独立进行TA-MMR选择，并分配对应的预算（K_video + K_audio = K），最后按时间顺序重排序。

#### 训练与推理
- **训练**：两阶段训练。阶段1：不使用压缩模块，只微调LLM（20k样本）。阶段2：激活压缩模块，联合训练压缩模块和LLM（20k样本）。视觉/音频编码器冻结。压缩模块训练时使用Gumbel-Softmax实现可微top-K选择；TA-MMR仅在推理时启用。
- **推理**：固定全局预算K=10240（主实验），模态比例2:1（视频:音频），λ=0.15，窗口半径W=3。

### 6. 论文的主要结论与发现

- AVOC在三个长时基准上均达到SOTA，超越第二名模型**平均准确率提升4.9~5.5个百分点**，在超长子集(10,30]分钟提升5.2点。

- 消融表明：三个压缩组件缺一不可；TA-MMR的局部窗口设计优于全局MMR；模态预算比2:1最优。
- 压缩模块仅引入微小开销（保留率1.0时增加1.8秒），且高压缩率下可获得近9倍的Prefilling加速。

### 7. 优点

- **新颖视角**：将令牌压缩视为检索问题，直接继承三条经典IR准则，思路清晰且理论支撑强。
- **对称双模态相互作用**：重要性评分通过双向视频-音频注意力实现，不偏向任一模态，避免非对称压缩的信息丢失。
- **时序感知多样性**：TA-MMR保留远距离相似事件，仅抑制局部冗余，更适合长时间视频中反复出现的模式。
- **模块化设计**：压缩模块可作为插件插入任意OLLM，且训练时通过Gumbel-Softmax实现端到端可微。
- **效率高**：高压缩率下显著降低Prefilling时间，实用性强。

### 8. 不足与局限

- **离线处理**：压缩模块需要完整音视频流全部输入后才能进行评分和选择，无法直接应用于流式或在线场景。
- **固定模态预算**：K_video:K_audio是手动设定的超参数，缺乏内容自适应性，可能在某些分布不均的数据上不最优。
- **小规模验证**：实验仅在7-8B骨干模型上进行，未验证在更大规模骨干（如13B、70B）上的表现。
- **训练算力未公开**：未报告训练所需的GPU数量和时长，影响可复现性评估。
- **无跨架构泛化实验**：仅以MiniCPM-o 4.5为骨干，未在其他OLLM（如Qwen2.5-Omni）上测试压缩模块的可迁移性。
- **AV-NIAH针来源单一**：仅使用一个长视频作干草堆，可能引入特定视频风格偏差。
