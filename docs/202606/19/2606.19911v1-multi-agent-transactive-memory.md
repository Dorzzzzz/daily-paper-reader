## 摘要
跨不同任务部署具有多样化能力的LLM智能体的去中心化，促使了跨异构智能体群体的知识共享基础设施。正如搜索引擎索引人类生成的人工制品以支持人类解决问题一样，检索系统可以组织智能体生成的人工制品，以便在智能体群体中重复使用。我们将检索增强生成（证明了人类作者制作的人工制品对单个智能体的价值）扩展到检索支持智能体群体的智能体生成人工制品。特别是，智能体轨迹编码了可重复使用的程序性知识，但这些人工制品通常在一次使用后被丢弃，或仅由生成智能体保留，迫使新实例化的智能体反复重新发现现有解决方案。我们提出了多智能体交互记忆（MATM），这是一种用于群体层面存储和检索智能体生成轨迹的框架，其中生产智能体将轨迹贡献给共享存储库，消费智能体检索它们以改进任务执行。我们关注交互式环境（ALFWorld和WebArena），其中的轨迹较长且编码了特别丰富的程序性结构。我们的实验表明，从MATM检索轨迹可以改善下游任务性能，并减少交互步骤，而无需协调或联合训练。这些结果将MATM定位为开放智能体生态系统中群体层面经验共享的设计模式。

## Abstract
The decentralized deployment of LLM agents with diverse capabilities across diverse tasks motivates infrastructure for knowledge sharing across heterogeneous agent populations. Just as search engines index human-generated artifacts to support human problem solving, retrieval systems can organize agent-generated artifacts for reuse across agent populations. We extend retrieval-augmented generation - which demonstrates the value of human-authored artifacts to individual agents - to retrieval of agent-generated artifacts supporting a population of agents. In particular, agent trajectories encode reusable procedural knowledge, yet these artifacts are typically discarded after a single use or retained only by the producing agent, forcing newly instantiated agents to repeatedly rediscover existing solutions. We propose Multi-Agent Transactive Memory (MATM), a framework for population-level storage and retrieval of agent-generated trajectories, where producer agents contribute trajectories to a shared repository and consumer agents retrieve them to improve task execution. We focus on interactive environments (ALFWorld and WebArena), where trajectories are long and encode especially rich procedural structure. Our experiments demonstrate that retrieving trajectories from MATM improves downstream task performance and reduces interaction steps without coordination or joint training. These results position MATM as a design pattern for population-level experience sharing in open agent ecosystems.

# 论文总结：Multi-Agent Transactive Memory

## 1. 核心问题与整体含义

- **研究动机**：在大规模去中心化部署下，异构的 LLM 智能体在执行任务时会产生大量中间产物（如动作-观测轨迹），这些轨迹编码了可复用的程序性知识。然而，现有系统通常将轨迹在一次使用后丢弃，或仅由生成它的智能体保留，导致新实例化的智能体反复重新发现已有解决方案，造成计算资源和时间的浪费。
- **整体含义**：论文提出 **Multi-Agent Transactive Memory (MATM)**，构建一个群体级别的共享经验存储与检索机制，使智能体能够跨个体复用轨迹，无需协调或联合训练。这为开放智能体生态系统中的持续学习和效率提升提供了新的设计模式。

## 2. 方法论

- **核心思想**：借鉴人类群体中的“交互记忆”概念，将智能体分为 **生产者**（贡献轨迹）和 **消费者**（检索轨迹），共享一个不断增长的索引仓库。角色可重叠。
- **关键技术细节**：
  - **状态条件键-值索引**：以最近的交互历史（窗口长度 \(l=5\) 步）作为键，后续的 \(l\) 步动作-观测对作为值。采用 E5-Base 嵌入模型 \(f\) 对键进行编码。
  - **检索流程**：消费者智能体配备一个 **RetrievalPlanner** 决定是否调用检索。检索分为两阶段：
    - 第一阶段：密集检索（top-20候选）。
    - 第二阶段：可选的 **学习排序 (Learning-to-Rank, LTR)** 重排器，从候选中选择 top-1 轨迹块。
  - **LTR 重排器 (LTRT)**：使用 **边际效用** 作为标签（检索后任务得分减去无检索基线得分）。训练数据通过增量式构建过程收集：对每个训练问题，在基线轨迹中随机选取分支点，检索 top-K 候选并执行单步 rollout 得到得分差。
  - **特征设计**：共 44 维特征，涵盖六个类别：
    1. 生产者元数据（如基准得分）
    2. 消费者元数据（如 agent ID）
    3. 第一阶段检索得分
    4. 查询特征（长度、当前步数）
    5. 轨迹特征（块长度、步数、成功标志）
    6. 查询-轨迹交互特征（TF-IDF 相似度、嵌入相似度、重叠率等）
  - **重排器家族**：包括点式 (FFN)、成对式 (LambdaMART、SVMRank)。

## 3. 实验设计

- **数据集与场景**：
  - **ALFWorld**：基于文本的家庭任务环境。使用官方 3553 个训练集构建 MATM，274 个测试集评估。
  - **WebArena**：网页导航环境。自行划分 724 训练 + 88 测试，保持任务意图分布。
- **智能体群体**：
  - 生产者：35-37 个不同模型（包括 GPT-4-Turbo、Claude-3.5-Sonnet、Qwen3-32B、Grok 系列等）。
  - 消费者：34 个模型（包含部分与生产者重叠的模型）。
- **对比方法**：
  - **无检索基线**：标准 LLM 直接与环境交互。
  - **单级检索**：仅使用密集检索（无重排）。
  - **三种 LTR 重排器**：FFN、LambdaMART、SVMRank。
- **评估指标**：
  - **成功率 (SR)**：任务完成率。
  - **步数 (# steps)**：每轮交互平均步数。
  - **返回配对偏好 (RPP)**：衡量联合优化效果与效率的 Pareto 支配指标。

## 6. 主要结论与发现

- MATM 检索显著提升消费者智能体的成功率和效率（ALFWorld SR 从 47%→55%，WebArena SR 从 18%→20%）。
- 学习排序重排器（LTR）进一步放大增益，ALFWorld 上 SVMRank 达到最高 SR 64.3%，步数降至 10.35；WebArena 上 FFN 最好（SR 20.5%，步数 19.91）。
- **收益分布广泛**：消费者无论从更强、相当还是更弱的生产者处获取轨迹均受益，表明 MATM 不仅仅是“强者援助弱者”。
- **跨任务泛化**：即使检索到的轨迹来自不同任务类型，仍能提升性能（ALFWorld 跨任务 SR 达 59.9%），优于无检索基线。
- **记忆规模扩展性**：MATM 性能随索引大小单调递增（ALFWorld），或先降后升（WebArena 50% 时出现 dip，但全量时最佳），表明更大更丰富的记忆更有利。

## 7. 优点

1. **新颖性**：首个提出群体级交互记忆框架，系统性地利用智能体生成的轨迹进行跨个体复用，区别于仅作用于单智能体或同质群体的方法。
2. **轻量实用**：重排器使用轻量级 LTR，特征设计兼顾生产者可信度建模和消费者个性化，无需联合训练或额外预训练。
3. **跨任务泛化能力**：实验证明轨迹语义通用性超出任务类型限制，提升了框架的实用性。
4. **规模可扩展**：记忆索引可增量生长，随更多智能体加入而积累知识。
5. **实验设计严谨**：区分训练/测试、控制随机种子、与无检索基线对比，并使用 RPP 指标同时衡量效果与效率。

## 8. 不足与局限

1. **环境覆盖有限**：仅涉及两个交互式基准（ALFWorld、WebArena），未涵盖更多领域（如代码生成、多轮对话等），结论的泛化性有限。
2. **重排器训练标签稀疏**：LTR 标签仅来自 5 个固定秩位置（1,5,10,15,20），未覆盖全部排序分布，可能引入偏差。
3. **跨基准泛化未测试**：重排器在同一基准内训练和评估，未验证跨基准迁移能力。
4. **未考虑生产者激励与安全性**：当前框架假定生产者善意，未处理对抗性生产者（如注入恶意轨迹）或设计贡献激励机制，这是双面市场的重要环节。
5. **计算成本**：虽然总体成本可控，但增量构建过程需对每个问题执行多次 rollout（基线 + 5 个候选），可能在大规模下变得昂贵。
6. **探索-利用平衡**：RetrievalPlanner 的设计和最优检索时机未深入分析，可能影响效率。
