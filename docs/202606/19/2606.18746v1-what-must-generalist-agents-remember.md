## 摘要
本文提出了一个形式化描述，探讨通才型智能体为了在多个环境和目标中接近最优地行动，必须在记忆中存储什么。研究表明，当两个领域共享一个观测瓶颈但需要不相容的最优行动时，任何一致接近最优的策略必须在那个瓶颈处引发不同的记忆分布。这一结果导出一个分离定理：足够成功的智能体不能仅依赖当前状态观测，而必须在记忆中保留领域相关信息。本文进一步证明，如果智能体的记忆包含足够的信息来估计相关目标的值，那么该记忆可用于近似重构智能体的局部转移动力学。这些结果共同将记忆刻画为支持领域消歧、转移模型重构和通才型智能体规划的基板。

## Abstract
This paper develops a formal account of what generalist agents must store in memory in order to act near-optimally across multiple environments and goals. It shows that when two domains share an observational bottleneck but require incompatible optimal actions, any uniformly near-optimal policy must induce distinct memory distributions at that bottleneck. The result yields a separation theorem: sufficiently successful agents cannot rely only on current state observations, but must preserve domain-relevant information in memory. The paper further shows that if an agent's memory contains enough information to estimate values for related goals, then that memory can be used to approximately reconstruct the agent's local transition dynamics. Together, these results characterize memory as the substrate that supports domain disambiguation, transition-model reconstruction, and planning for generalist agents.

## 3. 实验设计

### 3.1 场景：ForkWorld
- 一个T形路口网格世界：起始点s0 → 走廊长度为c → 瓶颈状态s† → 上臂长ℓ通向上目标G_up，下臂通向下目标G_down。动作包括上下左右停留，确定性移动。
- 领域σ ∈ {normal, swapped}：垂直动作映射互换。normal时up→(0,+1), down→(0,-1)；swapped时相反。水平动作不变。
- 目标ψ ∈ {up, down}：到达正确端点得+1，错误得0，每步成本-0.01。
- 关键性质：在s†处最优动作集跨领域不相交（满足Assumption 1）。

### 3.2 Benchmark与对比方法
- **Memoryless DQN**：仅当前状态+目标，无记忆。
- **Stacked DQN**：滑动窗口k=3，包含过去的观测和动作。
- **DRQN (states)**：GRU循环网络，仅状态观测。
- **DRQN (states+actions)**：GRU额外拼接上一动作。
- **Oracle DQN**：记忆less DQN但提供领域标签σ。
- **Oracle DRQN**：DRQN提供领域标签。

### 3.3 评估指标
- 成功率（Success rate），按(goal × domain)四种条件分层。
- 领域可区分性：在瓶颈处用线性探针对记忆状态进行分类（首次访问 vs 后续访问）。
- 转移解码误差：用记忆+动作训练MLP预测下一状态，计算错误率。

1. **记忆是必要的**：在ForkWorld中，无记忆的DQN成功率仅19%（低于随机水平），而记忆型智能体可达75-88%，接近Oracle DQN的100%。
2. **记忆必须分离领域**：在瓶颈s†处，首次访问时所有智能体无法区分领域（正确率≈50%），但后续访问时记忆型智能体正确率达97-100%，而无记忆者仍为50%。
3. **记忆支持转移解码**：在s†处，记忆型智能体的记忆+动作可解码下一状态，解码误差显著低于多数类baseline（例：DRQN states从0.46降到0.17），而无记忆者解码误差等于baseline。
4. **理论界限得到验证**：Theorem 1关于记忆分离的预测以及Theorem 2关于解码存在的预测在实验中均成立。
