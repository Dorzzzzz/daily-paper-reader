## 摘要
当前的视觉-语言模型在处理长达数小时的视频时面临困难，因为处理完整视觉序列会导致令牌爆炸和注意力稀释。为解决这一问题，我们提出了MemDreamer，通过解耦感知与推理，将长视频理解转化为一种代理式探索过程。作为一个即插即用框架，它增量式地流式处理视频，构建分层图记忆——一种自上而下的三层架构用于语义抽象，并以捕获时空与因果关系的基图为核心。在推理阶段，推理模型采用代理工具增强检索，通过观察-推理-行动循环在层级间导航、搜索节点并遍历逻辑边。实验结果表明，MemDreamer在四个主流基准测试中取得了最先进的结果，与人类专家的差距缩小至仅3.7个百分点。它将推理上下文窗口限制在全上下文摄入的仅2%的同时，带来了12.5个百分点的绝对准确率提升。此外，统计分析揭示了视觉-语言模型在逻辑推理与长视频理解基准上的性能之间存在强正线性相关性，将代理能力扩展确立为多模态理解的新范式。

## Abstract
Current Vision-Language Models struggle with hours-long videos because processing full-length visual sequences induces prohibitive token explosion and attention dilution. To overcome this, we introduce MemDreamer to decouple perception and reasoning, shifting long-video understanding into an agentic exploration process. As a plug-and-play framework, it incrementally streams videos to construct a Hierarchical Graph Memory, a top-down three-tier architecture for semantic abstraction, anchored by a foundational graph capturing spatiotemporal and causal relations. During inference, the reasoning model employs agentic tool-augmented retrieval, navigating hierarchies, searching nodes, and traversing logical edges via an Observation-Reason-Action loop. Experiments show MemDreamer achieves SOTA results across four mainstream benchmarks, narrowing the gap with human experts to only 3.7 points. It constrains the reasoning context window to merely 2% of full-context ingestion while delivering a 12.5 point absolute accuracy gain. Furthermore, statistical analysis uncovers a strong positive linear correlation between an VLM's performance on logic reasoning and long-video understanding benchmarks, establishing agentic capability scaling as a new paradigm for multimodal comprehension.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：现有视觉-语言模型（VLM）处理数小时的长视频时，由于必须全量处理视觉序列，导致两个关键瓶颈：
  - **感知层面**：每秒1帧采样2小时视频产生超过160万令牌（例如Qwen3-VL tokenizer下约1.62M），远超当前上下文窗口限制。
  - **推理层面**：冗余令牌引起注意力稀释（attention dilution）和“lost in the middle”现象，严重退化长程推理能力。
- **整体含义**：作者指出当前VLM采用“紧耦合”策略，将视觉感知与逻辑推理强行捆绑在同一上下文中，这是瓶颈根源。因此提出**解耦感知与推理**的新范式，将长视频理解转化为主动的代理式探索过程，从而实现更高效的视频理解，并首次揭示了VLM的代理推理能力与长视频理解性能之间的强正相关性。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
- 采用**“流式构建记忆 + 代理检索”**的两阶段解耦框架：
  - **感知阶段**：一个独立的感知模型P流式处理视频，增量构建纯文本的**分层图记忆（Hierarchical Graph Memory）G**。
  - **推理阶段**：另一个推理模型R通过工具增强的**代理检索机制**，在G上执行多步**Observation-Reason-Action循环**，提取任务相关线索并给出答案。推理过程中不访问原始视频帧。

### 关键技术细节

#### (1) 分层图记忆（Hierarchical Graph Memory）构建，分三步：
- **流式自适应分割**：感知模型P每10分钟滑动窗口内，识别语义完整的**Macro Events**（宏事件），窗口边界由事件自然结束决定而非固定时长。避免固定窗口导致的语义截断。
- **向下子图提取**：为每个Macro Event构建局部子图gi = (Vi, Ei)：
  - 节点集Vi包含**实体节点VEi**（人物、物体、地点等）和**微事件节点VMi**（原子动作，有精确时间范围）。
  - 边集Ei包含三类拓扑关系：
    - 空间-属性边（VEi ↔ VEi）：静态布局、组成、共指等。
    - 主体-对象边（VEi ↔ VMi）：实体与动作的角色绑定。
    - 时间-因果边（VMi → VMi）：时间顺序和因果链（BEFORE, CAUSES, PREVENTS等）。
- **向上层次聚合**：将相邻的Macro Events按语义和时间相近性合并为**Super Events**（中层），最终收敛到一个**Video Root**（顶层）。形成三层结构：Video Root → Super Events → Macro Events（内含子图）。

#### (2) 代理工具增强检索（Agentic Tool-Augmented Retrieval）
- 为推理模型R配备三类工具：
  - **层次导航工具**：GetSummary, GetSuperEvent, GetMacroEvent, GetSubgraph —— 支持从粗到细地展开记忆。
  - **精确搜索工具**：SearchNodes（语义向量检索）、SearchByTime（时间范围定位）。
  - **图遍历工具**：GetRelationGraph —— 沿三类边进行多跳探索。
- **Observation-Reason-Action循环**：
  - 每步t，R根据历史轨迹Ht-1选择工具并给出参数at = R(Q, Ht-1)。
  - 执行工具后得到原始观察ot，R仅抽取与问题相关的高质量线索ct = R(ot, Q)，并附加到轨迹Ht。
  - 这种“选择性压缩”避免冗余token累积，保持推理上下文窗口极小（5.9K~6.3K token，仅为全量输入的2%左右）。

#### (3) 流程概述
- 输入视频流 → 流式自适应分割（窗口τ=10分钟） → 向下子图提取（用感知模型P） → 向上层次聚合（同样用P） → 得到G。
- 推理时：用户查询Q → R执行多步ORA循环，调用工具探索G → 积累证据 → 输出最终答案A。

## 6. 论文的主要结论与发现

1. **解耦感知与推理显著提升性能**：MemDreamer在四个基准上达到SOTA，LVBench得分90.7，与人类专家（94.4）差距仅3.7个百分点。相比端点到端Gemini-3.1-Pro提升12.5点。
2. **极大压缩推理上下文**：推理上下文窗口仅5.9K~6.3K token（仅为全量输入的2%），同时提升准确率12.5点。验证了结构化记忆+代理检索可避免“lost in the middle”。
3. **代理推理能力与长视频理解呈现强正相关**：在MemDreamer框架下，VLM的AIME2025逻辑推理分数与LVBench得分的Pearson相关系数达到0.897（p<0.01），而端到端范式下仅0.702且不显著。这表明解耦后，模型的推理能力可直接迁移至视频理解，提出“代理能力缩放”新范式。
4. **层次图记忆优于平面存储**：分层结构（Hierarchy）提供宏观导航，图拓扑（Graph）提供因果链追踪，二者互补。完整Hierarchical Graph比Flat-Chunk提升13.3点。
5. **代理工具集优于静态检索**：全工具集比纯语义相似度检索高20.2点；比全上下文输入（Full Context）高出11.8点（尤其是推理维度提升显著）。

## 7. 优点：方法或实验设计上的亮点

- **创新型框架**：首次将长视频理解彻底解耦为“感知建记忆”和“推理做探索”，完全消除视觉token在推理阶段的干扰。
- **即插即用性**：不依赖任何特定VLM的微调，可直接作为插件提升任何现有VLM的长视频能力，易于推广。
- **高效上下文管理**：通过选择性线索压缩，每轮只维护最相关的证据，避免多步交互积累噪声，保证了代理循环的可持续性。
- **完整的工具设计**：三类工具（导航、搜索、图遍历）覆盖了多层次信息访问需求，使代理能够灵活地在宏观结构和微观细节之间切换。
- **详尽的消融分析**：不仅消融了记忆结构、检索策略，还分析了轮次预算、搜索广度、模型组合等，并揭示了推理能力与视频理解的强相关性，为未来研究提供新方向。
- **实验覆盖全面**：4个基准（LVBench、LongVideoBench、Video-MME、EgoSchema）覆盖了不同时长、视角和推理类型，结果具有较强泛化性。

## 8. 不足与局限

- **感知模型依赖**：虽然表6显示不同感知模型（Gemini-2.5-Pro vs 3.1-Pro）造成的性能差异很小（0.4%），但前提是感知模型能力较强。对于更弱的感知模型，构建的记忆质量可能下降，导致最终性能受损。论文未测试非常弱的感知模型。
- **文本记忆的固有局限**：纯文本描述和结构化子图可能丢失原始视频中的细微视觉信息（如颜色、表情、细微动作），某些需要精确视觉定位或进行视觉相似性判断的问题可能受损（如“衣服是什么颜色”可能需要精确描述，但描述可能不准确）。论文未专门分析此类问题。
- **代理循环的延迟**：推理阶段需要多轮工具调用（平均约3轮），每次调用涉及一次大模型推理+向量搜索+图遍历。尽管上下文小，但总延迟可能高于端到端单轮推理。论文未报告实际推理延迟。
- **数据集覆盖有限**：尽管四个基准具有代表性，但主要集中在新闻、纪录片、电影、烹饪等类型，可能未覆盖互动式视频（如GUI视频、在线会议）或极端长视频（如24小时监控）。
- **人类差距仍存在**：在LVBench上，MemDreamer最佳90.7 vs 人类94.4，仍有3.7点差距，表明高难度问题仍需更强大的推理或感知能力。
- **超参数敏感性**：轮次预算Tmax=12最好，但Tmax=15已出现退化（90.2），表明过多轮次可能引入噪声。搜索top-k=10最优，k=5或15均下降。这些超参数可能需针对不同数据进行调优。
