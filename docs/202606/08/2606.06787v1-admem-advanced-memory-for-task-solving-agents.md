## 摘要
大型语言模型（LLMs）在作为工具使用型智能体方面展现出潜力，但在需要记忆、组织和重用知识的长期任务中仍受限。先前的记忆方法旨在解决这一问题，但主要集中于存储事实信息。近期关于程序记忆的工作改善了任务重用，但往往简化为重放过去的成功经验，而未处理失败案例或在线可扩展性。我们引入了一个统一且自动化的记忆框架，该框架整合了语义、情景和程序记忆，采用结合短期与长期存储的双层设计。一种包含执行、记忆和评价智能体的多智能体架构实现了自动记忆生成、奖励标注和自适应检索。长期记忆通过基于奖励的评估、合并和剪枝进行管理，确保可扩展性和持续改进。跨多种环境的实验表明，与现有基线相比，我们的方法在长期多轮任务中提升了鲁棒性和成功率。这项工作凸显了全面、自适应记忆对于推进基于LLM的智能体的重要性。

## Abstract
Large Language Models (LLMs) show promise as tool-using agents but remain limited in long-horizon tasks that require remembering, organizing, and reusing knowledge. Prior memory approaches aim to resolve the situation, but mainly focus on storing factual information. Recent work on procedural memory improves task reuse, yet often reduces to replaying past successes without addressing failure cases or online scalability. We introduce a unified and automatic memory framework that integrates semantic, episodic, and procedural memory in a bi-level design combining short-term and long-term stores. A multi-agent architecture with actor, memory, and critic agents enables automatic memory generation, reward annotation, and adaptive retrieval. Long-term memory is managed through reward-based evaluation, merging, and pruning, ensuring scalability and continual improvement. Experiments across various environments show that our approach improves robustness and success on long multi-turn tasks compared to existing baselines. This work highlights the importance of comprehensive, adaptive memory for advancing LLM-based agents.

- **整体含义**：提出一套全面、自适应的记忆机制对于推进LLM智能体在复杂、长时间跨度的任务中提升鲁棒性和成功率至关重要。

## 2. 方法论

### 核心思想
- 提出 **AdMem**：一个统一且自动化的记忆框架，以**双层记忆架构**（短期记忆+长期记忆）整合**语义记忆、情景记忆和程序记忆**。
- 采用**多智能体架构**（Actor、Critic、Memory Agent）实现记忆的自动生成、奖励标注、检索和在线管理。

### 关键技术细节
- **记忆类型定义**：
  - *语义记忆*：存储关于环境和任务的事实与通用知识。
  - *情景记忆*：存储过去交互事件的摘要。
  - *程序记忆*：存储从过去行动中提取的决策指导（包含上下文、行动、反思），并附带奖励信号。
- **短期记忆管理**：
  - 采用类似计算机程序运行的**栈结构**，支持子目标（sub-goal）的添加和结束，实现上下文压缩（context compaction），只保留当前子目标相关信息，空间复杂度可控。
- **长期记忆管理**：
  - *检索*：对语义/情景记忆使用稠密检索；对程序记忆结合**上下文相似度**（通过归一化嵌入向量ψ）和**记忆有效性参数v_m**进行打分，选择top-n条目。
  - *评估与更新*：引入轻量级模型，假设奖励由选中的程序记忆条目的有效性以及上下文相似度共同决定，使用**EM算法**在线更新v_m（初始值设为1，体现不确定性乐观）。critic agent每步生成奖励r∈{0,1}，反馈给memory agent用于更新v_m。
  - *修剪与合并*：设置阈值ε，低频使用的记忆条目被删除；经常同时被检索或同时不被检索的条目被合并成一个条目，以保持存储高效。
- **算法流程**：
  - **Actor Agent**：接收环境观察 → 向critic报告 → 向memory agent请求语义/情景记忆 → 检索程序记忆 → 基于上下文和记忆选择行动，并设定预期结果 → 更新短期状态 → 向critic报告半成品记忆。
  - **Critic Agent**：维护队列，收集actor的半成品记忆（上下文、行动、预期、相关记忆）。当收到足够观察后，生成奖励（0/1）和反思文本，并将新程序记忆条目送入memory agent，同时将奖励反馈给先前使用的记忆条目。

  - 仅长期程序记忆（LTP）——无短期规划

  - 多轮次测试（多epoch）以评估长期记忆的累积效果。
- **LLM后端**：统一使用 **Claude Haiku 4.5**。

## 6. 主要结论与发现

- **AdMem在大多数域上显著提升了任务完成率和平均进度**：
  - 例如：AlfWorld完成率从ReAct的49.3%提升至63.4%；Babyai从97.3%至100%；Jericho从40.0%至50.0%；PDDL从33.3%至76.7%等。
  - 在Tool-query Academic、Weather等域也有明显优势；仅在WebShop和Science World域略低于ReAct（但AdMem仍保持相近水平）。
- **短期规划提升单任务进度**，但**长期记忆是实现跨任务自我改进的关键**：多epoch实验显示，随着轮次增加，AdMem持续提升（Jericho从第一轮45%到第三轮60%），而仅LTP方式表现反而下降（20%→30%），说明单独加入程序记忆如不配合良好设计反而有害。
- **记忆系统需谨慎平衡“记忆依赖”与“即兴发挥”**：不当的记忆转移可能导致混淆，AdMem通过奖励引导和自适应检索缓解该问题。

## 7. 优点

- **统一性与完整性**：同时整合语义、情景、程序三类记忆，覆盖认知科学经典分类，且以双层结构（短期+长期）实现高效管理。
- **自动化与可扩展**：多智能体协作自动生成记忆和评估（无需人工标注），并拥有在线合并/剪枝机制，适合长期部署。
- **奖励驱动的自适应检索**：通过EM算法在线估计每个记忆条目的有效性参数，结合上下文相似度进行检索，实现记忆的持续优化。
- **短期规划与子目标堆栈**：借鉴计算机科学栈结构进行上下文压缩，使智能体能在复杂任务中保持清晰执行焦点。
- **实验设计客观**：在同一AgentBoard基准上，采用统一LLM，系统提示等一致，结果可复现。

## 8. 不足与局限

- **LLM泛化性**：仅测试Claude Haiku 4.5，不同模型（如GPT-4、Llama系列）下的表现未知。
- **算力与成本**：未报告具体GPU使用，仅提到API调用次数增加（最坏情况3倍），实际部署可能产生更高延迟和费用。
- **对比缺失**：未与Mem0、MemGPT、MIRIX等近期流行记忆系统在相同交互式任务上直接比较（论文给出的原因可被理解，但仍削弱了说服力）。
- **部分域无增益**：在WebShop和Science World上AdMem的完成率略低于ReAct，表明记忆机制在多变的Web环境中可能引入噪声或误导。
- **评估指标单一**：仅使用任务完成率和平均进度，未分析每一步的效率、检索开销、记忆存储规模等。
- **实验规模有限**：消融实验仅在Jericho域进行（20个任务），在其他更多任务上的消融缺失。
- **未讨论失败案例的粒度**：奖励为0/1二值，可能不足以反映部分成功情况；EM模型假设奖励由逻辑或组合产生，可能过于简化。
