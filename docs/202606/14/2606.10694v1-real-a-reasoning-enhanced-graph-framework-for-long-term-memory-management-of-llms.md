## 摘要
大语言模型（LLMs）被期望与用户进行长时间交互。然而，由于有限的上下文窗口，LLMs无法保留所有历史交互，因此长期记忆管理对于存储、更新和检索超出上下文限制的历史信息至关重要。尽管近年来的记忆系统试图通过外部存储历史信息来解决这一问题，但现有方法存在三个关键局限：基于扁平文本的记忆组织无法捕捉记忆间的显式关系；结构化记忆系统常常破坏性地覆盖演化中的事实；当前的检索机制在证据不完整时仍然与查询无关且被动。REAL将长期对话记忆构建为时间感知和置信度感知的有向属性图，其中每个原子事实用实体、关系、有效时间区间、置信度分数和探索意图标签表示。在记忆构建过程中，REAL采用非破坏性时间更新策略，保留并行事实版本及其有效区间，从而忠实地追踪事实演化。在检索过程中，REAL锚定与查询相关的根实体，解耦其探索意图，并执行语义评估器引导的混合束搜索以提取紧凑的记忆子图。它还进一步引入反事实推理来修复不可靠的检索状态，并通过隐式逻辑关系恢复缺失的记忆证据。综合实验表明，REAL在长期记忆性能上显著优于基于扁平文本、图结构及现有记忆基线的方法，平均提升22.72%。

## Abstract
Large Language Models (LLMs) are increasingly expected to interact with users over long time horizons. However, due to their finite context window, LLMs cannot retain all past interactions, making long-term memory management essential for storing, updating, and retrieving historical information beyond the context limit. Although recent memory systems attempt to address this issue by storing historical information externally, existing approaches suffer from three key limitations: flat text-based memory organizations fail to capture explicit relations among memories, structured memory systems often destructively overwrite evolving facts, and current retrieval mechanisms remain query-agnostic and passive when evidence is incomplete. REAL constructs long-term conversational memory as a temporal and confidence-aware directed property graph, where each atomic fact is represented with entities, relations, valid-time intervals, confidence scores, and exploration intent labels. During memory construction, REAL adopts a non-destructive temporal update strategy that preserves parallel fact versions and their validity intervals, enabling faithful tracking of fact evolution. During retrieval, REAL anchors query-relevant root entities, decouples their exploration intents, and performs semantic evaluator-guided hybrid beam search to extract compact memory subgraphs. It further incorporates counterfactual inference to repair unreliable retrieval states and recover missing memory evidence through implicit logical relations. Comprehensive experiments demonstrate that REAL substantially improves long-term memory performance over flat-text, graph-based, and existing memory baselines, achieving an average improvement of 22.72\%.

# 论文详细总结

## 1. 论文的核心问题与整体含义（研究动机和背景）

大语言模型（LLMs）在与用户长期交互中面临固有上下文窗口限制（通常8K-256K tokens），无法保留全部历史对话。单纯扩大上下文窗口不可持续，因为：  
- 无限累积的历史会超出窗口限制；  
- 长距离注意力衰减导致远距离关键信息难以利用；  
- 实际对话主题频繁切换，相关事实淹没在无关tokens中。  

因此需要外部长期记忆系统来存储、更新和按需检索历史信息。然而现有方法存在三大缺陷：  
- **C1：扁平文本组织**——无法建立记忆间的显式链接，不支持多跳推理；  
- **C2：缺乏事实演化**——结构化记忆系统采用破坏性覆盖，抹消了用户偏好等事实的演变轨迹；  
- **C3：检索低效与被动**——检索方式与查询无关，当证据不足时无法主动推理，只能返回“不知道”。  

论文提出REAL框架，旨在通过结构化的时间感知图与非破坏性更新、结合主动推理的检索机制来解决上述问题。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
将长期对话记忆构建为**时间感知、置信度感知的有向属性图**，每个原子事实以六元组存储：`(头实体h, 关系r, 尾实体t, 有效时间区间τ, 置信度c, 探索意图ι)`。  
检索时通过**语义评估器引导的混合束搜索**提取与查询相关的紧凑子图，并引入**反事实推理**修复不可靠的检索路径。

### 关键技术与流程

#### A. 记忆构建（Memory Construction）
- **原子事实提取**：对每轮对话调用LLM提取形如`(h, r, t, [τₛ, τₑ], c, ι)`的六元组。  
  - 时间区间：`τₛ`设为当前时间戳，`τₑ`初始为∞（仍有效）。  
  - 置信度：根据语言线索（如“可能”“总是”）由LLM赋值，低置信度事实（c < θₛₜₐₜₐ）仅在查询明确要求时才纳入检索。  
  - 探索意图：标签包括FACT（事实）、CAUSAL（因果）、TEMPORAL（时序）、CONTRAST（对比）、EVOLUTION（演化）。  
- **非破坏性时间更新**：  
  - 单值关系：当新事实与旧事实冲突时，不覆盖，而是关闭旧事实的`τₑ`（设为新事实开始时间），新事实独立插入。  
  - 多值关系：直接添加并行边。  
  - 未知基数：默认按多值处理。  
- **置信度升级**：后续对话确认后可提升低置信度事实的分数，使其进入稳定检索。

#### B. 记忆检索（Memory Retrieval）
1. **根实体锚定与意图解耦**：从查询中提取实体并判断每个实体的探索意图（如因果、时序等）。
2. **语义评估器引导的混合束搜索**（Algorithm 1）：  
   - 从每个根实体出发，维护k个束（beam），每步扩展时通过三重过滤：**时间有效**、**置信度≥θₛₜₐₜₐ**、**意图兼容**。  
   - 剩下的候选邻居按语义相似度取top-m。  
   - 对每条路径评估三个分数：**查询相关性(SQR)**、**逻辑连贯性(SLC)**、**实体特定答案充分性(SAS)**。  
   - **停止/扩展决策**：若当前路径的SAS ≥ 所有扩展候选的SAS，则停止；否则选择更高分的扩展路径。  
   - **反事实推理**：当无有效邻居、最大SQR < δ_QR或最大SLC < δ_LC时触发，利用对称、上下位、时序继起、因果、共现等隐式逻辑规则生成替代遍历路径，并合并回候选池。  
   - 全局束剪枝：保留每个根实体top-k的路径。重复直到所有束停止或达到最大深度D_max。
3. **答案生成**：将检索到的子图序列化为紧凑证据文本（包含实体、关系、时间、置信度），与查询一起送入LLM生成最终回答。

### 复杂度分析（论文IV-D节）
- 记忆构建：每个事实更新成本O(degᵣ(h))，远小于M总数。  
- 检索成本：O(n·D_max·[kd log m + k(m+1) + ρk\bar{B}_cf + km log k])，其中n根实体数，k束宽，D_max深度，m候选数。反事实推理触发率ρ通常很小。
