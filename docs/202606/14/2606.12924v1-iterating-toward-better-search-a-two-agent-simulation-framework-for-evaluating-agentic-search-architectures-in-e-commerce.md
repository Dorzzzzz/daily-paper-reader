## 摘要
我们提出了一种模块化的双智能体模拟框架，用于评估对话式购物助手架构。一个独立的买家智能体配置了角色、任务和耐心水平，与一个可互换的响应器配对，该响应器集成了真实的电商搜索API。通过在实验中固定买家智能体，可以在相同场景下对响应器设计进行受控比较。利用跨越14个角色组的2011次对话，我们得出了四个实证发现。首先，滚动窗口内存在所有质量指标上均优于意图提取内存，且每次查询速度提高35%。其次，通过系统性失效分析，我们快速实现了证据驱动的迭代：对某个响应器版本的分析使得全数据集上的失败和接近失败率降低了62%。第三，将响应器的大语言模型骨干从Gemini 2.5换成Llama 3.3 70B，在相同架构下造成了0.16–0.45个百分点的性能下降。最后，我们记录了前沿大语言模型评判者之间系统性的哲学分歧：尽管使用相同的评估提示，Gemini倾向于奖励过程正确性，而Claude则要求具体结果。

## Abstract
We present a modular two-agent simulation framework for evaluating conversational shopping assistant architectures. An independent buyer agent, configured with personas, missions, and patience levels, is paired with an interchangeable responder that integrates with a real e-commerce search API. Holding the buyer constant across experiments enables controlled comparison of responder designs on identical scenarios. Using 2011 conversations across 14 persona buckets, we establish four empirical findings. First, rolling-window memory outperforms intent-extraction memory on all quality metrics while being 35% faster per query. Second, illustrating rapid evidence-driven iteration, a systematic failure analysis of a responder version enables targeted fixes that reduce failure and near-failure rates by 62% across the full dataset. Third, swapping the responder LLM backbone from Gemini~2.5 to Llama~3.3~70B costs 0.16--0.45 points despite identical architecture. Finally, we document systematic philosophical disagreement between frontier LLM judges: Gemini rewards process correctness while Claude demands concrete outcomes, despite using the same evaluation prompt.

- **响应器架构**：
  - **Sys-A（意图追踪）**：每次查询后额外LLM调用提取结构化意图并生成摘要。

  - **Sys-C**：保持Sys-B架构，但LLM骨干换成Llama 3.3 70B Instruct（vLLM服务）。
- **评估**：使用两个前沿LLM评判者（Gemini 3.1 Pro和Claude Opus 4.6）对四个维度（任务成功、SRP相关性、聊天帮助性、意图理解）按1-5分链式思维评分。双评判者设计用于揭示评估哲学分歧。

### 6. 主要结论与发现
1. **简单记忆架构优于复杂意图提取**：Sys-B（滚动窗口）在所有质量指标上优于Sys-A（意图追踪），且延迟降低35%。意图提取的额外LLM调用引入错误和噪声，现代长上下文模型可直接处理原始查询序列。
2. **系统性失败分析驱动快速迭代**：基于2,011条对话的失败模式分析，在一天内完成Sys-B→Sys-B+修复，使整体失败率（≤2分）降低62%，灾难性失败（所有指标1分）降低36%，最差桶（精确严格不耐烦）提升1.3-1.8分。
3. **LLM骨干独立影响质量**：相同架构下Llama 3.3 70B比Gemini 2.5低0.16-0.45分，尤其在聊天帮助性上差距大（0.45分）。Llama回复更泛化、过度使用聊天模式（75%回合vs 25%），降低任务完成度。
4. **评判者选择是决定性设计决策**：Gemini和Claude在相同提示下对30%的对话评分分歧≥2分（满分5），Gemini偏向过程正确性（奖励信息丰富解释），Claude偏向结果导向（要求达成购买/满意）。评判者间的差距（~0.5分）远大于架构间的差距（~0.1分），选择评判者即选择质量标准。

### 7. 优点
- **模块化与可重复性**：买家与响应器解耦，支持独立替换和受控实验，边际成本低（仅需LLM推理）。
- **证据驱动迭代**：通过大规模模拟暴露集中失败模式，实现快速针对性修复，体现了`R&D实验室`价值而非仅生产监控。
- **评判者哲学揭示**：双重评判者设计不仅增强鲁棒性，更首次量化了不同LLM评估标准的系统性分歧，对方法论有重要指导意义。
- **公平性视角**：识别出精确严格不耐烦买家群体失败率更高（7.5倍），提示离线模拟可提前发现部署后的公平性问题。
- **现实行为保真度验证**：通过64次无响应器控制实验，证明双智能体模式产生的查询更短、动作命令更多、自然纠正更多，优于单智能体生成。

### 8. 不足与局限
- **可重复性受限**：响应器实现代码、买家配置和对话记录均为eBay专有，无法外部复现。搜索API为内部服务，作者明确承认这一行业常见限制。

- **单一平台与垂直领域**：仅基于eBay数据，结论可能不直接迁移至其他电商平台或非电商场景。
