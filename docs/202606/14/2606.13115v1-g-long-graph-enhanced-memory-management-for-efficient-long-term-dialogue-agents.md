## 摘要
尽管大型语言模型（LLM）推动了开放域对话系统的发展，但由于长期上下文推理的固有限制以及处理大量原始文本的低效性，保持长期一致性仍然是一个挑战。现有方法通常依赖于易丢失信息的非结构化记忆存储，或者计算成本高昂且延迟较高的LLM。为解决这些问题，我们提出G-Long，一种图增强框架，利用微调的小型语言模型（sLM）进行结构化三元组提取和关联检索，显著降低运行成本。此外，我们引入新颖的注意力感知重要性评分机制，利用T5摘要器的内在交叉注意力信号识别重要记忆。在多个基准上的广泛实验表明，G-Long在响应生成和记忆检索方面均取得了最先进的性能，在MSC上响应质量提升高达9.8%，在LME上检索召回率提升40.8%，同时显著降低了计算开销。

## Abstract
While Large Language Models (LLMs) have advanced open-domain dialogue systems, maintaining long-term consistency remains a challenge due to inherent limitations in long-context reasoning and the inefficiency of processing extensive raw text. Existing approaches typically rely on either unstructured memory storage, which is prone to information loss, or computationally expensive LLMs that incur high latency. To address these limitations, we propose G-Long, a graph-enhanced framework that utilizes a fine-tuned small Language Model (sLM) for structured triplet extraction and associative retrieval, significantly reducing operational costs. Furthermore, we introduce the novel attention-aware importance scoring mechanism that leverages the intrinsic cross-attention signals of a T5 summarizer to identify salient memories. Extensive experiments across diverse benchmarks demonstrate that G-Long achieves state-of-the-art performance in both response generation and memory retrieval, yielding performance gains of up to 9.8% in response quality on MSC and 40.8% in retrieval recall on LME, while significantly minimizing computational overhead.

## 2. 方法论：核心思想、关键技术细节

- **核心思想**：将非结构化对话转化为结构化图表示（实体-关系-三元组），利用图结构进行关联检索，并利用注意力机制量化三元组重要性，从而实现高效、精准的记忆管理。
- **框架组件**（如图2所示）：
    1. **高效记忆构建（Efficient Memory Construction）**：
        - **三元组提取模块**：使用微调的sLM（如Qwen-3-8B，在PersonaExt数据集上指令微调）将每轮对话解析为（subject, relation, object）三元组。
        - **注意力感知重要性评分模块（Attention-Aware Importance Scoring）**：利用在SAMSum上微调的T5摘要器的最后一层解码器交叉注意力权重，计算每个三元组的原始显著性分数 S(t_k) = Σ_{x_i∈Tokens(t_k)} Σ_{j=1}^M A_{i,j}，其中 A_{i,j} 是平均多头注意力权重。然后归一化得到相对权重 w_k ∈ (0,1]。
    2. **图记忆库（Graph-Based Memory Bank）**：
        - 节点（V）：实体（主语、宾语），使用预训练编码器（MiniLM）嵌入并存储于向量数据库（ChromaDB）。
        - 边（E）：有向关系，属性丰富，包含 relation、importance score w、创建时间戳 τ_create、最后访问时间 τ_access。
    3. **关联记忆检索（Associative Memory Retrieval）**：
        - **检索候选扩展**：从当前用户话语 u_t 嵌入出发，找到语义最相似的 Top-N 实体作为锚点；从锚点出发进行 L-hop 子图扩展（实验中 L=1），收集候选三元组 T_cand。
        - **两阶段混合重排序**：
            - 粗排：保留与 u_t 语义相似度最高的 Top-N 三元组（T_sem）。
            - 精细排序：结合语义相似度 S_sem(t)、重要性 w、时间衰减 e^{-λΔτ}，计算最终得分 S_final = β1·S_sem + β2·w + β3·e^{-λΔτ}。选择 Top-K 三元组 T_retrieved。
        - 超参数：N_anc=5，L=1，Top-N=5，β1=0.5，β2=0.3，β3=0.2，λ=10^{-7}，K=3。
    4. **响应生成**：将检索到的三元组序列化为文本，与系统指令和当前对话历史拼接，输入LLM（如gpt-4o-mini）生成响应。

## 7. 优点

- **资源高效**：使用微调sLM替代LLM进行记忆构建，大幅降低API成本和token消耗。
- **结构化图记忆**：三元组表示紧凑、精确，避免非结构化摘要的信息丢失和噪声。
- **注意力感知重要性评分**：无需额外LLM调用，利用T5交叉注意力自然衡量三元组重要性，有效筛选高质量记忆。
- **两阶段重排序**：结合语义相似性、重要性、时间衰减，实现精细检索。
- **泛化性强**：在多个数据集和多模型设置下表现一致，模块化可即插即用。
- **可解释性**：图结构三元组支持透明审计和“被遗忘权”实现。

## 8. 不足与局限

- **信息粒度损失**：三元组离散化会丢失细微情感、风格等非事实信息。

- **检索边界问题**：案例研究显示，对未解析的照应词（如“it”）和过度依赖字面关键词可能产生语义漂移，需要混合上下文解析。
- **人类评估样本量有限**：仅50样本，统计显著性略弱。
- **实验未能覆盖所有场景**：如未在真实部署环境中测试延迟和并发性能，也未讨论多语言场景。
