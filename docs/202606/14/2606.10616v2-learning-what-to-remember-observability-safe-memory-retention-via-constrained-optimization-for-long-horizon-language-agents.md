## 摘要
长时域语言代理积累的观测、推理轨迹和检索事实会超出其有限的上下文窗口，使得记忆留存成为一个根本性的资源分配问题。现有记忆系统通过启发式评分、检索优化或学习压缩来改进管理，但大多将留存视为局部决策问题，并未在现实的可观测性约束下明确建模其长期后果。为填补这一空白，我们将记忆留存形式化为一个具有显式预算可行性、证据效用以及延迟代价（包括遗漏惩罚、重新获取延迟和过时信息风险）的约束随机优化问题。随后，我们提出了OSL-MR（面向记忆留存的可观测安全学习），这是一个新颖的框架，它强制分离了在线可观测特征与离线可用监督（OAS）。OSL-MR结合了从实际证据监督中训练的证据学习器，以及一个混合评分启发式方法，后者既可作为可部署的在线安全基线，又可作为结构化的归纳先验用于学习。由此产生的策略直接从交互数据中学习查询条件化的证据价值，同时保持在同一可观测性约束下可部署。在LOCOMO和LongMemEval上的实验表明，OSL-MR在记忆预算紧张的情况下，始终优于基于近期性的方法、生成式代理风格的评分以及其他启发式基线。混合评分先验在保持召回率的同时进一步提高了精确度，敏感性分析显示了其在多种成本配置下的鲁棒性。

## Abstract
Long-horizon language agents accumulate observations, reasoning traces, and retrieved facts that exceed their finite context windows, making memory retention a fundamental resource-allocation problem. Existing memory systems improve management through heuristic scoring, retrieval optimization, or learned compression, but largely treat retention as a local decision problem and do not explicitly model its long-term consequences under realistic observability constraints. To fill this gap, we formulate memory retention as a constrained stochastic optimization problem with explicit budget feasibility, evidence utility, and delayed costs including miss penalties, reacquisition delays, and stale-information risk. We then propose OSL-MR (Observability-Safe Learning for Memory Retention), a novel framework that enforces a strict separation between online-observable features and offline-available supervision (OAS). OSL-MR combines an evidence learner trained from realized evidence supervision with a Mixed-Score heuristic that serves both as a deployable online-safe baseline and as a structured inductive prior for learning. The resulting policy learns query-conditioned evidence value directly from interaction data while remaining deployable under the same observability constraints. Experiments on LOCOMO and LongMemEval show that OSL-MR consistently outperforms recency-based methods, Generative Agents-style scoring, and other heuristic baselines, particularly under tight memory budgets. The Mixed-Score prior further improves precision while preserving recall, and sensitivity analysis demonstrates robustness across a wide range of cost configurations.

## 2. 方法论

### 核心思想
- 将记忆保留建模为**约束随机优化问题**：在每步，从记忆池中选择子集，受限于硬预算（token数），最大化期望累积奖励。奖励函数包含命中奖励、全覆盖率奖励、存储成本、遗漏惩罚、重新获取惩罚和过时信息惩罚。
- 引入**可观测性分离**：严格区分在线可观测特征（查询上下文、记忆元数据、交互历史等）和离线可用监督（OAS，如金标准证据、答案文本、真实新鲜度）。部署策略只能使用在线特征，OAS仅用于训练和评估。
- 提出**OSL-MR框架**：结合（i）**证据学习器**（Evidence Learner），从交互日志中训练，使用金标准证据标签（二分类）作为学习目标；（ii）**混合评分启发式**（Mixed-Score），作为冷启动可部署基线以及学习的归纳先验。

### 关键技术细节
- **奖励函数**：每步奖励 \( r_t = \alpha_{\text{hit}} T^{\text{hit}}_t + \alpha_{\text{full}} F_t - \alpha_{\text{store}} \sum x_{t,i} s_{t,i} - \alpha_{\text{miss}} T^{\text{miss}}_t - \alpha_{\text{reacq}} T^{\text{reacq}}_t - \alpha_{\text{stale}} T^{\text{stale}}_t \)。
- **混合评分**：\( MS_{t,i} = w^{\top} \bar{\psi}^{\text{time}} + w^{\top} \bar{\psi}^{\text{rel}} + w^{\top} \bar{\psi}^{\text{ctx}} + w^{\top} \bar{\psi}^{\text{risk}} - w_c \frac{s_{t,i}}{B_t} \)，所有组件均基于在线可观测信号，并加入新鲜度代理（基于记忆类型和时间的指数衰减）。
- **证据学习器**：使用MLP（单隐层，16个隐单元，sigmoid输出），输入为在线特征拼接混合评分，输出证据成员概率。训练目标为加权二分类交叉熵，推理时通过约束解码（贪心选择满足预算限制的最高分记忆）得到保留集合。
- **分阶段部署**：先使用混合评分进行冷启动并收集日志；离线训练证据学习器后，冻结部署，无缝替换启发式策略。

### 算法流程（文字说明）
1. 初始化空数据集。
2. 循环每个训练环境：每步观测记忆池，计算在线特征和混合评分，形成特征向量；获取金标准证据标签（OAS）；记录到数据集；使用混合评分进行约束解码选择保留记忆；执行交互，进入下一步。
3. 收集足够数据后，使用加权二分类交叉熵训练证据学习器。
4. 部署时，使用训练好的学习器（仅依赖在线特征）进行约束解码。

## 6. 主要结论与发现

- **启发式方法不足**：近期性、GA、混合评分均会饱和预算，导致证据F1低下，尤其在紧预算下。
- **证据监督学习是主要驱动**：OSL-MR在所有预算和数据集上一致优于所有基线，紧预算下提升最大。
- **混合评分先验提升精确率但不牺牲召回率**：去除先验后精确率下降，占用率上升，召回率基本不变。

- **鲁棒性**：敏感性分析表明OSL-MR在多种成本配置下仍为最优非预言方法。
