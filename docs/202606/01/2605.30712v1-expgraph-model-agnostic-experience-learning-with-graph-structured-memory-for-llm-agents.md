## 摘要
大型语言模型（LLM）智能体在推理、工具使用和多步交互方面展现出强大能力，但它们通常从零开始解决任务，未能重用以往成功策略或失败教训。基于收集的经验进行微调可改善重用，但当出现更强或更合适的执行器时，这种方法缺乏灵活性。我们提出ExpGraph，一种模型无关的经验学习框架，使冻结且可替换的LLM执行器能够通过外部经验重用而无需参数更新即可改进。ExpGraph将历史轨迹总结为可重用的技能和失败教训，将其组织为自演化经验图中的节点，并通过图扩散和效用感知排序检索有用经验。轻量级检索副驾驶员通过强化学习进行训练，利用比较有无检索经验时执行器性能的反馈，同时根据下游任务结果在线更新图。我们在ExpSuite上评估ExpGraph，涵盖问答、数学推理、代码生成以及包括ALFWorld和AppWorld在内的多步智能体环境。在静态任务中，ExpGraph在较小和较大执行器上分别比最强基线提高12.2%和4.7%；在智能体环境中提高21.4%和12.7%，同时平均交互步骤减少12.7%和21.6%。消融实验表明，图结构经验、效用感知排序和自适应检索共同实现了跨不同任务和执行器模型的有效经验重用。

## Abstract
Large language model (LLM) agents have shown strong capabilities in reasoning, tool use, and multi-step interaction, but they often solve tasks from scratch and fail to reuse successful strategies or failure lessons from prior experience. Fine-tuning on collected experience can improve reuse, but it is inflexible when stronger or more suitable executors emerge. We propose ExpGraph, a model-agnostic experience learning framework that enables frozen and replaceable LLM executors to improve through external experience reuse without parameter updates. ExpGraph summarizes historical trajectories into reusable skills and failure lessons, organizes them as nodes in a self-evolving experience graph, and retrieves useful experiences through graph diffusion and utility-aware ranking. A lightweight retrieval copilot is trained with reinforcement learning using feedback that compares executor performance with and without retrieved experiences, while the graph is updated online from downstream task outcomes. We evaluate ExpGraph on ExpSuite, covering question answering, mathematical reasoning, code generation, and multi-step agentic environments including ALFWorld and AppWorld. ExpGraph improves over the strongest baseline by 12.2% and 4.7% on static tasks with smaller and larger executors, and by 21.4% and 12.7% in agentic environments, while reducing average interaction steps by 12.7% and 21.6%. Ablations show that graph-structured experience, utility-aware ranking, and adaptive retrieval jointly enable effective experience reuse across diverse tasks and executor models.

- **核心问题**：LLM 智能体在执行推理、工具使用和多步交互任务时，通常每个任务都从零开始求解，无法系统性地重用以往的成功策略或失败教训。现有解决方法是基于收集的经验对执行器进行微调，但随着更强或更合适的 LLM 不断涌现，这种参数级更新方式缺乏灵活性：每次更换执行器都需要重新训练，成本高且无法适用于闭源或难以更新的模型。
- **研究意义**：提出一种**模型无关**的经验学习框架，使得**冻结且可替换**的 LLM 执行器能够通过外部经验重用实现性能提升，而不需要修改自身参数。这解耦了经验学习与执行器训练，为 LLM 智能体的持续学习提供了一条实用且可扩展的路径。
- **挑战**：表面相关 ≠ 下游有用；经验往往是关系型而非孤立存在；检索策略需自适应任务和执行器。

## 2. 方法论：核心思想、技术细节与算法流程

### 核心思想
ExpGraph 构建一个**自演化经验图**，将历史轨迹提炼为技能节点（成功策略）和失败教训节点，并通过**图扩散**和**效用感知排序**检索对当前任务真正有用的经验。同时训练一个轻量级**检索协作者**（Copilot）来预测图扩散深度和相似性-效用权衡，使用下游任务性能作为奖励信号进行优化。执行器 LLM 始终保持冻结。

|------|------|
| **经验图构建** | 每个轨迹 τ = (x, ξ, y, s) 被总结为自然语言经验 e = Summarize(τ)；高得分轨迹提炼为技能，低得分提炼为教训。每个节点 v = (e_v, h_v, u_v, n_v)，含文本、嵌入、效用估计、检索计数。新节点与 Top-K 近邻（余弦相似度 ≥ θ）连边构建稀疏图。 |
| **语义种子** | 对当前任务 x，取余弦相似度最高的 m 个节点作为种子集 S₀。 |
| **图扩散** | 利用个性化 PageRank 从种子集扩散，重启概率 α(ρ) 由协作者输出的扩散深度 R（ρ = R/100）控制：ρ 大则扩散范围小，ρ 小则扩散更广。 |
| **效用感知排名** | 对扩散后的候选集，计算 UCB 置信度分数 b_v = u_v + c√(log(N+1)/n_v)，最终排名分数 score(v|x) = (1-λ)sim̄ + λb̄，其中 λ 由协作者输出的 W（λ = W/100）控制。 Top-K 选定经验 E_{R,W}(x) 送入冻结执行器。 |
| **检索协作者** | 轻量级模型（Qwen2.5-3B）输出两个离散变量 (R, W) ∈ [0,100]。通过 PPO 优化，奖励 r = (s_with - s_without) + η·s_with，即边际收益 + 绝对质量正则化。 |
| **图演化** | 根据奖励在线更新被检索节点的 n_v 和 u_v（指数移动平均，β=0.1）；将新轨迹总结为经验节点插入图（去重、按容量阈值 2000 剪枝）。 |

### 算法流程（文字说明）
1. 采样任务 x，协作者预测 (R, W)。
2. 在图上语义种子选取 → 图扩散 → 效用感知排序得到 E_{R,W}。
3. 冻结执行器分别用带经验和不带经验两种方式执行任务，得到 s_with 和 s_without。
4. 计算奖励 r，使用 PPO 更新协作者。
5. 更新被检索节点的统计量，将新经验插入图。

## 3. 实验设计

### 数据集 / 场景
- **ExpSuite-Static（单轮）**：
  - 问答：ARC-C, CommonsenseQA, GPQA, MMLU, OBQA
  - 数学推理：GSM8K, GSM-Symbolic, MATH
  - 代码生成：HumanEval+, MBPP+
- **ExpSuite-Agentic（多步交互）**：
  - ALFWorld（Seen/Unseen 拆分，SR & #Steps）
  - AppWorld（Test-Normal/Test-Challenge 拆分，PR & #Steps）

### 基准（Baselines）
- **No-Memory**：直接使用冻结执行器，无外部经验。
- **检索中心方法**：ReasoningBank, ExpeL, LightMem, Mem0, AWM, MemRL。
- **LLM中心方法**：IRCoT, Search-o1, S3。
- **提示中心方法（仅Agentic）**：ReAct, Reflexion。
- 所有基于经验的方法使用相同数量经验，确保公平比较。

### 执行器
- **Static**：小执行器 Llama-3.2-3B-Instruct，大执行器 Llama-3.1-8B-Instruct。
- **Agentic**：小执行器 Qwen3-32B，大执行器 Gemini-3.1-Flash-Lite。

### 评估指标
- 静态任务：准确率、精确匹配、Pass@1
- Agentic：成功率/通过率、平均交互步数

- **框架**：PPO 训练使用 verl 分布式 RL 框架 + FSDP；推理使用 vLLM。
- **训练时间**：

- **代码将开源**：https://github.com/ulab-uiuc/ExpGraph

## 5. 实验数量与充分性

### 实验数量
- **静态任务**：10 个数据集，两种执行器，11 个基线方法（含 No-Memory 共 12 个），每组实验报告平均值和分项结果。
- **Agentic 环境**：4 个子任务（ALF-Seen/Unseen, AppWorld-Test-N/C），两种执行器，11 个基线方法。
- **迁移实验**：3 种设置（小→大、大→小、非推理→推理），4 个迁移变体（仅图、仅协作者、两者、完全 ExpGraph）。
- **消融实验**：4 个变体（无相似性过滤、平面记忆、无图扩散、无效用排名）在 5 个域上比较。
- **案例研究**：附录 H 提供了多个典型案例。

### 充分性与公平性
- **充分**：覆盖多种任务类型、执行器规模、交互模式，消融和迁移实验全面。
- **公平**：所有基于经验的方法使用相同数量经验；对比基线涵盖主流的检索中心、LLM 中心及无记忆方法；执行器冻结，只有协作者和图可训练。

## 6. 主要结论与发现

1. **整体性能最优**：ExpGraph 在所有设置中均取得最好平均分。静态任务提升 12.2%（小执行器）和 4.7%（大执行器）；Agentic 提升 21.4% 和 12.7%，交互步数减少 12.7% 和 21.6%。
2. **经验重用对弱执行器更有效**：小执行器相对增益更大（12.2% vs 4.7%；21.4% vs 12.7%），表明外部经验可弥补内部分推理能力不足。
3. **Agentic 场景增益更大**：多步决策中经验指导作用更突出，减少冗余探索。
4. **跨执行器迁移有效**：小→大转移几乎无性能损失；大→小虽难但仍有效；非推理→推理转移表现接近专用 ExpGraph，说明经验图编码了可泛化的知识。
5. **每个组件都必要**：消融实验表明图结构、图扩散、效用排名、相似性过滤均贡献显著，去掉任一都会导致性能下降。

## 7. 优点（方法与实验亮点）

- **模型无关性**：执行器完全冻结，无需访问参数或梯度，兼容闭源、不可微的模型。
- **图结构经验组织**：天然表达经验之间的关系，利用图扩散发现非直接相似但相关的经验（如共享子目标、失败模式）。
- **效用感知检索**：结合历史效用（含 UCB 探索）和语义相似度，避免仅依赖表面相似性。
- **自适应检索协作者**：通过强化学习从下游任务反馈中学习何时扩散远、何时信任效用，任务自适应性强。
- **联合演化**：协作者图同时学习，经验图在线更新，形成持续改善闭环。
- **实验充分且系统**：涵盖静态/动态、小/大执行器、多个消融和迁移设置，结果可靠。

## 8. 不足与局限

- **实验覆盖有限**：虽涉及 14 个基准，但未覆盖更长时域的 real-world 应用，如网页浏览、科学发现、多智能体协作等。
- **图构建超参固化**：邻居大小 (K=5)、相似度阈值 (θ=0.3)、容量 (2000)、更新率 (β=0.1) 等均为固定值，未探索自适应策略，可能在不同分布下不够鲁棒。
- **奖励信号粗粒度**：当前使用标量任务得分作为反馈，缺失中间过程信用分配；引入过程级奖励（如里程碑）或可提升学习效率。
- **经验利用方式局限**：仅通过提示注入经验，但提示与模型行为间可能存在不一致（参见 [12,13,47]），更强的耦合方式（如基于经验微调或蒸馏）未被采用。
- **潜在偏差风险**：经验图依赖于历史轨迹的好坏与多样性，若初始冷启动数据有偏可能导致检索偏好固化；实验未详细分析经验分布对公平性的影响。
- **复现门槛**：依赖特定环境配置（NVIDIA A6000、vLLM、NIM API），小规模研究可能难以完全复现。
