## 摘要
智能LLM必须持续判断新提取的事实是否应被添加、与现有记忆合并或被忽略，然而先前的工作更关注检索与存储，而非原则性的写入侧控制。我们将记忆演化构建为一个新颖性检测问题，并提出SAGE（Spherical Adaptive Gate for memory Evolution），一种用于记忆演化的球面自适应门控，它通过基于von Mises-Fisher的密度估计器对记忆嵌入上的候选事实进行评分，并利用一个跟踪记忆存储几何结构的自适应阈值进行路由。SAGE将明确的新颖事实解析为ADD，明确的冗余事实解析为NOOP，仅将不确定情况送入LLM合并步骤，从而减少昂贵的写入时推理。在LoCoMo上，SAGE在所有七种开放权重骨干网对比中，相比Mem0取得了最佳平均token-F1；而在GPT-4o-mini上，它减少了3.4倍的添加阶段API成本以及2.5倍的添加阶段延迟，仅产生很小的平均评估分数差距。作为A-Mem的即插即用二元门控，SAGE在五个模型中跳过了大约16-18%的LLM调用，且在开放权重骨干网上质量变化极小。这些结果表明，新颖性感知的写入控制是提升长期智能记忆系统记忆质量与系统效率的实用杠杆。

## Abstract
Agentic LLMs must continuously decide whether newly extracted facts should be added, merged with existing memories, or ignored, yet prior work has focused more on retrieval and storage than on principled write-side control. We frame memory evolution as a novelty-detection problem and propose SAGE, a Spherical Adaptive Gate for memory Evolution that scores candidate facts with a von Mises-Fisher-based density estimator over memory embeddings and routes them with an adaptive threshold that tracks memory-store geometry. SAGE resolves clearly novel facts as ADD, clearly redundant facts as NOOP, and sends only uncertain cases to an LLM merge step, reducing expensive write-time reasoning. On LoCoMo, SAGE achieves the best average token-F1 against Mem0 on all seven open-weight backbone comparisons, while on GPT-4o-mini it reduces add-phase API cost by 3.4$\times$ and add-phase latency by 2.5$\times$ with only a small average judge-score gap. As a drop-in binary gate for A-Mem, SAGE skips roughly 16-18% of LLM calls across five models with minimal quality change on open-weight backbones. These results suggest that novelty-aware write control is a practical lever for improving both memory quality and system efficiency in long-term agentic memory.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：现有智能体LLM记忆系统在写入侧（write-side）缺乏原则性控制，难以高效决定新提取的事实应添加、合并还是忽略。先前工作多聚焦于检索和存储（如嵌入模型、向量索引、混合检索），而对写入决策本身关注不足。
- **背景**：长期记忆系统（如Mem0、A-Mem）通常依赖LLM做每批次事实的路由决策，导致写路径成为主要成本来源。同时，冗余写入会污染记忆，合并错误会破坏事实准确性。作者提出将记忆演化形式化为**新颖性检测问题**，通过轻量门控避免不必要的LLM推理，降低系统成本并提升记忆质量。

## 2. 方法论：核心思想、关键技术细节、算法流程

- **核心思想**：利用von Mises-Fisher (vMF) 分布构建球面核密度估计，对候选事实的新颖性进行评分，通过自适应阈值将明确新颖、明确冗余和不确定的情况分开，仅不确定案例触发LLM合并调用。
- **关键技术细节**：
  - **记忆表示**：存储的记忆和候选事实均通过句子嵌入并ℓ2归一化到单位超球面S<sup>d-1</sup>。
  - **新颖性评分**：对候选嵌入 **c**，计算vMF核密度估计 ˆS(c|M)=(1/N)∑exp(κ **m**<sub>i</sub><sup>⊤</sup>**c**)，然后使用 `s_vMF(c|M) = (1/κ) log ˆS`，最终新颖性得分 ν(c) = (1 - s_vMF)/2，值越大表示越新颖。
  - **自适应阈值**：根据记忆集密度 ρ<sub>t</sub>（通过PCA降维后的体积与数量计算）动态调整阈值 τ<sub>t</sub><sup> *</sup> = τ<sub>min</sub> + τ<sub>0</sub> e<sup>-λρ<sub>t</sub></sup>，并经EMA平滑得到 τ<sub>t</sub>。
  - **路由规则**：
    - ν(c) ≥ τ<sub>t</sub> + δ → **ADD**（无LLM）
    - τ<sub>t</sub> ≤ ν(c) < τ<sub>t</sub> + δ → **UPDATE**（触发LLM合并）
    - ν(c) < τ<sub>t</sub> → **NOOP**（无LLM）
  - **扩展为二元门控**：固定阈值 τ<sub>noop</sub>，若 s_vMF > τ<sub>noop</sub> 则跳过，否则传递至宿主系统（如A-Mem）进行全量处理。

## 8. 不足与局限

1. **场景覆盖有限**：仅在LoCoMo英语多会话对话上评估，未测试更复杂的LongMemEval、多语言、工具使用或任务导向型agent设置。
