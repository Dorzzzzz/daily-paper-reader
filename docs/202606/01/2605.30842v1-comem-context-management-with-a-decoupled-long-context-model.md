## 摘要
情境管理使代理模型能够通过对先前交互历史的迭代总结来解决长期任务。然而，这一过程通常会因额外的总结标记而产生大量解码开销，显著影响部署时的端到端响应延迟。在本文中，我们引入CoMem，一种新颖的框架，将记忆管理与主代理工作流解耦，使这些过程能够并行执行。我们提出了一种$k$步异部流水线，将记忆模型的总结与代理的推理重叠，有效掩盖上下文处理的延迟。为确保这种异步设置下的鲁棒性，我们引入了一种奖励驱动的训练策略，使记忆模型能够为代理的决策捕获足够的统计信息。理论分析证实，与耦合架构相比，CoMem提供了更优的效率-效果权衡。我们在SWE-Bench-Verified上的大量实验结果表明，CoMem在保留大部分性能的同时，相比普通的長上下文解决方案实现了1.4倍的延迟改进。此外，我们证明这些延迟增益随着系统吞吐量的增加而有利地扩展，为代理推理和记忆压缩的独立优化提供了一条模块化路径。

## Abstract
Context management enables agentic models to solve long-horizon tasks through iterative summarization of previous interaction histories. However, this process typically incurs substantial decoding overhead for the extra summarization tokens, which significantly affect the end-to-end response latency at deployment. In this paper, we introduce CoMem, a novel framework that decouples memory management from the primary agent workflow, enabling these processes to execute in parallel. We propose a $k$-step-off asynchronous pipeline that overlaps the memory model's summarization with the agent's inference, effectively masking the latency of context processing. To ensure robustness under this asynchronous setting, we introduce a reward-driven training strategy that aligns the memory model to capture sufficient statistics for the agent's decision-making. Theoretical analysis confirms that CoMem offers a superior efficiency-effectiveness trade-off compared to coupled architectures. Our extensive experimental results on SWE-Bench-Verified show that CoMem provides 1.4x latency improvements upon vanilla long-context solutions while preserving most of the performance. Furthermore, we demonstrate that these latency gains scale favorably with increased system throughput, offering a modular path forward for the independent optimization of agent reasoning and memory compression.

## 1. 核心问题与整体含义（研究动机和背景）
- **问题**：当前基于大语言模型（LLM）的自主代理（agent）在执行长周期任务时，需要维护、迭代压缩大量交互历史。然而，在推理阶段，对历史进行压缩产生的额外解码token带来了严重的内存带宽瓶颈和计算开销，导致端到端响应延迟显著增加，制约了实时部署。
- **背景**：已有方法包括滑动窗口（丢失远距离依赖）、检索增强生成（依赖语义相似性，难以捕获过程轨迹）、以及系统级优化（如vLLM、稀疏注意力、KV缓存量化），但这些方法本质上都未能解决“对大量静态历史反复解码”的冗余问题。当交互历史无限增长时，延迟墙依然存在。
- **整体含义**：论文旨在提出一种**解耦记忆管理与代理推理**的新框架，通过将长上下文压缩任务外包给一个轻量级、专用的记忆模型，并采用异步流水线隐藏其延迟，从而实现**兼具长上下文推理能力与低延迟推理**的效果。

## 2. 方法论：核心思想、关键技术细节、公式/算法流程
### 核心思想
- **解耦架构**：将上下文管理职责从主代理模型（大型，负责决策）中分离，交由一个更小的记忆模型处理。记忆模型负责将长历史压缩为简短的摘要状态，代理模型仅需处理该摘要+最近几步的原始缓冲区，大幅减少解码时的KV缓存加载量。
- **异步重叠**：提出**k-step-off 异步流水线**，允许记忆模型在后台进行压缩，代理继续执行若干步，从而将压缩延迟掩盖在代理推理时间之内。
- **奖励驱动对齐训练**：为了使压缩摘要真正对代理决策有帮助，训练记忆模型使其输出能够诱导代理产生与全上下文相同的动作（功能等价），而非简单的文本相似度。

### 关键技术细节
1. **记忆模型**：选择较小参数量、具备长上下文能力的基础模型（如 Qwen3-4B）。它输出固定最大长度（如 2048 tokens）的摘要。
2. **代理模型**：保持冻结，在推理时输入 `summary + recent buffer` 进行解码。
3. **k-step-off流水线**：
   - 每 k 步为一个周期。周期开始时，异步启动记忆模型压缩全历史前半段（`τ_{≤t-k}`）。代理继续执行接下来的 k-1 步，使用缓存前缀（仅增量 prefilling 新观测）。当记忆模型完成后，下一个周期开始，代理需要进行一次全量 uncached prefill（因为摘要更新）。
   - 形式化：`a_t ~ π(a | f(τ_{≤t-k}), τ_{t-k+1:t})`。
   - 参数 k 控制新鲜度与摊销预填充成本的权衡。
4. **训练方法**：
   - 使用 GRPO（Group Relative Policy Optimization）训练记忆模型。
   - 奖励函数：给定候选摘要 s，冻结代理输出动作 `â_t`，与全上下文下的真实动作 `a*_t` 计算余弦相似度作为奖励 `R(s)=sim(â_t, a*_t)`。
   - 同时限制摘要最大长度，激励模型抛弃无关细节。
5. **理论分析**：给出确定可接受压缩率的上界公式 `L_sum / L_full < 1/(1 + (W·Y)/(S·P))`，示例中 `Y=1000, W=2TB/s, P=3000tok/s, S=2×10⁻⁴ GB` 得到压缩率需 <0.23（即 32K 上下文应压缩至 ≤7.36K）。

### 算法流程（文字说明）
```
初始化：s=∅, t=1
每步循环：
  若当前步是 k 的倍数：
    异步启动记忆模型压缩全部历史 τ_{≤t}
    此时保留最近可用的摘要 s
  代理推理：
    如果 KV 缓存有效（不是新周期开始）：仅 prefill 新观测
    否则：prefill 完整输入 [s, τ_{t-k+1:t}]
    解码输出动作 a_t
  执行动作，获取新观测，更新历史
  若上一轮异步压缩完成，更新 s 并令 KV 缓存失效（下一周期开始）。
```

## 6. 主要结论与发现
1. **效率提升显著**：CoMem 在 SWE-Bench-Verified 上实现 **1.4× ~ 2.08×** 端到端加速，且在高并发下加速比更高（batch=256 时 2.52×）。
2. **性能损失可控**：在大型骨干（GLM-4.7）上，CoMem（GRPO）解决率 62.7% 接近全上下文 69.0%，优于通用摘要模型（base 58.3%、SFT 61.3%）和 No Summary（59.4%）。
3. **训练方法有效**：基于动作一致性的 GRPO 训练显著优于普通微调；跨骨干迁移损失仅 0.8%，说明学到的压缩策略具有泛化性。
4. **k 值稳健**：k ∈ {2,4,8} 时性能稳定，过大或过小会引入延迟或性能下降。
5. **可扩展性**：单个 4B 记忆模型可服务约 300 个并发代理实例，额外架构代价可忽略。
