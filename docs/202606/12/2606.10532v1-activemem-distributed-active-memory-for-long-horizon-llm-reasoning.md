## 摘要
记忆对于使大型语言模型（LLM）智能体能够处理长程推理任务至关重要。现有的记忆机制大多是集中式的，通常将检索到的信息和交互历史组织在单个模型上下文中。这种设计引入了一个基本权衡：扩展推理轨迹可能导致上下文过载，而激进的内容剪枝则可能造成不可逆的信息丢失。为了寻求更好的权衡，我们从人类认知系统中汲取灵感，尤其是前额叶皮层（执行控制）和海马体（记忆管理）之间的功能互补性，表明这种权衡并非固有，而可能源于集中式的记忆组织。为此，我们提出ActiveMem，一种将智能体记忆与核心推理过程解耦的异构框架。具体来说，一个高层规划器利用提炼的语义要点来执行推理，而一个轻量级的分布式记忆系统并行运行，在整个任务中主动积累和整合这些要点。在BrowseComp-Plus和GAIA上的实验表明，ActiveMem在显著降低开销的同时实现了最先进的准确率，证明了分布式主动记忆在长程推理中的有效性。

## Abstract
Memory is essential for enabling large language model (LLM) agents to handle long-horizon reasoning tasks. Existing memory mechanisms are largely centralized, typically organizing retrieved information and interaction history within a single model context. This design imposes a fundamental trade-off: scaling reasoning trajectories risks context overload, whereas aggressive content pruning may result in irreversible information loss. Seeking a better trade-off, we draw inspiration from human cognitive systems, especially the functional complementarity between the prefrontal cortex (executive control) and the hippocampus (memory management), suggesting that such a trade-off need not be inherent, but may instead stem from centralized memory organization. To this end, we propose ActiveMem, a heterogeneous framework that decouples agent memory from the core reasoning process. Specifically, a high-level Planner utilizes distilled semantic gists to execute reasoning, while a lightweight, distributed memory system operates in parallel to actively accumulate and consolidate these gists throughout the task. Experiments on BrowseComp-Plus and GAIA show that ActiveMem achieves state-of-the-art accuracy with significantly reduced overhead, demonstrating the effectiveness of distributed active memory for long-horizon reasoning.

# ActiveMem：面向长程LLM推理的分布式主动记忆 - 详细总结

## 1. 核心问题与研究动机
- **核心问题**：现有LLM智能体在长程推理中常采用集中式记忆架构，即将所有检索文档、中间推理轨迹都堆积在同一模型上下文中，导致**上下文过载**（context overload）和**“丢失在中间”**现象（lost-in-the-middle）。为缓解该问题，现有方法对上下文进行压缩或截断，但这又会造成**不可逆的信息丢失**，因为被丢弃的原始文档细节在后续推理中无法恢复。
- **研究动机**：受人类认知系统启发——前额叶皮层负责执行控制，海马体负责记忆管理，二者功能互补：海马体会将详细的情节记忆转化为结构化的语义摘要，而前额叶皮层通过发出执行信号来引导检索。这表明**记忆与推理在结构中解耦**可以避免集中式架构的内在矛盾。因此，提出ActiveMem，将记忆管理从核心推理中分离，实现更高效的长程推理。

## 2. 方法论：核心思想与技术细节
### 核心思想
- **解耦记忆与推理**：将系统分为两个主要模块：
  - **Planner（规划器）**：负责高层推理和生成检索查询，只维护一个紧凑的推理上下文（包含原始问题、最近K步交互历史、上一步返回的蒸馏语义摘要）。
  - **分布式记忆系统**：包含三个组件——Memorizers、Memory Shards、Operator，负责并行处理文档、持久存储和主动整合摘要。
### 关键技术细节
1. **Planner**  
   - 输入状态 $s_t = (x, h_t, m_{t-1})$，其中 $x$ 为原始问题，$h_t$ 为经过裁剪（Trim）保留最近K步的交互历史，$m_{t-1}$ 为上一步返回的蒸馏摘要。  
   - 在每个推理步，Planner生成一组检索查询 $Q_t = \pi(s_t)$，每个查询包含检索词 $q_i$ 和预算 $k_i$（请求的文档数量）。  
   - 如果Planner决定提交答案，则调用 `submit_answer(a)` 终止推理。

2. **分布式记忆系统**
   - **Memory Shards（记忆分片）**：固定数量的逻辑分片（实验中为16个），每个分片 $B_j$ 是一个键值存储，以文档ID为键，存储<蒸馏摘要 $g_c$，查询历史 $H_c$>。持久存储，不丢弃任何信息。
   - **Memorizers**：轻量级模型（实验中为4B参数量），给定查询 $q$ 和文档内容 $c$，输出与该查询相关的简洁摘要 $g_c = \omega(c, q)$（若内容相关输出摘要，否则输出None）。多个Memorizer可并行处理不同文档。  
     - **训练数据构建**：从BrowseComp-Plus的训练集中收集12,000个查询-文档对，使用GPT等价模型（gpt-oss-120b）作为教师生成摘要，然后使用条件下一个词预测损失（公式(5)）微调Memorizer。
   - **Operator**：负责协调路由、判断记忆复用、以及异步整合。  
     - **记忆复用**：判断新查询是否与文档的查询历史 $H_c$ 语义相似（`J(q, H_c)` 输出 SIMILAR 或 NEW）。若相似，直接返回已有摘要，避免再次调用Memorizer；若为新查询，则派发给Memorizer生成新摘要，并异步整合到分片中。  
     - **异步整合**：当同一文档从多个角度被蒸馏时，合并新旧摘要，消除冗余，同时保留所有实体信息。

3. **推理流程**（算法1）  
   初始化分片和历史 → 每步Planner生成查询 → 检索文档 → Operator路由到对应分片 → 并行处理（最多N个并发）→ 对未见过文档：蒸馏写入；对已见且查询相似：复用摘要；对已见但查询新：蒸馏并异步整合 → 将收集的摘要组装为观察 → 裁剪历史（保留最近K步）→ 循环直到提交答案。

## 3. 实验设计
### 数据集与基准
- **BrowseComp-Plus**：主要评测，包含150个问题（Easy/Medium/Hard三档），由Context-Folding论文引入，用于细粒度分析。
- **GAIA**：通用智能体基准，使用其WebSearch验证子集（106个例子），专注于信息密集型检索任务。

### 对比方法
- **Vanilla ReAct LLMs**：Kimi-K2.5、Qwen3.5-397B-A17B、GLM-5.1、DeepSeek-V3.2，均采用标准ReAct循环，无内存压缩，带两级页面阅读机制。
- **集中式记忆智能体**：Context-Folding、AgentFold、MemoBrain、MemAgent。所有方法统一使用Qwen3.5-397B-A17B作为骨干，以保证公平。

### 评价指标
- **LasJ（LLM-as-a-Judge）**：使用Qwen3.5-397B-A17B作为裁判判断答案正确性。
- **PFLOPs**：衡量推理计算开销，包含线性FLOPs和自注意力FLOPs，考虑模型规模和注意力架构差异。
- **ACT（Accuracy-Cost Trade-off）**：复合指标，$ACT = LasJ - \alpha \cdot CostNorm$，其中成本归一化采用对数尺度，$\alpha=0.05$，以区分不同方法的效率。

## 6. 主要结论与发现
- ActiveMem在**BrowseComp-Plus**上取得最高LasJ（0.79）和最高ACT（0.785），在**GAIA**上也获得最好LasJ（0.62）和最低PFLOPs。
