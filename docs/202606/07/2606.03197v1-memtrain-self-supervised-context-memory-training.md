## 摘要
记忆是长周期LLM智能体不可或缺的能力，使其能够保留并利用在扩展交互中积累的信息。现有的记忆智能体方法通常通过强化学习在下游任务上进行端到端训练。然而，为记忆密集型场景收集高质量标注问题成本高昂，且由此产生的训练数据往往缺乏足够的多样性来覆盖通用的记忆行为。在这项工作中，我们提出MemTrain，一种自监督训练框架，旨在普遍增强LLM智能体的上下文记忆能力，以实现更有效的下游后训练。MemTrain在无标签的维基百科语料库上引入了两个耦合的代理任务：（1）端到端掩码重构目标，要求模型在多次记忆更新后恢复被掩码的实体，从而从最终结果角度鼓励记忆维持；（2）中间记忆回忆目标，要求模型利用中间记忆状态重构被掩码的历史信息，鼓励在交互过程中进行忠实压缩并保持记忆完整性。这两个目标通过GRPO进行联合优化。在长文本问答和基于搜索的问答基准上的大量实验表明，MemTrain在不同模型上持续提升下游记忆密集型推理性能，与直接针对特定任务的后训练相比，最高可获得17.67个百分点的提升。

## Abstract
Memory is an indispensable capability for long-horizon LLM agents, enabling them to preserve and utilize information accumulated across extended interactions. Existing memory-agent approaches are typically trained end-to-end with reinforcement learning on downstream tasks. However, collecting high-quality annotated problems for memory-intensive scenarios is costly, and the resulting training data often lack sufficient diversity to cover general memory behaviors. In this work, we propose MemTrain, a self-supervised training framework for generally enhancing the context-memory capability of LLM agents for more effective downstream post-training. MemTrain introduces two coupled proxy tasks over unlabeled Wikipedia corpora: (1) an end-to-end masked reconstruction objective, which requires the model to recover masked entities after multiple rounds of memory updates, thereby encouraging memory maintenance from the final outcome perspective; and (2) an intermediate memory recall objective, which requires the model to reconstruct masked historical information using intermediate memory states, encouraging faithful compression and memory completeness throughout the interaction process. The two objectives are jointly optimized using GRPO. Extensive experiments on long-text QA and search-based QA benchmarks demonstrate that MemTrain consistently improves downstream memory-intensive reasoning performance across different models, achieving gains of up to 17.67 points over direct task-specific post-training.

- **意义**：为提升LLM代理的通用上下文记忆能力、降低对昂贵标注数据的依赖，亟需一种**自监督**训练范式，能在无标注互联网语料上大规模预训练记忆相关行为。

## 2. 方法论

### 核心思想
提出 **MemTrain** 框架，在无标注的 **Wikipedia** 语料上构建**两个耦合的代理任务**，并通过 **GRPO** 算法联合优化，从而在记忆生成和利用的各个阶段提供监督信号。

### 关键技术细节

1. **上下文记忆智能体设定**  
   - 在每个交互步骤 \(t\)，模型接收元组 \((m_{t-1}, a_{t-1}, i_t)\)，其中 \(m_{t-1}\) 是固定长度的记忆状态，\(a_{t-1}\) 是上一动作，\(i_t\) 是环境反馈。模型输出更新后的记忆 \(m_t\) 和当前动作 \(a_t\)。
   - 相比无限拼接历史，该方法保持恒定上下文窗口。

2. **代理任务一：端到端掩码重构（End-to-End Masked Reconstruction）**  
   - 从 Wikipedia 中选取一个**枢轴段落**，将其中的一个实体（如数字、地名）替换为 `[MASK]`，并连同其他相关段落拼接成**长文档**。
   - 将长文档分块（chunk），模型通过多轮交互逐块阅读并更新记忆，最终仅基于记忆生成被掩码实体的预测。
   - 奖励为最终预测的**精确匹配**（Exact Match）。

3. **代理任务二：中间记忆召回（Intermediate Memory Recall, IMR）**  
   - 在生成一条完整轨迹后，**随机选择**一个中间步骤 \(k\)，并随机选择先前的一个块 \(c_l\)（\(l<k\)），将其中的实体替换为 `[TARGET]`。
   - 要求模型仅基于当前记忆状态 \(m_k\) 在**单次交互**中预测被掩码实体。
   - 奖励同样为精确匹配。

4. **联合优化（GRPO）**  
   - 对于每条训练样本（\(N\) 个段落 + 掩码实体 \(y\)），采样 \(G_1\) 条端到端轨迹，然后为每条轨迹再采样 \(G_2\) 条 IMR 轨迹。
   - **端到端奖励**为最终预测的正误加上 IMR 奖励的加权和（平衡系数 \(\lambda=0.5\)）。
   - 采用**未归一化优势** \(\hat{A}_{i,j,k} = R_i - \text{mean}(R_i)\)，并将轨迹级优势广播到所有步骤。
   - 使用 GRPO 损失函数（含 KL 散度正则化）联合优化所有步骤的 token 概率。

## 6. 主要结论与发现

1. **MemTrain 一致提升下游性能**：在长文本QA上，Qwen3-4B 提升 5.17 个百分点，Qwen2.5-7B 提升 **17.67** 个百分点；在搜索QA上分别提升 10.58 和 8.50 个百分点。
2. **长度泛化性强**：尽管训练上下文长度仅 32k~40k，但在 896k 上下文长度上仍保持较高准确率，下降幅度远小于直接后训练的 MemAgent。
3. **IMR 任务至关重要**：移除 IMR 分支后平均分下降 7 个百分点；解耦奖励在长上下文时退化明显。
4. **MemTrain 可单独提升能力**：仅 MemTrain 训练（无下游后训练）即可将模型从 21.97% 提升至 56.15%（Qwen3-4B），说明自监督训练直接赋予了一定的多轮记忆能力。
5. **优于扩展后训练**：MemTrain + MemAgent 超越持续后训练缩放 2.64 个百分点，表明其提升了性能天花板。

## 7. 优点

- **自监督**：完全基于无标注 Wikipedia 语料，极大降低数据收集成本。
- **双目标耦合设计**：端到端目标提供结果级监督，中间记忆召回提供过程级监督，联合优化促进记忆的忠实压缩与完整保持。
- **使用 GRPO 直接优化**：无需价值函数，简化训练流程，同时结合 KL 正则化防止策略偏离。
- **强泛化性**：不仅在掩码重建任务上有效，还迁移到完全不同的搜索问答场景，且能外推到远超训练长度的上下文。
- **实验充分、结果显著**：在多个模型、多种任务、消融分析中均取得大幅提升，且通过案例直观展示记忆更新差异。

## 8. 不足与局限

- **模型规模有限**：仅实验了 4B 和 7B 模型，未在更大规模（如 70B、170B）上验证，规模扩展后的有效性未知。
- **训练数据单一**：仅使用 Wikipedia，可能限制记忆行为在专业领域、多语言、对话等场景的泛化。
- **对记忆中间状态的评估不足**：仅通过掩码召回任务间接衡量中间记忆质量，未直接分析记忆内容的因果完整性与冗余。
- **缺乏对内存和计算开销的实际分析**：未讨论训练和推理时的显存占用、时间成本，以及相比全历史拼接的优势量化。

- **下游任务局限**：仅测试了阅读理解和搜索问答，未涵盖更复杂的智能体交互（如工具使用、多轮对话、规划等）。
