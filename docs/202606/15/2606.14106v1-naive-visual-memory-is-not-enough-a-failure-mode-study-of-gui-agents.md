## 摘要
图形用户界面（GUI）代理越来越多地被用于自动化跨应用、网站和操作系统的复杂计算机任务。为提高其可靠性，近期工作引入了经验记忆，即代理检索先前的轨迹以指导相似状态下的决策。更近期的方法进一步将这一思想扩展到视觉记忆，通过存储和检索过去交互中的截图，为代理提供比纯文本记忆更丰富的上下文信息。然而，视觉记忆在GUI代理中的作用仍未得到充分理解：尚不清楚视觉记忆减轻了哪些失败，或加剧了哪些失败。为系统分析视觉记忆的效果，我们引入了一个包含四种GUI代理失败（即认知失败、视觉状态误解、隐藏操作盲点和接地错误）的分类法，这些失败对应感知-推理-行动管道的不同阶段。我们发现，预置全图记忆对失败分布产生不同影响：它减少了状态级失败，但加剧了行动级失败，并增加了隐藏操作盲点和接地错误。受此发现启发，我们提出了行动接地视觉记忆（AGMem），一种用于GUI代理的行动接地记忆框架。AGMem的核心思想是存储与成功行动或恢复密切相关的局部GUI区域的图像裁剪，而非存储全截图。在OSWorld上的实验表明，AGMem相比全图记忆将任务成功率提高了33.3%。这些结果证明AGMem是GUI代理中视觉记忆的有效表示形式。

## Abstract
Graphical User Interface (GUI) agents are increasingly used to automate complex computer tasks across applications, websites, and operating systems. To improve their reliability, recent work has introduced experiential memory, where agents retrieve prior trajectories to guide decision-making in similar states. More recent approaches further extend this idea to visual memory by storing and retrieving screenshots from past interactions, providing agents with richer contextual information than text-only memories. However, the effect of visual memory in GUI agents remains insufficiently understood: it is unclear which failures visual memory mitigates, or which failures it exacerbates. To systematically analyze the effect of visual memory, we introduce a taxonomy of four GUI agent failures (i.e., cognitive failure, visual state misunderstanding, hidden operation blindness, and grounding error) that map to distinct stages of the perception-reasoning-action pipeline. We find that prepending full-image memory has a divergent effect on the failure distribution: it reduces state-level failures but worsens action-level ones, and increases hidden operation blindness and grounding error. Motivated by this finding, we propose Action-Grounded Visual Memory (AGMem), an action-grounded memory framework for GUI agents. The core idea of AGMem is to store image crops that capture the local GUI region closely related to a successful action or a recovery, rather than storing full screenshots. Experiments on OSWorld show that AGMem improves task success rates by 33.3 % over full-image memory. These results demonstrate that AGMem is an effective representation for visual memory in GUI agents.

## 2. 论文提出的方法论

### 2.1 核心思想

- 提出**四种失败模式**的分类法，对应感知-推理-行动管道的不同阶段：
  - **认知失败**（Cognitive Failure）：模型误解任务目标、当前子任务或成功条件。
  - **视觉状态误解**（Visual State Misunderstanding）：模型误读当前屏幕状态（如认为对话框已打开但实际上未打开）。
  - **隐藏操作盲点**（Hidden Operation Blindness）：正确操作需要先执行某个不可见操作（如打开菜单、使用快捷键）。
  - **接地错误**（Grounding Error）：模型意图正确但执行坐标或低级动作未命中目标。
- 发现**全图视觉记忆**带来分歧效应：减少状态级失败（认知失败、视觉状态误解），但加剧操作级失败（隐藏操作盲点、接地错误）。这促使设计更聚焦的记忆表示。

### 2.2 关键技术与算法流程

- **AGMem（Action-Grounded Visual Memory）** 框架：
  1. **行动接地视觉视图**（Action-grounded visual memory entries）：对于每个时间步t，利用连续截图(ot, ot+1)的像素差异检测变化区域，并裁剪出与执行动作at最相关的局部GUI区域（称为动作相关视图Ct）。存储时仅保留此裁剪图像，而非全截图。
  2. **恢复感知记忆检索**（Recovery-aware memory retrieval）：
     - **两阶段检索**：先进行轨迹级检索（基于句子Transformer比较子任务标签），再在选定轨迹中进行步骤级检索（基于CLIP编码器组合文本和图像嵌入，返回Top-5记忆步骤）。
     - **恢复记忆**：当错误状态检测器（LLM-based）发现错误时，定向检索恢复记忆库（存储了从错误状态恢复到正确状态的纠正示例），替换常规记忆检索。
  3. **记忆构建**：从AgentNet数据集自动提取非冗余正确轨迹，分割为子任务标签、动作、裁剪图组成的记忆单元。

### 2.3 算法流程说明（文字描述）

1. 对给定指令I，先分解为子任务列表s = (s1, s2, …, sp)。
2. 每步行动前，代理自报告当前子任务；轨迹检索器根据s从记忆库M中选出k条相关轨迹；步骤检索器根据当前状态（子任务+上一时间步的裁剪图）检索Top-5记忆步骤。
3. 若恢复检测器发现当前状态错误，则重定向到恢复记忆库，获取纠正示例。
4. 将记忆步骤（裁剪图+动作+子任务标签）拼接至提示，由VLM输出下一动作at。
5. 行动执行后，更新记忆存储（用于未来检索）。

## 6. 论文的主要结论与发现

1. **GUI代理存在四种可分类的失败模式**，分别对应感知-推理-行动管道的不同阶段，且不同基准的故障主导模式不同（OSWorld：认知失败和隐藏操作盲点；WebForge：接地错误；AgentNet：视觉状态误解）。
2. **全图视觉记忆具有分歧效应**：有效改善状态级失败（认知、视觉误解），但显著加剧操作级失败（隐藏操作盲点、接地错误），导致整体收益有限甚至为负。
3. **行动接地局部裁剪（AGMem）可以统一缓解所有失败模式**，相比全图记忆将任务成功率提升33.3%（相对值），且在所有四种失败率上均优于无记忆基线。
4. **恢复记忆**对于打断错误传播至关重要：当代理进入错误状态时，仅靠常规成功轨迹无法纠正，需要专门存储纠正示例。
