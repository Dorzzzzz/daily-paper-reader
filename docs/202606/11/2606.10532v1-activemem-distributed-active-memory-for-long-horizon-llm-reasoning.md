## 摘要
记忆对于让大语言模型（LLM）智能体处理长程推理任务至关重要。现有记忆机制大多采用集中式设计，通常将检索到的信息和交互历史组织在单一模型上下文内。这种设计带来一个根本性权衡：扩展推理轨迹可能导致上下文过载，而激进的剪枝则可能造成不可逆的信息丢失。为寻求更好的权衡，我们从人类认知系统中汲取灵感，特别是前额皮层（执行控制）与海马体（记忆管理）之间的功能互补性，表明这种权衡并非必然，而可能源于集中式记忆组织。为此，我们提出ActiveMem，一种将智能体记忆与核心推理过程解耦的异构框架。具体而言，高层规划器利用提炼后的语义要旨进行推理，而一个轻量级分布式记忆系统并行运行，在任务过程中主动积累并整合这些要旨。在BrowseComp-Plus和GAIA上的实验表明，ActiveMem以显著降低的开销实现了最先进的准确率，证明了分布式主动记忆在长程推理中的有效性。

## Abstract
Memory is essential for enabling large language model (LLM) agents to handle long-horizon reasoning tasks. Existing memory mechanisms are largely centralized, typically organizing retrieved information and interaction history within a single model context. This design imposes a fundamental trade-off: scaling reasoning trajectories risks context overload, whereas aggressive content pruning may result in irreversible information loss. Seeking a better trade-off, we draw inspiration from human cognitive systems, especially the functional complementarity between the prefrontal cortex (executive control) and the hippocampus (memory management), suggesting that such a trade-off need not be inherent, but may instead stem from centralized memory organization. To this end, we propose ActiveMem, a heterogeneous framework that decouples agent memory from the core reasoning process. Specifically, a high-level Planner utilizes distilled semantic gists to execute reasoning, while a lightweight, distributed memory system operates in parallel to actively accumulate and consolidate these gists throughout the task. Experiments on BrowseComp-Plus and GAIA show that ActiveMem achieves state-of-the-art accuracy with significantly reduced overhead, demonstrating the effectiveness of distributed active memory for long-horizon reasoning.

  - **信息不可逆丢失**：为控制上下文长度，现有方法通常采用丢弃或压缩（如step-level summary）策略，但这一步会造成永久的信息损失，后续推理无法恢复。

- **整体含义**：论文提出一种新的设计范式——将记忆系统从推理过程中解耦（decoupled memory-reasoning paradigm），从而实现更好的精度-效率权衡。这一思想对构建可扩展、高效的LLM智能体具有重要的理论和实践意义。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
- **ActiveMem**：一个异构框架，包含一个高层**规划器（Planner）**和一个**分布式记忆系统（Distributed Memory System）**。
- 规划器仅维护紧凑的推理上下文（含原问题、近期交互历史、上一步返回的语义要旨），负责生成检索查询和最终答案。
- 分布式记忆系统由**记忆分片（Memory Shards）**、**记忆器（Memorizers）**和**操作器（Operator）**组成，三者协作实现对检索文档的并行处理、语义要旨的提取、持久化存储、重复利用和异步整合，保持规划器上下文清洁且界限固定。

### 关键技术细节

1. **规划器（Planner）**：
   - 维护状态 \( s_t = (x, h_t, m_{t-1}) \)，其中 \( x \) 是原始问题，\( h_t \) 是修剪后的交互历史（仅保留最近K步），\( m_{t-1} \) 是上一步的语义要旨。
   - 每一步生成一组检索查询 \( Q_t = \pi(s_t) \)，每个查询附带检索数量预算 \( k_i \)。
   - 当收到记忆系统返回的语义要旨后，更新状态并决定下一步搜索或提交答案。

2. **分布式记忆系统**：
   - **记忆分片（Memory Shards）**：固定数量（文中N=16）的逻辑分片，每个分片是键-值存储，键是文档ID，值存储该文档的**语义要旨 \( g_c \)** 和**历史查询集合 \( H_c \)**。支持持久化、无冗余存储。
   - **记忆器（Memorizers）**：多个轻量级（4B参数）模型可并行执行。给定查询 \( q \) 和文档 \( c \)，输出语义要旨 \( g_c = \omega(c, q) \)。若文档不相关则输出∅。
     - **训练**：在BrowseComp-Plus训练集上运行完整流水线收集12,000个查询-文档对，使用gpt-oss-120b作为教师模型生成要旨，然后用这些三元组对记忆器进行监督微调（条件下一词预测损失）。
   - **操作器（Operator）**：负责路由和复用。
     - 对每个记忆任务，首先判断文档是否已在分片中。若未存在（memory miss），则调用记忆器蒸馏并写入；若已存在且当前查询与历史查询语义相似（`J(q, H_c)`判定为SIMILAR），则直接复用已有要旨（memory hit），跳过记忆器；若已存在但查询不同（NEW），则重新蒸馏并启动**异步合并**（consolidation），将新旧要旨合并为更丰富的单一要旨，消除冗余，不阻塞规划器。

3. **推理流程（Algorithm 1）**：
   - 初始化分片和历史。
   - 循环至多T步：规划器生成查询或提交答案；检索文档；操作器将文档路由到对应分片；最多N个记忆器并行处理（每个分片一个）；收集要旨形成观察 \( o_t \)；修剪历史至最近K步。
   - 关键设计：通过分片持久化和复用减少冗余计算，异步合并保持分片内要旨整洁。
