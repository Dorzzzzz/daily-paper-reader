## 摘要
现代大型语言模型智能体可以使用外部工具来帮助用户解决复杂任务。然而，对于需要从长期历史事件或之前的智能体-环境交互中学习的问题，LLM智能体需要使用记忆机制来存储和检索经验。尽管对话智能体存在复杂的记忆系统，但很少有研究实证检验如何通过过去的用户-智能体对话来提升智能体的工具使用能力。我们提出MemToolAgent，一个通过记忆管理来改进工具使用的框架。我们的方法包含一个记忆提取模块，将过去的经验处理为结构化的记忆条目；以及一个检索模块，动态选择存储记忆条目的子集。这使得无需LLM微调即可实现更个性化和更准确的响应，与用户偏好和反馈保持一致。总之，这项工作的三个主要贡献是：(1) 统一的记忆条目格式，无需LLM微调即可改进通用和个性化工具使用；(2) 基于反思的记忆提取，利用环境和用户反馈将错误执行提炼为要存储的批评；(3) 一个检索模块，根据记忆相似性分布选择使用多少过去的经验。与WorkBench、NESTFUL和PEToolBench基准上的强基线相比，MemToolAgent分别实现了29%、80%和17%的相对改进。

## Abstract
Modern large language model (LLM) agents can use external tools to help users solve complex tasks. However, for problems that require learning from long-term historical events or from previous agent-environment interactions, LLM agents are required to use memory mechanisms to store and retrieve experiences. While sophisticated memory systems exist for dialogue agents, few studies have empirically examined how to improve agents' tool-using capabilities through past user-agent conversations. We propose MemToolAgent, a framework that improves tool use through memory management. Our approach contains a memory extraction module that processes past experiences into structured memory entries, and a retrieval module that dynamically selects a subset of the stored memory entries. This enables more personalized and accurate responses aligned with user preferences and feedback without requiring LLM fine-tuning. In summary, this work has three main contributions: (1) a unified memory entry format that improves both general-purpose and personalized tool use without LLM fine-tuning, (2) a reflection-based memory extraction that uses environment and user feedback to distill wrong executions into critiques to store, and (3) a retrieval module that chooses how many past experiences to use based on the memory similarity distribution. MemToolAgent achieves 29%, 80%, and 17% relative improvements compared to strong baselines on the WorkBench, NESTFUL, and PEToolBench benchmarks, respectively.

## 2. 方法论

- **核心思想**：构建MemToolAgent框架，包含记忆提取模块和记忆检索模块。记忆提取模块将过去的执行经验（含用户反馈）加工为结构化记忆条目（查询、工具调用序列、二元反馈、反思/批评）；记忆检索模块基于语义相似性动态选择最相关的记忆条目作为上下文示例，辅助当前任务的工具调用。
- **关键技术细节**：
  - **统一记忆条目格式**：每个条目由四元组 `(q, a, f, r)` 组成，其中 `q` 为用户查询，`a` 为工具调用序列，`f` 为成功/失败反馈，`r` 为失败时的反思/批评。
  - **反射式记忆提取**：对失败执行，由LLM生成反思/批评，存储替代原始轨迹，减少干扰。
  - **动态“n”检索**：计算查询与所有记忆条目的余弦相似度，降序排列；基于滑动窗口估计一阶导数，利用峰值检测（SciPy的find_peaks）确定相似度突降位置，动态决定检索条目数n，避免固定k值带来的信息不足或冗余。
  - **硬偏好引导**（可选）：在个性化场景中，直接滤除历史中反馈为0的工具，作为低成本替代方案。
- **算法流程**（文字说明）：
  1. 输入当前查询q和记忆库M，计算q与每个记忆条目的余弦相似度S。
  2. 对S降序排序，并计算一阶导数估计（滑动窗口半径为R）。
  3. 使用find_peaks找到导数估计的峰值，根据预设的峰序号（通常为第一或第二峰值）确定n。
  4. 检索前n个记忆条目，连同其反馈和反思，作为上下文提示注入LLM，指导当前工具调用。
  5. 执行后，若用户反馈为失败，调用记忆提取模块生成反思并存入记忆库。

## 6. 主要结论与发现

- 在WorkBench整体准确率上，MemToolAgent达到85.06%，相对无记忆基线（57.56%）提升29%。
- 在NESTFUL上，完全序列匹配率从15.6%提升至30.4%（相对提升95%），胜率从51%提升至70.2%。
- 在PEToolBench上，工具准确率0.82，相对A-MEM/Mem0提升17%，参数准确率并列0.82。
- **动态检索优于固定k**：不同查询需要不同数量的记忆上下文，动态n方法显著优于任何固定k。
- **记忆提取模块至关重要**：反思/批评的引入比直接提供原始轨迹能更有效避免相似错误。
- **合成查询可缓解冷启动**：即使无真实历史数据，通过LLM生成合成查询也能提升性能。

## 7. 优点

- **创新性**：首次提出将环境与用户反馈相结合的反射式记忆提取，并引入基于相似度分布动态决定检索条目数的方法。
- **实用性**：无需LLM微调，直接利用闭源API即可部署，计算开销可控（输出token显著少于Extended Thinking和ReAct）。
- **泛化性**：统一记忆格式同时适用于通用和个人化任务，在三个差异显著的基准上均获得一致提升。
- **消融设计全面**：验证了动态检索、记忆提取、不同记忆类型、硬偏好引导等各个组件的作用。

## 8. 不足与局限

- **冷启动问题**：初始空记忆场景下性能受限，合成查询方法简单且部分领域（多域任务）效果不佳。
- **工具数量规模有限**：实验所用基准工具数均少于40，实际企业级场景可能成百上千，记忆覆盖和检索效率需进一步验证。
- **单轮交互限制**：所有基准为单轮任务，记忆仅在开头检索一次，不适用于多轮对话中动态更新需求。
- **反馈信号简单**：仅使用二元用户反馈，忽略了更丰富的文本或数值反馈的可能性（虽作者提到可扩展）。
- **超参数依赖**：动态检索中R、prominence、峰序号需手动调优，不同任务最佳参数各异，缺乏自适应机制。
- **单次运行缺乏统计检验**：结果无方差或置信区间，可能存在随机波动。
