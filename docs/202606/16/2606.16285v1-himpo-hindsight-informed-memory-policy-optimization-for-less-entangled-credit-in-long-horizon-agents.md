## 摘要
长时域智能体依赖记忆机制压缩交互历史，但优化记忆写入面临独特的信用分配挑战：一次记忆更新可能因下游工具故障、嘈杂观测或推理错误而非自身贡献而受到奖励或惩罚。这种因果纠缠的信用可能导致智能体丢弃有用证据或保留无关信息。我们提出HiMPO，一种后见知情记忆策略优化框架，用于在长时域智能体中对记忆写入动作进行低纠缠信用分配。HiMPO首先通过比较相同写前状态下从先前记忆和更新记忆中可恢复的任务相关信息，来估计记忆更新的局部效用；然后利用后见相关性作为有界的回顾性过滤器，当局部效用未得到目标结果支持时，削弱记忆信用。由此得到的记忆特异性优势仅应用于记忆令牌，而轨迹级奖励则优化智能体的其余行为。在基于评判者的开放领域任务和客观压缩记忆问答中，HiMPO在保持压缩上下文效率的同时，超越了基于强记忆和基于强化学习的基线方法。受控干预进一步表明，HiMPO减少了由工具引起的误差导致的责备泄漏，并提高了记忆更新的归因保真度。

## Abstract
Long-horizon agents rely on memory mechanisms to compress interaction history, but optimizing memory writing faces a distinct credit assignment challenge: a memory update may be rewarded or penalized due to downstream tool failures, noisy observations, or reasoning errors rather than its own contribution. This causally entangled credit can lead agents to discard useful evidence or preserve irrelevant information. We propose HiMPO, a Hindsight-Informed Memory Policy Optimization framework for assigning less-entangled credit to memory-writing actions in long-horizon agents. HiMPO first estimates the local utility of a memory update by comparing the task-relevant information recoverable from the previous and updated memories under the same pre-write state. It then uses hindsight relevance as a bounded retrospective filter that attenuates memory credit when local utility is not supported by the target outcome. The resulting memory-specific advantage is applied only to memory tokens, while trajectory-level rewards optimize the rest of the agent behavior. Across judge-based open-domain tasks and objective compressive-memory QA, HiMPO improves over strong memory-based and RL-based baselines while preserving compressed-context efficiency. Controlled interventions further show that HiMPO reduces blame leakage from tool-induced errors and improves attribution fidelity of memory updates.

- **问题**：长时域智能体（LLM agent）需要压缩交互历史来管理上下文长度，但记忆更新（memory write）的信用分配面临**因果混杂**：最终的成功/失败可能由下游工具错误、噪声观测或推理错误引起，而记忆更新却被错误地奖励或惩罚。这导致智能体可能丢弃有用证据或保留无关信息。
- **背景**：现有基于最终结果的RL方法（如MEMPO、SUPO）无法区分错误来源，记忆信用与工具/推理噪声纠缠。需要一种更加“解缠”的信用分配机制。

## 2. 方法论（HiMPO框架）

### 核心思想
为每个记忆更新构造一个**记忆特异性优势（memory-specific advantage）**，基于两个互补信号：
- **局部反事实效用（Local Counterfactual Utility）**：在相同写前状态下，比较更新后记忆与更新前记忆对目标任务信息可恢复性的增益。
- **后见相关性（Hindsight Relevance）**：衡量给定目标成功结果条件下，该记忆更新相对于同组兄弟写入的似然偏离程度。

通过**门控函数**将两者结合，当信号方向一致时才传递信用，避免混杂。

### 关键技术细节
1. **局部效用计算**：
   - 定义答案性得分 \(S(H_{i,t}, m, z^\star_i)\)：在写前状态 \(H_{i,t}\) 下，用记忆 \(m\) 替代原有记忆后，对目标结果 \(z^\star_i\) 的平均对数似然。
   - 效用差：\(\Delta_{i,t} = S(H_{i,t}, m_{i,t}, z^\star_i) - S(H_{i,t}, m_{i,t-1}, z^\star_i)\)。
   - 在组内按步骤标准化得到 \(\hat{\Delta}_{i,t}\)。

2. **后见相关性计算**：
   - 在条件（\(H_{i,t}\) 和 \(z^\star_i\)）下计算当前记忆令牌的平均对数似然 \(\log h_{i,t}\)。
   - 组内归一化：\(\log\rho_{i,t} = \log h_{i,t} - \text{mean}(\log h_{j,t})\)。

3. **门控函数**：
   - \(G(\hat{\Delta}_{i,t}, \log\rho_{i,t}) = \sigma(\beta_{\text{eff}} \cdot (\text{sgn}(\hat{\Delta}_{i,t}) \log\rho_{i,t} - \tau_\rho))\)。
   - 当局部效用与后见相关性方向一致时门控打开，否则抑制信用传递。

4. **稳定化机制**：
   - **成功轨迹保护**：若轨迹成功且记忆优势为负，则置零。
   - **后向平滑**：用指数移动平均（EMA, \(\alpha=0.5\)）将下游效用传播到早期记忆。

5. **令牌级优势**：
   - 只有 `<mem>` 令牌使用记忆特异性优势 \(A^M_{i,t}\)；其他令牌使用轨迹级优势 \(A^T_i\)。
   - 最后使用标准裁剪策略优化（如GRPO）。

### 算法流程
- 对每组N条轨迹，计算轨迹奖励和优势。
- 对每个记忆写入步骤，计算局部效用、后见相关性、门控记忆优势。
- 应用稳定化措施（掩码、平滑）。
- 将记忆优势散射到对应令牌，其余令牌用轨迹优势。
