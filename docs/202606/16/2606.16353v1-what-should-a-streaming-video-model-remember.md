## 摘要
流式视频理解模型必须在持续流中的任意时刻回答查询，仅使用到目前为止观察到的内容，并在固定的内存和计算预算下运行。现有方法通过添加记忆库、检索模块或视觉令牌压缩来保留长期历史信息。然而，强大的近期窗口基线表明，不加区分地注入历史信息可能会稀释当前场景的感知，这表明关键挑战不在于是否使用记忆，而在于如何选择性分配记忆。我们将此问题形式化为预算约束的在线潜在证据分配，并提出\textbf{SelectStream}，一种选择性潜在记忆框架，该框架保持当前观测直接可见于冻结的VLM，同时仅通过紧凑的、查询条件化的证据预算暴露历史信息。三个协调机制控制何时写入、保留什么以及如何检索：惊喜驱动的自适应窗口化、优先级保持的整合以及固定容量潜在记忆图上的查询条件化图推理。检索到的证据被校准并作为潜在令牌注入以生成答案，无需重放帧或随着流长度增长上下文。实验结果表明，SelectStream实现了强大的在线流式性能，同时保持了通用的视频理解能力，在StreamingBench上达到82.67％，在OVO-Bench上达到67.03％，在离线视频基准上平均准确率达到74.4％，并优于强大的近期窗口基线和先前的流式记忆方法。

## Abstract
Streaming video understanding models must answer queries at any moment during an ongoing stream, using only what they have observed so far and under fixed memory and computation budgets. Existing methods address this by adding memory banks, retrieval modules, or visual token compression to preserve long-range history. However, strong recent-window baselines show that indiscriminate history injection can dilute current-scene perception, suggesting that the key challenge is not whether to use memory, but how to allocate it selectively. We formulate this as budgeted online latent evidence allocation and propose \textbf{SelectStream}, a selective latent-memory framework that keeps the current observation directly visible to a frozen VLM while exposing historical information only through a compact, query-conditioned evidence budget. Three coordinated mechanisms govern when to write, what to preserve, and how to retrieve: surprise-driven adaptive windowing, priority-preserving consolidation, and query-conditioned graph reasoning over a fixed-capacity latent memory graph. Retrieved evidence is calibrated and injected as latent tokens for answer generation, without replaying frames or growing the context with stream length. Experimental results show that SelectStream achieves strong online streaming performance and preserves general video understanding, reaching 82.67\% on StreamingBench, 67.03\% on OVO-Bench, and 74.4\% average accuracy on offline video benchmarks, while outperforming strong recent-window baselines and prior streaming memory methods.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：流式视频理解要求在持续的视频流中，模型可以在任意时刻回答查询，且只能使用已观测的内容，并受限于固定的内存和计算预算。
- **矛盾**：现有方法通过添加记忆库、KV缓存检索、视觉令牌压缩等手段保留长期历史，但最近的“近期窗口基线”表明，不加区分地注入历史信息会稀释当前场景的感知，甚至比简单只保留最近帧的效果更差。
- **核心挑战**：不是要不要记忆，而是如何 **选择性分配记忆** ——决定何时写入、保留什么、如何检索以及暴露多少历史证据。
- **论文意义**：提出了一种**预算约束的在线潜在证据分配**视角，并实例化为SelectStream框架，平衡历史保留与当前感知。

## 2. 方法论

### 核心思想
- 将流式记忆形式化为**动态潜在证据图**（Dynamic Latent Evidence Graph），维持固定容量。当前观测直接喂入冻结的VLM，历史信息只通过紧凑的、查询条件化的证据预算暴露。
- 使用三个协调机制：**SAW（惊喜驱动自适应窗口化）**、**LVM（潜在视觉记忆）**、**GAR（图注意力推理）**。

### 关键技术细节
- **SAW（何时写入）**：
  - 计算每帧的惊喜分数（注意力偏移+特征变化），使用指数移动平均平滑。
  - 当分段达到最小长度且满足以下任一条件时关闭分段：惊喜峰值超过自适应阈值、累积惊喜能量超过预算、达到最大长度。
  - 闭合分段后，其投影视觉嵌入通过轻量Transformer编码为段向量。

- **LVM（保留什么）**：
  - 记忆节点存储潜在状态和元数据（时间跨度、惊喜、访问计数等）。
  - 新段与现有节点比较余弦相似度，若匹配且惊喜低则执行**门控更新**，否则创建新节点。
  - 当节点数超过预算N时，执行**优先级保留整合**：合并相似度最高且优先级最低（不惊喜、不常访问、不新鲜）的节点对，更新状态与元数据。

- **GAR（如何检索）**：
  - 查询经编码后，对所有活跃节点进行粗评分（语义兼容性+惊喜偏置-时间跨度惩罚-合并次数惩罚）。
  - 选择top-k种子，进行**查询条件化路由**扩展邻域（包括时序边和语义边），不超过子图预算B。
  - 在子图上执行**关系图注意力**（含边类型偏置、时间间隙惩罚、边支持偏置），K层后重新评分，选top-M节点。
  - 读取节点状态，通过校准投影层（LayerNorm+线性层）转换为潜在证据令牌，注入冻结VLM的输入。

- **训练目标**：仅训练SelectStream模块（段编码器、门控MLP、查询编码器、GAR、校准层），使用答案损失+检索损失（有标注时）+稀疏正则化（惩罚冗余证据）。

- **理论性质**：
  - 命题1：SAW分段数有界，经整合后活跃节点数≤N。
  - 命题2：检索到相关证据时，注意力集中下界与证据预算M相关，M越小则干扰越小。
