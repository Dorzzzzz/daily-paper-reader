## 摘要
LLM代理的长期记忆不仅仅是在正确的时间检索正确的段落。当前的记忆系统将信念修正、因果耦合和跨领域抽象压缩到一个为表面回忆调优的单一检索表面，因此难以处理需要推理用户如何演变的隐式个性化。我们提出了DCPM，它沿着认知能力层次重新组织代理记忆，从原始输入和原子事实开始，经过历时信念轨迹和身份，到领域模式、潜在意图和跨领域模式。该层次结构由两个继承双过程理论架构划分的过程驱动：一个同步的白天写入器（System1），记录信念修正为双向链接的取代链，以及一个异步的夜间引擎（System2），归纳模式和意图，并扫描跨领域冲突，将其抽象为更高级别的核心模式。在LongMemEval、PersonaMem和PersonaMem-v2上，启用System2在基准测试奖励隐式跨会话推理时贡献最大（在PersonaMem-v2上最多+5.20），在跨度回忆上贡献最小，与架构预测一致。

## Abstract
Long-term memory for an LLM agent is more than retrieving the right passage at the right time. Current memory systems collapse belief revision, causal coupling, and cross-domain abstraction into a single retrieval surface tuned for surface recall, and consequently struggle on implicit personalisation that requires reasoning over how a user has evolved. We propose DCPM, which reorganises agent memory along a cognitive capability hierarchy ascending from raw inputs and atomic facts, through diachronic belief trajectories and identity, to domain schemas, latent intentions and cross-domain patterns. The hierarchy is driven by two processes inheriting the architectural split of dual-process theory: a synchronous daytime writer (System1) that records belief revisions as doubly linked supersedes chains, and an asynchronous nighttime engine (System2) that induces schemas and intentions and sweeps for cross-domain collisions abstracted into higher-level core schemas. On LongMemEval, PersonaMem and PersonaMem-v2, enabling System2 contributes most where the benchmark rewards implicit cross-session inference (up to +5.20 on PersonaMem-v2) and least on span recall, matching the architectural prediction.

## 1. 核心问题与整体含义（研究动机和背景）

- **当前LLM agent记忆系统的局限**：现有系统将长期记忆简化为检索问题，仅存储表面内容（向量库、时序知识图谱等），缺乏对用户信念演化（belief revision）、因果耦合（causal coupling）以及跨领域抽象（cross-domain abstraction）的建模能力。因此，当需要隐式推理用户如何随时间变化时（如偏好转变、不同生活领域行为模式的关联），系统表现不佳。
- **根本原因**：论文将问题归因于“记忆即存储”（memory-as-storage）与“记忆即认知”（memory-as-cognition）的混淆，现有系统将所有需求压缩到单一的检索表面，丢失了中间状态、因果链接及高阶模式。
- **研究目标**：提出一种基于认知能力层次的组织方式，使LLM agent具备自我进化能力，实现从被动回忆到主动认知推理的跃迁。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 认知能力层次结构（Capability Hierarchy）
- **底层**：原始输入（raw inputs）和原子事实（atomic facts）——矢量存储，保证零损失。
- **中层**：稳定身份项（identity items）和历时信念轨迹（supersedes chains）——通过双向指针链接修订版本，形成信念演化链。
- **上层**：领域内行为模式（within-domain schemas）、潜在意图（latent intentions）和跨领域核心模式（cross-domain core schemas）——存储在独立的图结构G中。

### 2.2 双过程架构（Dual-Process Architecture）
- **System 1（同步白天写入器）**：
  - 触发方式：用户或应用显式调用 `add_memory`（非每个对话轮次）。
  - 步骤：
    1. **原始持久化**：将原始输入直接写入矢量存储（零损失）。
    2. **提取**：提取LLM `Me` 从当前轮次和短历史窗口中提取身份项和原子事实，标记类型、主题、显著性、时间戳。
    3. **调和（Reconcile）**：调和LLM `Mr` 对每个提取项与矢量存储中top-k近邻进行比对，决策：`ADD`（新）、`SUPERSEDE`（矛盾或演化）、`UPDATE`（补充）。重复项丢弃。
    4. **批量写入与取代链**：对`SUPERSEDE`项添加双向指针（`new.supersedes = old`, `old.superseded_by = new`），保留所有历史版本，形成双向链表。
  - **关键设计**：不删除前驱，支持读路径通过指针遍历整个演化弧，弥补嵌入相似度丢失的因果中间状态。

- **System 2（异步夜间引擎）**：
  - 运行时机：空闲或夜间，宽松延迟预算（数十秒）。
  - 三个阶段：
    - **阶段1（预处理，无LLM）**：事实分诊（筛选未纳入模式/意图的新事实）、两阶段DBSCAN聚类（初始ε=0.35，紧致ε=0.25，`min_samples=3`）、检索最近图上下文。
    - **阶段2（LLM代理归纳）**：为每个聚类调用归纳代理`Ma`，使用四个工具：`CREATE_SCHEMA`（创建领域内行为模式节点）、`CREATE_INTENTION`（创建潜在意图节点）、`ADD_EVIDENCE`（关联事实）、`ADD_EDGE`（添加图边）。图逐步增量演化。
    - **阶段3（跨领域扫描器）**：
      - 行为抽象：对每个模式节点，用LLM生成简短行为描述，编码到行为-认知空间`E_beh`和语义空间`E_sem`。
      - 碰撞扫描：计算跨领域模式对，当`cos(E_beh(si), E_beh(sj)) > θ_beh`且`cos(E_sem(si), E_sem(sj)) < θ_sem`（θ_beh=0.72, θ_sem=0.40）时标记碰撞。用并查集聚合冗余对。
      - 核心模式归纳：对每个碰撞簇，用LLM `Mc` 归纳高层级核心模式，写入图并与成员模式连接。

### 2.3 读路径与复杂度
- **读路径**：查询嵌入通过矢量搜索命中事实/身份存储→遍历取代链→查找图G中证据边指向该事实的模式/意图/核心模式节点。全程不调用LLM，延迟由矢量搜索主导。
- **复杂度**：写入`O(N log N)`（N为事实数），系统2预处理`O(N)`（无LLM），阶段2`O(|C|)`LLM调用（C为聚类数），阶段3`O(D·s̄) `LLM调用（D为领域数，s̄为每领域平均模式数）加`O((D·s̄)²)`矢量比较。读取`O(log N + k̄)`（k̄为取代链平均长度）。典型链长度≤4。

## 6. 主要结论与发现

- **双过程假设验证**：System 2的贡献呈现不对称性——在隐式跨会话推理（PersonaMem-v2）上提升显著（+2.51/+5.20），在显式回忆（LongMemEval）上几乎无提升（+0.44/+0.33）。与理论预测一致。
- **核心模式的高杠杆作用**：跨领域核心模式虽然仅占记忆节点的1.3%，但消融实验显示其贡献约4.1个准确率点（占System 2总贡献的绝大部分），表明这些抽象节点编码高价值认知结构。
- **取代链对信念恢复的重要性**：在LongMemEval知识更新子集中，78%正确回答的查询触及至少一个取代指针，而错误回答仅为31%，证实链遍历对恢复被修订信念状态的关键作用。
- **DCPM full超越长上下文基线**：在PersonaMem-v2上，DCPM full（59.30%）超过长上下文基线（58.20%），尤其在kimi-2.5模型下，结构化记忆克服了长上下文中的“中间丢失”效应。
- **可解释性与效率**：读路径无LLM，延迟仅由矢量搜索决定；System 2离线运行，不影响在线响应速度。

## 7. 优点

- **理论驱动架构**：将双过程认知理论与Theory-of-Mind系统性地映射到记忆系统设计，提出明确的认知能力层次，而非工程拼凑。
- **创新性机制**：
  - 取代链（Supersedes Chains）通过双向指针保持信念演化的完整轨迹，解决了更新覆盖丢失因果链的问题。
  - 跨领域碰撞扫描（Dual-space Collision）利用行为空间与语义空间的差异发现隐式模式，是新颖的抽象方法。
- **高效读路径**：推理时不调用LLM，仅依赖矢量搜索和指针遍历，保证了与检索系统相同的低延迟。
- **可扩展性**：系统2异步运行，允许在不影响在线服务的情况下持续提升认知结构。
- **实验设计清晰**：通过对比DCPM lite与full，精确分离System 1和System 2的贡献；消融实验逐步移除组件，清晰归因每个机制的价值。
- **诊断性分析**：提供节点分布、失败模式、定性示例等深入分析，支持理论主张。

## 8. 不足与局限

- **评估范围有限**：仅覆盖英文聊天助手场景，未涉及跨语言、具身代理、多轮任务规划等场景；基准数据集均为静态构建，未测试真实用户长期交互中的实时演化效果。
- **阈值依赖**：碰撞检测阈值（θ_beh, θ_sem）通过保留集人工调整，缺乏自适应学习方法，可能对基准分布敏感。
- **领域假设**：假设用户行为受少量重复认知模式支配，对于单领域主导用户，跨领域核心模式收益有限；对于高领域多样性，二次扫描开销可能成为瓶颈。
- **自然语言节点局限**：模式、意图等节点用自然语言表示，继承了提取LLM的冗长和不一致性，且无法进行代数运算（如集合交集）。论文建议未来可结合结构化槽位。
- **离线成本**：System 2的离线计算随模式节点数量增长，对大规模部署可能带来资源压力。
- **伦理风险**：跨领域推断可能推断出用户未明确暴露的隐私模式，论文建议生产部署时应提供层级可选的同意机制，并禁止用于高影响决策，但未提供具体防护方案。
- **长期维护未讨论**：多个夜间运行后图结构可能膨胀或退化，未讨论图压缩、陈旧模式清理等机制。
- **未与最先进的自进化系统直接对比**：相关工作部分提及了TSUBASA、SEARL、FileGram等同时期工作，但主实验中未将其纳入比较，削弱了绝对性能的说服力。
