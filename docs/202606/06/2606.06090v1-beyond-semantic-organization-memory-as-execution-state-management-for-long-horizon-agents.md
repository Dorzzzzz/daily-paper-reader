## 摘要
基于大语言模型的智能体日益处理具有相互依赖决策的长视界任务，其中每个动作都会重塑未来约束，中间错误可能级联放大。现有的RAG和智能体记忆系统通过语义相似性组织历史记录，在决策时检索内容相关的条目。我们认为这种设计与执行状态依赖关系不匹配：它碎片化决策轨迹，混合有效和错误的痕迹，阻碍连贯的状态重建和错误隔离。我们提出MAGE（记忆作为智能体引导的探索），一个主动的执行状态管理器，将交互存储在层次状态树中。智能体从活动的根到当前路径中推导其状态，结合子目标摘要、近期轨迹和来自先前分支的提示。四种耦合操作维护该树：Grow记录新轨迹，Compress总结完成的子目标，Maintain验证摘要，Revise恢复目标边界并在新分支上继续。这种设计在保持状态完整性的同时限制上下文增长，并将有缺陷的片段与活动路径隔离。在MemoryArena上的实验表明，MAGE在基线基础上将平均任务成功率提高了7.8-20.4个百分点，同时将token消耗降低了55.1%。

## Abstract
LLM-based agents increasingly tackle long-horizon tasks with interdependent decisions, where each action reshapes future constraints and intermediate errors can cascade. Existing RAG and agent memory systems organize histories by semantic similarity, retrieving content-relevant entries at decision time. We argue that this design mismatches execution-state dependencies: it fragments decision trajectories and mixes valid and erroneous traces, hindering coherent state reconstruction and error isolation. We propose MAGE (Memory as Agent-Guided Exploration), an active execution-state manager that stores interactions in a hierarchical state tree. The agent derives its state from the active root-to-current path, combining subgoal summaries, recent traces, and hints from prior branches. Four coupled operations maintain the tree: Grow records new traces, Compress summarizes completed subgoals, Maintain validates summaries, and Revise restores a target boundary and resumes on a new branch. This design bounds context growth while preserving state integrity and isolating flawed segments from the active path. Experiments on MemoryArena show that MAGE improves the average task success rate by 7.8--20.4 pp over baselines, while reducing token consumption by 55.1%.

## 2. 方法论

### 核心思想
- **MAGE（Memory as Agent-Guided Exploration）** 将智能体的交互历史组织为一个**两层层次状态树**：
  - **底层**：记录逐步骤的“动作-观察”原始节点，保留细粒度执行轨迹。
  - **顶层**：对已完成的底层段进行摘要压缩，形成子目标级摘要节点。
- 智能体的**当前执行状态**通过**活动根到当前路径**（active root-to-current path）构建，结合：
  - 压缩状态（C）：顶层摘要的序列
  - 原始状态（R）：最近未压缩的底层节点
  - 执行提示（H）：同层兄弟分支的探索历史及诊断反馈

### 关键技术细节
- **节点结构**：包含 id、内容、父节点、子节点集合、覆盖的底层节点列表（仅顶层）、诊断笔记（仅顶层）。
- **四种耦合操作**：
  - **Grow**：追加新动作-观察到底层；若当前节点已有相同内容子节点则合并；更新原始状态和提示。
  - **Compress**：当子目标完成或原始状态超阈值时，将底层段压缩为顶层摘要节点；支持复用已有摘要以节省空间；清空原始状态并更新压缩状态和提示。
  - **Maintain**：每次压缩后立即验证新摘要的正确性（LLM检查任务指令与底层轨迹的一致性）；失败则记录诊断反馈并返回修订目标步骤。
  - **Revise**：根据失败反馈或智能体主动调用，回滚指针到目标边界，丢弃当前分支的错误段，保留其他分支的进展；更新提示包含诊断和历史分支。

### 算法流程（文字描述）
1. 智能体执行动作并接收观察 → **Grow** 追加到底层树。
2. 当子目标完成或原始状态长度过大 → **Compress** 压缩为顶层摘要。
3. 压缩后立即 **Maintain** 验证：若通过则继续；若失败则触发 **Revise**。
4. **Revise** 恢复状态至目标边界（失败摘要的父节点），标记失败分支，并创建新分支继续探索。
5. 每次状态更新后，执行状态 S = (C, R, H) 被提供给智能体用于决策。

## 6. 主要结论与发现

- MAGE 在**所有领域上均取得最高任务成功率**，优于Long Context和其他基线，平均提升 **7.8–20.4个百分点**（SR）。
- **同时显著降低 token 消耗**：相比 Long Context，平均减少 **55.1%** token 消耗，且在购物和旅行领域甚至低于多数记忆系统。
- 消融实验证实：
  - 缺少 Compress 导致 token 激增（2.4倍）和成功率下降（7.3 pp in Shopping）。
  - 缺少 Maintain 导致错误摘要污染状态（成功率下降5–7 pp）。
  - 缺少 Revise 导致无法恢复错误分支（成功率下降4–5 pp）。
- 错误隔离机制有效：错误段被分支隔离，不影响其他路径进展。

## 7. 优点

- **创新视角**：跳出语义相似性思维，将记忆重新定义为执行状态管理，更契合依赖型任务的本质。
- **层次树结构**：既保留细粒度轨迹（底层）又实现上下文压缩（顶层），且根-当前路径天然提供完整状态。
- **主动闭环**：Grow→Compress→Maintain→Revise形成监控-修复循环，自动隔离错误，防止级联。
- **高效率**：仅在子目标边界调用LLM（Compress和Maintain），维护开销低，token消耗最小。
- **通用性**：在不同骨干模型（Qwen3.6-35B-A3B、Gemma4-31B）上均获得一致提升。
- **实验严谨**：包含消融、跨领域、模型泛化实验，以及详细案例分析。

## 8. 不足与局限

- **基准单一**：全部实验仅在 MemoryArena 上进行，未在更广泛的长视界代理任务（如真实网页操作、机器人控制）上验证。MemoryArena 是模拟环境，可能无法完全反映现实复杂性。
- **依赖LLM验证**：Maintain阶段需要LLM调用验证摘要，可能引入额外的延迟和成本（尽管后续算力消耗小）。
- **边界定义假设**：Compress和Revise依赖于子目标边界的显式标识（任务提供的步骤分界或智能体主动标记），在缺少天然边界的任务中可能难以触发。
- **未讨论记忆持久性与跨会话重用**：当前树结构仅用于单次任务，未涉及跨任务的长期知识积累。
- **上下文窗口限制**：尽管MAGE压缩树结构，但若任务步骤极长或不具备明确子目标结构，上下文可能仍会增长。
- **潜在偏差风险**：评估基于单一LLM（Qwen3.6-27B）和有限基线超参数，不同设定下相对表现可能变化。
