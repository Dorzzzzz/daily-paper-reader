## 摘要
一个LLM代理应该记住多少，以及多代理系统在试图达成共识时应如何连接？我们展示了这两个设计选择以某种方式相互作用，从而翻转了记忆对协调影响的符号。通过在八个固定的16代理拓扑上进行的432次网络化命名游戏模拟运行中，我们改变了记忆深度和网络结构。较长的记忆在去中心化网络中减慢了达到稳态的时间，但在中心化网络中却加速了该过程；相同参数根据拓扑将系统推向相反方向。关键的是，中心化网络中“更快稳定”意味着更快锁定到碎片化的平台期，而非达成系统范围内的共识，这可用于产生分歧意见。我们进一步记录了一种记忆介导的速度-一致性权衡：中心化网络始终比去中心化网络保留更多竞争性惯例，但其稳定速度严重依赖于记忆。在代理层面，网络内分析表明，高介数桥接节点遭受中介惩罚，而位于局部聚类邻域中的代理则获得更高的协调成功率。最后，在寻找可分析处理的生成机制时，我们发现代理的选择被虚拟博弈很好地捕捉，表明适应是基于信念而非奖励。实际意义：记忆深度和通信拓扑应共同设计，而非单独优化。

## Abstract
How much should an LLM agent remember, and how should multi-agent systems be connected when trying to reach consensus? We show these two design choices interact in a way that flips the sign of memory's effect on coordination. Across 432 simulation runs of a networked Naming Game on eight fixed 16-agent topologies, we vary memory depth and network structure. Longer memory slows the time to reach steady state in decentralized networks but accelerates it in centralized ones; the same parameter pushes the system in opposite directions depending on topology. Critically, "faster settling" in centralized networks means locking in to a fragmented plateau more quickly, not reaching system-wide consensus, which can be used to generate diverging opinions. We further document a memory-mediated speed-unity trade-off: centralized networks consistently preserve more competing conventions than decentralized networks, but their settling speed depends sharply on memory. At the agent level, within-network analyses show that high-betweenness bridges suffer a brokerage penalty while agents in locally clustered neighborhoods achieve higher coordination success. Finally, in search of analytically tractable generative mechanisms, we find that agents' choices are well captured by Fictitious Play, indicating belief-based rather than reward-based adaptation. The practical implication: memory depth and communication topology should be co-designed, not optimized in isolation.

## 2. 方法论：核心思想、技术细节与算法流程
- **核心思想**：采用经典的**命名游戏（Naming Game）**作为纯协调范式，在固定拓扑上运行重复博弈，通过LLM代理的局部交互观察全局共识涌现。

  - **代理模型**：每个代理是一个独立的LLM（Gemini 2.0 Flash），零样本推理，不允许多步推理。
  - **记忆机制**：固定大小先入先出队列（FIFO deque），存储最近M次交互记录（M ∈ {2, 5, 10}），每次决策前将记忆格式化为自然语言提示。
  - **交互协议**：每轮随机选择一条边上的两个代理同时选择惯例字母（从10个无偏字母集中选）。若匹配则各得+100分，否则各得−50分。
  - **算法流程**（Algorithm 1）：
    1. 初始化所有代理为空记忆和零分数；
    2. 每轮随机选一条边，让该边上的两个代理分别基于其记忆查询LLM选择惯例；
    3. 对比选择结果，更新得分；
    4. 每个代理将本轮交互追加到记忆，若超限则丢弃最旧记录。
  - **行为基线**：Fictitious Play（FP，基于对伙伴选择的信念）和Reinforcement Learning（RL，基于自身历史回报），通过软max温度τ拟合，比较对数似然。
- **网络结构**：采用Mason & Watts的8种固定16节点、度k=3的拓扑，分为**去中心化**（A-D，短平均路径、低聚类）和**中心化**（E-H，长平均路径、高聚类）两类。

## 6. 主要结论与发现
1. **记忆效应的符号反转**：在去中心化网络中，长记忆减慢稳定时间；在中心化网络中，长记忆**加速**稳定时间——同一参数方向相反，效应大小显著（M=10时中心化网络稳定速度是去中心化的约3倍）。
2. **速度-一致性权衡**：中心化网络保留更多竞争惯例（更高碎片化），但其稳定速度强烈依赖于记忆深度；短记忆下中心化网络稳定最慢（926轮），长记忆下最快（190轮）。
3. **局部与全局的分离**：高局部协调成功率并不等同于全局单一共识；代理可以在子群内有效协调但全系统碎片化。
4. **结构位置效应**：
   - **桥接惩罚**：高介数代理协调成功率更低（β ≈ -0.5~-0.7，所有拓扑中成立），长记忆加剧此惩罚。
   - **聚类优势**：高局部聚类代理协调成功率更高（β ≈ +0.24~+0.39），长记忆放大此优势。
5. **决策机制**：LLM代理的行为更符合**Fictitious Play**（基于对伙伴的信念）而非**Reinforcement Learning**（基于自身回报），FP在短记忆下优势更明显。
6. **跨模型一致性**：Claude Haiku 4.5与Gemini Flasht的选择匹配率95.4%，GPT-4o-mini匹配率94.2%，远高于10%随机基线，表明结果非模型特异。
