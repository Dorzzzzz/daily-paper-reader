## 摘要
记忆系统对于个性化大语言模型（LLMs）至关重要。然而，现有检索方法主要依赖语义相似性，可能遗漏语义重叠有限但逻辑关键的记忆。当前的基准测试不足以评估这一问题。为填补这一空白，我们构建了IMLogic，首个针对长对话场景中隐式逻辑记忆检索的高质量基准。受此挑战启发，我们引入根记忆（root memory），一种结构化的、保留决策的表示，从长期用户历史中提炼可复用的个性化逻辑。进而提出RootMem，一个即插即用框架，首先将原始历史蒸馏为结构化的根记忆，然后利用基于LLM的路由器激活逻辑相关的记忆，用个性化决策逻辑补充语义检索。大量实验表明，RootMem显著优于最强的检索基线，并持续提升现有记忆代理的准确性。我们的基准和代码将发布于https://anonymous.4open.science/r/IMLogic-DBB3。

## Abstract
Memory systems are essential for personalized Large Language Models (LLMs). However, existing retrieval methods in these systems primarily rely on semantic similarity, potentially missing logically critical memories with limited semantic overlap. Current benchmarks remain inadequate for evaluating this problem. To address this gap, we construct IMLogic, the first high-quality benchmark targeting implicit logical memory retrieval in long-dialogue scenarios. Motivated by this challenge, we introduce root memory, a structured, decision-preserving representation that distills reusable personalized logic from long-term user histories. We then propose RootMem, a plug-and-play framework that first distills raw histories into structured root memories and then uses an LLM-based router to activate logically relevant ones, complementing semantic retrieval with personalized decision logic. Extensive experiments demonstrate that RootMem significantly outperforms the strongest retrieval baselines and consistently boosts the accuracy of existing memory agents. Our benchmark and codes will be available at https://anonymous.4open.science/r/IMLogic-DBB3.

- **研究动机**：现有个性化大语言模型（LLM）的记忆系统主要依赖语义相似性进行检索，这会导致两种关键失败场景：1）检索到语义相似但逻辑无关的记忆（如用户说“喜欢热带鱼”，便推荐鱼缸）；2）遗漏语义遥远但逻辑关键的记忆（如用户养猫，猫可能在工作室陪伴用户，而建议购买开放式鱼缸会危及猫的安全）。现有基准（如LoCoMo、LongMemEval、PersonaMem等）均未系统建模语义相似性与逻辑相关性之间的冲突，无法有效评估隐式逻辑记忆检索能力。

- **整体含义**：要实现真正个性化的LLM响应，必须从“语义匹配”转向“逻辑推理”，即能够从长期用户历史中捕捉并利用那些与当前查询表面无关但实质上约束合理决策的个性化逻辑。

## 2. 论文提出的方法论

### 2.1 核心思想

- **根记忆（Root Memory）**：一种结构化的、保留决策逻辑的记忆表示，将分散的原始记忆条目蒸馏为可复用的个性化规则（Execution Rules）和支撑事实（Personalized Logical Evidence）。它不存储“用户喜欢什么”，而是存储“用户的行为规则是什么”以及“为什么”。

- **根记忆单元定义**：每个单元 \(U_i = \langle R_i, E_i \rangle\)，其中 \(R_i\) 是执行规则（激活条件和响应引导逻辑），\(E_i\) 是支撑这些规则的个性化逻辑证据（用户特定事实和约束）。

## 6. 主要结论与发现

1. **现有方法普遍失败**：最佳检索系统（EverMemOS）在IMLogic上的多项选择准确率仅为43.50%，错误集中在Preference和Generic陷阱，说明语义检索无法捕捉隐式逻辑记忆。
2. **RootMem显著提升**：记忆层级准确率达到55.23%，相对提升27.23%；集成到现有记忆系统后平均提升26.36%准确率，且减少Generic错误20.06%、Preference错误14.04%。
3. **组件不可或缺**：消融实验中移除路由器导致最大下降（-8.51%），表明路由机制是核心；移除执行规则和证据均有显著下降。
4. **开放生成与泛化性强**：在更难的开放生成设置下，RootMem带来57.56%的相对提升；跨多个LLM骨干均有一致提升（最高71.52%）。
