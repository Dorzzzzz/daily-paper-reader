## 摘要
长期记忆对于跨长时间交互和不断变化的任务场景中运行的LLM智能体变得越来越重要。最近的记忆系统使过去的经验更加持久、紧凑和可检索，但仅凭检索并不能确保记忆为当前查询提供有效证据。当经验被压缩成可复用的片段时，如果不同情景涉及重复出现的实体或用户状态，它们可能看起来同样相关。我们将这种失败称为上下文坍塌：记忆失去了判断它们是否为当前查询提供有效证据所需的周围上下文。为解决这一问题，我们提出了智能体记忆的上下文复现框架RaMem，该框架将检索到的记忆片段转化为可在上下文中验证的证据。RaMem通过四个协调阶段运作：(i) 证据锚定，将每条记忆定位于其原始情景条件，特别是事件时间、提及时间、会话跨度及参与者；(ii) 回忆条件归纳，推导出查询隐含的证据条件；(iii) 有效性感知检索，利用这些条件优先选择与上下文兼容的记忆，同时保留内容相关的候选项作为备选证据；(iv) 上下文保留合成，使所选记忆的结构化上下文对生成器保持可用。在长期记忆基准上的实验表明，RaMem在多个骨干网络上相比强记忆基线持续提升性能，平均F1得分提升超过10%。

## Abstract
Long-term memory has become increasingly important for LLM agents that operate across extended interactions and evolving task contexts. Recent memory systems have made past experiences more persistent, compact, and retrievable, but retrieval alone does not ensure that a memory provides valid evidence for the current query. When experiences are compressed into reusable fragments, memories from different situations may appear equally relevant if they involve recurring entities or user states. We refer to this failure as context collapse: memories lose the surrounding context needed to judge whether they provide valid evidence for the current query. To address this problem, we propose Contextual Reinstatement for Agentic Memory (RaMem), a framework that turns retrieved memory fragments into contextually verifiable evidence. RaMem operates through four coordinated stages: (i) evidence anchoring grounds each memory in its original episodic conditions, especially event time, mention time, session span, and participants; (ii) recall condition induction derives the evidence conditions implied by the query; (iii) validity-aware retrieval uses these conditions to prioritize context-compatible memories while retaining content-relevant candidates as fallback evidence; and (iv) context-preserved synthesis keeps the selected memories' structured context available to the generator. Experiments on long-term memory benchmarks show that RaMem consistently improves performance over strong memory baselines, with average F1 gains of more than 10% across several backbones.

## 1. 核心问题与整体含义（研究动机和背景）

- **研究动机**：大语言模型（LLM）智能体在长时间交互和演进任务中需要长期记忆。现有记忆系统通过压缩、存储和检索使经验更持久紧凑，但检索结果并不保证能作为当前查询的有效证据。当经验被压缩成可复用片段后，来自不同情景的记忆可能因共享实体或用户状态而显得同样相关，导致**上下文坍塌（context collapse）**：记忆失去了判断其有效性的周围上下文，检索到的内容虽相关但可能来自错误情景，造成证据误识别。
- **整体含义**：长期智能体记忆的关键缺失属性是**上下文可验证性（contextual verifiability）**——记忆不仅应被存储和检索，还应保留足够上下文以供智能体判断其是否能支持当前查询。这类似于人类情景记忆中的编码特异性原则：检索取决于线索与编码时上下文的匹配。

## 2. 方法论：核心思想、关键技术细节

- **核心思想**：提出**上下文复现（Contextual Reinstatement）框架 RaMem**，将检索到的记忆片段转化为情景可验证的证据。通过恢复每条记忆的原始情景条件，并在检索时优先选择与查询上下文兼容的记忆。
- **四个阶段**：
  1. **证据锚定（Episodic Memory Anchoring）**：将每条记忆 $m_i$ 结构化为内容 $x_i$ 和情景上下文 $e_i$。$e_i$ 包含事件时间 $\tau^{\text{event}}_i$、提及时间 $\tau^{\text{mention}}_i$、会话跨度 $\tau^{\text{session}}_i=[s^{\text{start}}_i, s^{\text{end}}_i]$、参与者 $p_i$、地点 $\ell_i$、实体 $u_i$、主题 $z_i$。区分事件时间与会话时间。
  2. **回忆条件归纳（Recall Condition Induction）**：将查询 $q$ 分解为信息需求 $r_q$ 和上下文召回帧 $c_q$。$c_q$ 包含接地时间范围 $\hat{\tau}_q$、人员 $\hat{p}_q$、地点 $\hat{\ell}_q$、实体 $\hat{u}_q$、主题 $\hat{z}_q$。利用全局对话日期范围解析相对时间表达。
  3. **有效性感知检索（Validity-Aware Memory Retrieval）**：先通过密集语义检索和词法检索（RRF融合）获得内容候选集 $C_{\text{content}}(q)$。仅当召回条件可靠接地时，激活上下文兼容检索 $C_{\text{ctx}}(q)$（例如会话重叠过滤：$s^{\text{start}}_i \le t^{\text{end}}_q$ 且 $s^{\text{end}}_i \ge t^{\text{start}}_q$）。最终候选列表为 $C_q = \text{DedupFirst}(C_{\text{ctx}}(q) \oplus C_{\text{content}}(q))$，否则退化为纯内容检索。
  4. **上下文保留合成（Context-Preserved Evidence Synthesis）**：将选中的记忆保留结构化上下文（会话跨度、时间、地点、人员、实体、主题）传递给生成器，生成器根据上下文证据生成答案。

## 6. 主要结论与发现

- RaMem 在所有骨干上平均 F1 提升明显：GPT-4o 上 39.06→51.66，GPT-4.1-mini 上 43.24→54.23，Qwen3-8B 上 33.45→44.55，Qwen2.5-3B 上 17.98→24.65。
