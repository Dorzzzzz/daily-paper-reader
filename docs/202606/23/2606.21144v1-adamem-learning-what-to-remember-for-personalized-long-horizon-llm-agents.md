## 摘要
大型语言模型智能体的长期记忆系统通常试图“记住一切”，统一提取记忆以保留尽可能多的事实。然而在实际应用中，推理成本和有限的上下文预算使得这种方法站不住脚：除了将原始对话整合到记忆中，智能体还必须进行“写入控制”，高效地仅保留每个用户真正关心的信息。否则，长时程个性化交互会出现“记忆膨胀”，无关琐事挤占有用信息，逐步降低问答准确性。我们认为，值得记住的内容取决于角色，并提出了AdaMem（自适应记忆），一种从反馈中学习为每个用户记住什么的方法。AdaMem维护一个结构化的、特定角色的记忆策略，并通过轻量级的补丁式自我反思步骤（带有失败回滚）从每周的问答反馈中优化该策略。为了研究这一设置，我们构建了AdaMem-Bench基准，模拟数周的交互和逐周问答。在两种提取模型和两种反馈模式下，AdaMem相比统一的Mem0基线将问答准确性提高了高达+9.0%，同时将记忆体积缩小了9%。

## Abstract
Long-term memory systems for Large Language Model (LLM) agents typically try to \emph{remember everything}, extracting memories uniformly to retain as many facts as possible. In production, however, inference cost and finite context budgets make this untenable: beyond consolidating raw dialogue into memory, an agent must exert \emph{write control}, efficiently keeping only the information each user actually cares about. Otherwise, long-horizon personalized interactions suffer \emph{memory bloat}, where irrelevant trivia crowds out useful information and steadily erodes question-answering (QA) accuracy. We argue that what is worth remembering is role-dependent, and propose \textbf{AdaMem} (Adaptive Memory), a method that \emph{learns what to remember} for each user from feedback. AdaMem maintains a structured, role-specific Memory Policy and refines it from weekly QA feedback through a lightweight, patch-style self-reflection step with failure rollback. To study this setting, we build \textbf{AdaMem-Bench}, a benchmark that simulates weeks of interaction with week-by-week QA. Across two extraction models and two feedback modes, AdaMem improves QA accuracy by up to \textbf{+9.0\%} over the uniform Mem0 baseline while shrinking memory volume by \textbf{9\%}.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究动机**：现有的大语言模型（LLM）智能体长期记忆系统（如Mem0、MemoryBank）普遍采用“统一提取规则”，试图记住对话中的所有事实。这种“记住一切”的策略在长时程个性化交互中会导致**记忆膨胀**（memory bloat）：无关的琐碎信息（如日常问候、次要日程）逐渐挤占有用的记忆，在检索时引入噪声，从而稳步降低问答（QA）准确性。
- **核心问题**：在推理成本有限、上下文预算固定的实际部署条件下，智能体必须进行**写入控制**（write control），只保留每个用户真正关心的信息。而“什么值得记住”是**主观且依赖角色**的（例如，与经理交互应关注业务决策，与健身伙伴交互应关注锻炼计划），因此记忆提取应由用户偏好引导。
- **整体含义**：论文主张将长期记忆管理从“被动存储所有对话”转变为“主动学习记住什么”，通过用户反馈自适应地修正记忆策略，以缓解记忆膨胀、提升个性化问答精度。这一思路对于工业部署中降低检索和推理开销、提高用户体验具有直接价值。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
- **AdaMem（Adaptive Memory）**：维护一个结构化的、角色特定的**记忆策略（Memory Policy）**，该策略以自然语言规则的形式描述了每种角色的提取偏好。系统通过一个**闭环周循环**从每周的QA反馈中学习，采用**补丁式自我反思（Patch-Style Self-Reflection）** 和**失败回滚（Failure Rollback）** 机制来逐步优化策略，从而决定哪些信息该写入记忆。

### 关键技术细节
1. **记忆策略结构**：\( P = \{C_1: T_1, ..., C_n: T_n\} \)，一个JSON对象，将每个角色 \( C_i \) 映射到其自然语言提取偏好 \( T_i \)（例如：“只提取最终的业务决策和截止日期，忽略日常闲聊”）。
2. **闭环周循环（Algorithm 1）**：
   - **每日提取**：基于当前策略 \( P_t \)，结合时间锚定（Time Anchoring，将相对时间表达式解析为绝对日期）提取偏好记忆。
   - **每周评估**：通过QA测试智能体的记忆召回能力，识别错误答案集 \( W_t \)。
   - **策略反思**：诊断错误类型——召回失败（策略太严格，遗漏信息）或精确性失败（策略太宽松，引入噪声）。据此生成补丁 \( \Delta P_t \)。
   - **失败回滚**：将更新后的策略 \( P'_{t+1} \) 在历史QA验证集上评估，若性能下降则回滚，否则接受。
   - **QA写入回**：用更新后的记忆重新生成答案并写入。
3. **补丁式更新**：仅对策略中的相关规则进行局部调整，而非全局改动，保证稳定性和轻量级。
4. **时间锚定**：提取时注入会话绝对日期，将所有相对时间表达式（如“明天”）转换为绝对日期再存储，防止未来检索时混淆。

  - **隐式反馈（Implicit）**：用户仅提供正确答案，智能体需自行推断偏好。

## 7. 优点

- **问题定义创新**：将长时程记忆管理重新定义为“写入控制”问题，而非单纯的“存储更多”，切中工业部署痛点，具有很强的实际意义。
- **方法轻量、可集成**：AdaMem的补丁式更新和失败回滚机制无需重新训练模型，可直接插入现有RAG记忆栈，成本可控。
- **反馈驱动、闭环优化**：通过每周QA反馈动态调整策略，形成持续的自我改进循环，适应偏好变化。
- **Benchmark设计合理**：AdaMem-Bench考虑了多角色、同类概念干扰、自然对话动态，且包含黄金记忆标注，为个性化长时程记忆评估提供了有价值的测试平台。
- **分析深入**：不仅报告整体性能，还按信息类别、检索动态、策略学习瓶颈进行拆解，揭示了方法的优势来源和剩余挑战。

## 8. 不足与局限

- **依赖合成数据**：所有评估基于自建合成数据集，虽然可控性好，但可能无法完全反映真实人类交互的语言多样性、噪声和偏好突变。需要未来在真实用户数据上验证。
- **LLM作为评判的偏差**：QA准确率、提取质量、政策遵循性等指标均依赖另一个LLM（deepseek-v4-flash）作为评判，可能引入模型自身偏见，尽管已解耦，但仍存在风险。
- **评估规模小**：受API成本限制，仅使用5个故事和10周交互，统计可靠性一般。更长周期（如一年）和更多故事才能提供更强保证。
- **隐式反馈下策略过拟合**：补丁式反思可能对单次QA失败过度调整，导致规则过严，影响其他类别。回滚机制部分缓解了问题，但缺乏更强的正则化手段。
- **未与现有长期记忆基准（如LoCoMo、LongMemEval）对比**：论文仅与Mem0比较，未在公开基准上验证，限制了结果的通用性。
- **未讨论用户偏好动态变化**：假设偏好在一段时间内相对稳定，未涉及用户偏好突然改变时策略如何快速适应。
