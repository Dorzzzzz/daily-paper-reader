## 摘要
AI眼镜为AI智能体充当个性化记忆助手提供了引人入胜的平台。要真正有用，此类系统必须超越短期视频理解，解决人类在纵向自中心视频流中因实用、个人或社交目的而经历的记忆空白。然而，现有自中心数据集主要关注动作识别或来自短视频片段的一般性问答，衡量的是感知能力而非真实的人类记忆需求。我们推出SuperMemory-VQA，一个用于评估AI助手在实用长时记忆任务上的自中心视觉问答（VQA）数据集。它包含52.9小时使用AI眼镜记录的日常活动，包括同步的RGB视频、音频转录、眼动注视、IMU和SLAM轨迹。通过人工验证的标注流程，我们构建了4,853个有依据的问答对，涵盖物体与位置记忆、意图回忆、视觉场景回忆、时间线重建、对话记忆和上下文检索。每个问题以选择题形式提出，并带有明确的“无法回答”选项以测试幻觉鲁棒性。对领先的智能体框架和LLM骨干的基准测试表明，现有系统在现实世界记忆任务上仍远不可靠，这凸显了构建仅在证据充足时才能回答的基于事实的AI记忆新架构的必要性。参与者调查进一步支持我们的问题是现实、有用且符合日常记忆需求的。

## Abstract
AI glasses present a compelling platform for AI agents to serve as personalized memory assistants. To be genuinely useful, such systems must move beyond short-term video comprehension and address memory gaps that humans experience for practical, personal, or social purposes over longitudinal egocentric video streams. However, existing egocentric datasets predominantly focus on action recognition or generic QAs from short clips, measuring perceptual capabilities rather than realistic human memory needs. We introduce SuperMemory-VQA, an egocentric visual question answering (VQA) dataset for evaluating AI assistants on practical, long-horizon memory tasks. It contains 52.9 hours of everyday activities recorded with AI glasses, including synchronized RGB video, audio transcription, eye gaze, IMU, and SLAM trajectories. Through a human-verified annotation pipeline, we construct grounded 4,853 question-answer pairs that span object and location memory, intent recall, visual scene recall, timeline reconstruction, conversational memory, and in-context retrieval. Each question is posed as multiple-choice with an explicit "unanswerable" option to test hallucination robustness. Benchmarking leading agentic frameworks and LLM backbones reveals that existing systems remain far from reliable on real-world memory tasks, highlighting the need for new architectures for grounded AI memory that can answer only when evidence is sufficient. A participant survey further supports that our questions are realistic, useful, and aligned with everyday memory needs.

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：现有自我中心（egocentric）视频数据集（如 EPIC-KITCHENS、Ego4D、EgoSchema、EgoLife）主要关注短时动作识别或通用视频问答，缺乏对**长期、跨会话记忆任务**的评估，无法衡量AI助手在真实人类记忆辅助场景中的表现。  
- **整体含义**：为满足AI眼镜等设备作为“个性化记忆助手”的需求，需要建立一个能评估系统在**长期（数小时至数天）、多模态、多证据推理**以及**幻觉鲁棒性**方面的基准。  
- **研究背景**：当前模型（包括百万上下文窗口的LLM）在长序列中存在“lost in the middle”效应；检索增强生成（RAG）虽然能扩展上下文，但在组合推理和时间跨度大的任务上仍易失败。因此需要一个针对性强的基准来推动该领域发展。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- 构建一个**自我中心视觉问答（VQA）基准数据集**，包含**52.9小时**的真实日常活动录制（使用Meta Aria Glasses），覆盖**六类记忆任务**（物体与位置记忆、意图回忆、视觉场景回忆、时间线重建、对话记忆、上下文检索），并采用**有序多选题**（含“不可回答”选项）来评估系统的**可回答性判断**和**幻觉鲁棒性**。

### 关键技术细节
- **多模态传感器数据**：RGB视频、双SLAM灰度流、眼动追踪、7声道音频、IMU、SLAM轨迹。
- **标注流程**（两阶段 + 人工审核）：
  1. **Phase 1 (密集视频描述)**：将视频分块，结合ASR转录和人物注册表，由LLM生成密集描述。
  2. **Phase 2 (智能体式QA生成)**：构建统一“超级账本”，由QA规划器生成问答对；验证器通过检索器检查事实正确性、目标对齐、因果性、选项平衡和自然度；增强器迭代优化；最终人工审核。
- **有序答案选项**：每个问题包含四个选项：`Correct`（正确）、`Vague`（模糊）、`Wrong`（错误）、`N/A`（不可回答），其中前三个由人工定义，`N/A`作为固定选项。可回答性问题中，正确选项与三个自定选项对应；不可回答性问题中，三个自定选项均为错误。
- **评估指标**：`Ans-F1`（可回答性检测的F1）、`QA-Acc`（四选一准确率）、`QA-MRR`（平均倒数排序，对有序选项打分）。

## 3. 实验设计

### 数据集
- **SuperMemory-VQA 自身**：10名参与者的52.9小时录制，4,853个QA对，覆盖六类任务，长时域（多数问题证据与查询间隔>1小时），约34%的QA需要多证据（multi-evidence）。
- **对比方法**：
  - **Video-RAG**：训练无关的单轮检索增强框架，使用ASR、OCR、物体检测三个并行数据库，通过FAISS检索后与视频帧拼接输入VLM。
  - **EgoButler**：与EgoLife配套的框架，采用层级摘要（30秒片段→小时→天）的粗到细检索。
  - **VideoAgent**（部分实验）：基于迭代智能体循环的方法。
- **VLM骨干**：开源模型（Qwen-3-VL 8B/30B, InternVL-3.5 8B/30B, Gemma-4-E4B IT, Gemma-4 31B）和闭源模型（Gemini-3-Flash, Gemini-3.1-Pro, GPT-5.4-mini, GPT-5.4）。

### 实验设置
- 零样本评估：不进行微调，仅提供问题、选项和问题时刻前的视频/文本证据。
- 每个方法使用相同VLM推理，最大上下文长度由框架决定。
- 额外实验：盲文评估（仅文本）、按视频/按人称准确率、部分给分分析、定性案例分析。

## 6. 主要结论与发现

1. **当前系统远不可靠**：最强配置（Gemini-3-Flash + Video-RAG）QA准确率仅61.0%，远低于人类期望，且Ans-F1与QA-Acc之间有明显差距（可回答性检测较好但答案精度低）。  
2. **Video-RAG优于EgoButler**：在Ans-F1、QA-Acc、QA-MRR上平均提升，尤其对可回答性检测帮助大。  
3. **闭源模型整体更强**，但性能不与模型大小单调相关（如Gemini-3-Flash常优于Gemini-3.1-Pro，GPT-5.4-mini表现接近GPT-5.4）。  
4. **主要失败模式是过度弃权**：即使存在证据，许多模型（特别是开源模型）错误地选择“不可回答”，而非给出正确或错误答案。  
5. **任务差异明显**：物体位置记忆相对简单，而时间线重建、意图回忆等需要跨时间证据的任务极难。  
6. **定性案例显示**：成功需要精确定位稀疏证据、保持精确属性、验证前提真实性；当前系统常在对话细节、小物体/OCR、时序排序、计数等方面失败。  
7. **盲文评估接近随机（~24%）**，证实答案不能仅靠语言先验猜中。  
8. **参与者调查积极**：86%认为问题反映了真实记忆缺口，82%认为答案在日常中有用。

## 7. 优点

- **新颖性**：首次系统评估AI助手在真实长期自我中心记忆任务上的表现，填补了现有基准（EgoLife等）的空白。  
- **基准设计严谨**：  
  - 自然语言措辞，避免模板化。  
  - 包含“不可回答”选项，测试幻觉鲁棒性。  
  - 有序答案（正确/模糊/错误/无法回答）提供更细粒度的定序反馈，可用于对齐。  
  - 多人多天录制，长时域（最长达2周）。  
- **标注流程可扩展**：结合AI生成和人工校验，效率较高且保证质量。  
- **评估全面**：多个框架、多种VLM、多维指标、定性与定量结合。  
- **开源开放**：数据集、代码、评估脚本均已公开，促进可复现研究。

## 8. 不足与局限

- **数据规模有限**：10名参与者，52.9小时，难以代表广泛人群和场景分布（如不同文化、年龄、非结构化活动等）。可能存在选择偏差。  
- **传感器利用不充分**：当前基线仅使用RGB、ASR、OCR、物体检测等，未利用眼动、IMU、SLAM 3D信息，而这些信息对长期记忆可能至关重要。论文也承认这一点，留作未来工作。  
- **仅零样本评估**：未探索在SuperMemory-VQA上微调或适配的方法，可能低估了实际应用潜力。  
- **标注依赖大模型**：AI生成QA可能引入系统性偏差，尽管有人工校验，但仍可能遗漏某些推理类型。  
- **答案选项定义主观性**：“模糊”（vague）选项的标注依赖于标注者判断，可能影响公平比较（但论文提供了部分给分分析来缓解）。  
- **未评估端到端系统延迟**：对实际AI助手使用体验（如响应速度）未涉及。  
- **调查样本小**：仅8人回答过自己的问题，样本量小，统计显著性有限。
