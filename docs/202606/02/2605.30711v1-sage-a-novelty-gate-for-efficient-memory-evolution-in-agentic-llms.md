## 摘要
智能体LLM必须持续决定新提取的事实是否应被添加、与现有记忆合并或忽略，然而先前的工作更多地关注检索和存储，而不是原则性的写入端控制。我们将记忆演化框架化为一个新颖性检测问题，并提出SAGE（球面自适应门控记忆演化），它利用基于von Mises-Fisher分布的密度估计器对记忆嵌入上的候选事实进行评分，并通过跟踪记忆存储几何结构的自适应阈值对其进行路由。SAGE将明显新颖的事实解析为ADD，明显冗余的事实解析为NOOP，并仅将不确定的情况发送给LLM合并步骤，从而减少了昂贵的写入时推理。在LoCoMo上，SAGE在所有七个开放权重骨干网对比中相对于Mem0实现了最佳的平均token-F1，而在GPT-4o-mini上，它使添加阶段API成本降低了3.4倍，添加阶段延迟降低了2.5倍，仅有一个小的平均评判分数差距。作为A-Mem的即插即用二进制门控，SAGE在五个模型上跳过了大约16-18%的LLM调用，并且对开放权重骨干网的质量变化极小。这些结果表明，新颖性感知的写入控制是提高长期智能体记忆中记忆质量和系统效率的实用杠杆。

## Abstract
Agentic LLMs must continuously decide whether newly extracted facts should be added, merged with existing memories, or ignored, yet prior work has focused more on retrieval and storage than on principled write-side control. We frame memory evolution as a novelty-detection problem and propose SAGE, a Spherical Adaptive Gate for memory Evolution that scores candidate facts with a von Mises-Fisher-based density estimator over memory embeddings and routes them with an adaptive threshold that tracks memory-store geometry. SAGE resolves clearly novel facts as ADD, clearly redundant facts as NOOP, and sends only uncertain cases to an LLM merge step, reducing expensive write-time reasoning. On LoCoMo, SAGE achieves the best average token-F1 against Mem0 on all seven open-weight backbone comparisons, while on GPT-4o-mini it reduces add-phase API cost by 3.4$\times$ and add-phase latency by 2.5$\times$ with only a small average judge-score gap. As a drop-in binary gate for A-Mem, SAGE skips roughly 16-18% of LLM calls across five models with minimal quality change on open-weight backbones. These results suggest that novelty-aware write control is a practical lever for improving both memory quality and system efficiency in long-term agentic memory.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：智能体LLM在长期交互中需要不断更新记忆（添加、合并、忽略新事实）。现有系统（如Mem0、A-Mem）大多将写入决策完全委托给LLM，导致写路径成为主要成本来源，且缺乏原则性的控制机制。
- **动机**：社区在记忆检索和存储方面投入了大量精力，但在“写什么”这一端缺乏高效且可靠的决策手段。错误的写入（重复、错误合并、过早删除）会损害下游查询质量。
- **整体含义**：作者主张将记忆演化重新定义为“新颖性检测”问题，并设计一个轻量级门控，在调用昂贵的LLM之前先判断候选事实的新颖程度，从而在保持记忆质量的同时大幅降低写端成本。

## 2. 论文提出的方法论

- **核心思想**：利用von Mises-Fisher（vMF）分布对当前记忆嵌入进行核密度估计，计算候选事实的新颖性分数；基于记忆存储的几何密度自适应调整路由阈值，将候选事实路由为ADD（直接添加）、NOOP（忽略）或UPDATE（仅不确定时调用LLM合并）。
- **关键技术细节**：
  - **记忆表示**：每个记忆项和候选事实都用ℓ2归一化的句子嵌入表示在单位超球面S^(d-1)上。
  - **vMF核密度估计**：定义`Ŝ(c|M) = (1/N) Σ exp(κ m_i^T c)`，其中κ为浓度参数，通过平均合向量长度Ȓ估计（`κ̂ ≈ Ȓ(d-Ȓ^2)/(1-Ȓ^2)`）。新颖性分数`ν(c) = (1 - svMF)/2`，其中`svMF = (1/κ) log Ŝ`。该分数位于[0,1]区间，越大表示越新颖。
  - **自适应阈值**：根据记忆密度ρ_t（通过PCA投影后的体积和数量计算）动态调整基础阈值`τ*_t = τ_min + τ_0 e^{-λρ_t}`，并经过EMA平滑得到τ_t。路由规则：
    - `ν(c) ≥ τ_t + δ` → ADD（无LLM）
    - `τ_t ≤ ν(c) < τ_t + δ` → UPDATE（调用LLM合并）
    - `ν(c) < τ_t` → NOOP（无LLM）
  - **二进制门控扩展**：为现有系统（如A-Mem）提供即插即用门控，使用固定阈值τ_noop过滤明显冗余的候选（`svMF > τ_noop` → NOOP），其余原样传递给宿主系统。

## 6. 主要结论与发现

- **质量**：SAGE在全部7个开放权重骨干上平均token-F1排名第一，BLEU-1在6/7上最优，Judge分数在4/7上最优。分类平均显示SAGE在所有四类问题上均最佳，多跳和开放域增益尤其显著。
- **效率**：写端LLM调用次数减少29-42%（排除异常骨干），GPT-4o-mini上添加阶段API成本降低3.4倍，延迟降低2.5倍，总写入token减少2.6倍。
- **二进制门控效果**：A-Mem+SAGE跳过16-18% LLM调用，开放权重模型上质量几乎不变（Judge变化≤0.65点），GPT-4o-mini上略降2.01点Judge。
- **核心理念验证**：新颖性感知写入控制能同时提高记忆质量和系统效率，而非简单的权衡。

## 7. 优点

- **方法创新**：将记忆演化形式化为新颖性检测，使用vMF密度估计和自适应阈值，理论简洁且与余弦相似度几何一致。
- **即插即用**：二进制门控可无缝接入现有系统（如A-Mem），无需修改内部逻辑。
- **写端成本大幅降低**：在保持或略优质量的前提下，LLM调用减少至原来的1/4~1/3（取决于骨干），对大规模实际部署意义重大。
- **鲁棒性**：自适应阈值避免了固定阈值在不同骨干上表现差异大的问题。
- **实验设计全面**：涵盖多种模型规模和API场景，消融实验充分。

## 8. 不足与局限

- **实验覆盖不足**：仅在LoCoMo一个benchmark上测试，未在LongMemEval、工具操控、任务导向对话或多语言场景验证，泛化性存疑。
- **功能受限**：未支持DELETE操作，无记忆压缩/遗忘机制；仅处理ADD/UPDATE/NOOP，缺少更复杂的演化动作。
- **依赖嵌入模型质量**：vMF分数基于句子嵌入，语义不同但向量相似的事实可能被错误忽略，而语义相同但向量差异大的事实可能绕过过滤。
- **阈值校准依赖合成数据**：二进制门控的τ_noop需通过合成数据校准，现实中可能难以完美匹配分布。
- **鲁棒性边界**：论文承认固定阈值在特定骨干上可能稍好，但自适应阈值作为默认更稳健；然而在GPT-4o-mini上二进制门控导致Judge下降2.01点，表明对强模型可能有轻微质量损失。
