## 摘要
我们提出eMEM（具身记忆），一种基于图的混合记忆系统，用于在物理环境中操作的具身代理。当前的代理记忆架构，如Generative Agents、MemGPT和A-MEM，将记忆视为文本流或知识图谱，但具身代理需要同时能通过意义、空间和时间进行搜索的记忆。eMEM通过单一图模型背后的多索引架构（用于结构化存储的SQLite、用于近似最近邻语义搜索的hnswlib以及用于空间查询的R树）填补了这一空白。层级整合流水线将原始感知观察转化为压缩摘要，模拟生物系统中的海马-新皮层整合。十个面向代理的回溯工具将记忆检索原语（包括概念到位置的解析和跨层回溯）作为LLM工具调用的第一类操作暴露出来。该系统完全嵌入，并与代理在同一进程中运行。此外，我们引入了eMEM-Bench v1，这是一个我们在ProcTHOR-10K场景上构建的用于具身记忆评估的基准。该基准明确围绕八个认知心理学范式（DRM诱饵、模式分离、模式完成、源监控、情境依赖检索、长时程干扰、序列位置和增强保留曲线）组织，每个范式的选择使得结果可与人类更广泛的记忆系统文献和先前的代理记忆系统文献进行对比解释；这是像LoCoMo或OpenEQA这样的表面任务基准无法提供的诊断水平。eMEM在988个探针上的加权平均得分为80.8，对于房间唯一的项目，在1小时到1年的模拟延迟下，保留曲线平坦且达到天花板。我们表明，纯RAG基线（flat_rag消融）在情境依赖检索上损失30分，在DRM诱饵拒绝上损失29分，分别隔离了多层存储和整合的贡献。我们同时发布了系统和基准代码。

## Abstract
We present eMEM (Embodied Memory), a hybrid graph-based memory system for embodied agents operating in physical environments. Current agent memory architectures, such as Generative Agents, MemGPT, and A-MEM, treat memory as text streams or knowledge graphs, but embodied agents require memory that is simultaneously searchable by meaning, space, and time. eMEM fills this gap with a multi-index architecture (SQL ITE for structured storage, hnswlib for approximate nearest neighbour semantic search, and an R-tree for spatial queries) unified behind a single graph model. A tiered consolidation pipeline transforms raw perceptual observations into compressed summaries, mirroring hippocampal-neocortical consolidation in biological systems. Ten agent-facing recall tools expose memory retrieval primitives, including concept-to-location resolution and cross layer recall, as first-class operations for LLM tool calling. The system is fully embedded and runs in-process alongside the agent. In addition we introduce eMEM-Bench v1, a benchmark we construct over ProcTHOR-10K scenes for embodied memory evaluation. The benchmark is organised explicitly around eight cognitive-psychology paradigms (DRM lures, pattern separation, pattern completion, source monitoring, context-dependent retrieval, long-horizon interference, serial position, and a foil augmented retention curve), each chosen so that the result is interpretable against the broader memory-systems literature in humans and prior agent-memory systems; a level of diagnostic that surface-task benchmarks like LoCoMo or OpenEQA cannot provide. eMEM scores 80.8 weighted mean over 988 probes, with a flat retention curve at ceiling from 1 h to 1 yr of simulated delay on room-unique items. We show that a pure RAG baseline (the flat_rag ablation) loses 30 pt on context dependent retrieval and 29 pt on DRM lure rejection, isolating the contribution of multi-layer storage and consolidation respectively. We release both the system and the benchmark code.

## 1. 核心问题与整体含义 (研究动机和背景)

*   **核心问题**：当前的LLM（大型语言模型）代理记忆系统（如 Generative Agents, MemGPT, A-MEM）主要针对**文本对话**设计，将记忆视为文本流或知识图谱。然而，**具身智能体**（如机器人在物理环境中操作）需要的记忆系统必须能**同时且高效地按“意义（语义）”、“空间（位置）”和“时间（时序）”三个维度进行检索**。现有的机器人空间表示系统（如 Hydra, ConceptGraphs）虽然擅长空间感知，但缺乏处理长期经验、整合记忆和概念回溯的机制。
*   **研究动机**：填补上述空白，即为具身代理提供一个既能处理时序和整合的LLM级记忆，又能提供机器人场景理解所需的空间基础能力的统一记忆系统。
*   **整体含义**：本文提出**eMEM**，通过混合多索引架构和生物启发的记忆整合流水线，旨在解决具身代理在长期部署中普遍面临的记忆碎片化、空间信息缺失和检索效率低下的痛点。

## 2. 方法论：核心思想与关键技术

*   **核心思想**：
    1.  **混合多索引架构**：使用三种互补的索引（SQLite, hnswlib, R-tree）分别处理结构化、语义和空间查询，并在单一图模型下统一管理。
    2.  **生物启发的分级整合（Consolidation）**：将记忆从原始观察（类似海马体）逐步压缩为长期知识（类似新皮层），模拟生物记忆的巩固过程。
*   **关键技术细节**：
    1.  **数据模型**：图模型包含四种节点类型（Observation, Episode, Gist, Entity）和六种边类型（BELONGS_TO, FOLLOWS等）。
    2.  **四层记忆层级**：工作记忆（进程内缓冲） → 短期记忆（可搜索） → 长期记忆（保留文本和嵌入） → 归档（仅保留摘要Gist，控制存储增长）。
    3.  **三索引统一存储**：
        *   **SQLite**：管理结构化数据，如时间戳、层级标签、实体属性等。
        *   **HNSW (hnswlib)**：对所有嵌入进行高维近似最近邻语义搜索。
        *   **R-tree**：支持3D空间范围和最近邻查询。
        *   **查询策略**：一个典型查询（如“机器人最近在厨房附近看到了什么？”）会依次使用HNSW（语义）、R-tree（空间）和SQLite（时间/层）进行过滤和计算。
    4.  **多层级感知**：同一个位置可以记录来自不同感知模型（如VLM描述、物体检测、语音识别）的独立观察，用 `layer_name` 标签区分，而非混合在一个条目中。
    5.  **分级整合（Consolidation）流水线**：
        *   **片段整合**：当Episode结束时，按时间间隔拆分、生成Gist摘要、提取并合并或创建新实体。
        *   **两阶段归档**：第一阶段保留原始观察和Gist；第二阶段（维护周期时）删除原始文本和嵌入，仅保留Gist。
        *   **非片段观察整合**：对不属于任何Episode的陈旧观察，使用DBSCAN进行空间聚类，每个聚类生成一个Gist。
    6.  **LLM工具接口**：提供10个面向代理的回溯工具，包括8个基本原语（如 `semantic_search`, `spatial_query`, `temporal_query`）和2个高阶工具（`locate`: 解析语义概念到空间位置；`recall`: 链式调用原语实现“告诉我关于X”的跨模态综合召回）。

## 3. 实验设计：数据集、基准和对比方法

*   **数据集与场景**：
    *   使用 **ProcTHOR-10K** 场景中的20个多房间房子，模拟环境使用 **AI2-THOR**。代理沿着固定路径移动并记录三个感知层（VLM描述、物体检测、室内分类）和合成内感受（电池、温度）。
*   **基准 (Benchmark)**：
    *   作者自建了 **eMEM-Bench v1**，特点如下：
        *   **基于范式（Paradigm-based）**：不是一个通用的表面任务基准，而是基于人类记忆研究中的8个经典认知心理学范式组织，每个范式测试特定的记忆功能。
        *   **八大范式**：
            1.  **DRM诱饵 (Encoding/Similarity)**：测试抵抗语义相关错误记忆的能力。
            2.  **模式分离 (Encoding/Similarity)**：测试区分相似经验的能力。
            3.  **模式完成 (Encoding/Similarity)**：测试从部分线索恢复完整记忆的能力。
            4.  **源监测 (Source/Context)**：测试归因信息来源（如VLM vs. 物体检测器）的能力。
            5.  **情境依赖检索 (Source/Context)**：测试当前空间位置是否能作为检索的上下文线索。
            6.  **长时程干扰 (Temporal/Interference)**：测试新旧记忆之间的干扰影响。
            7.  **序列位置 (Temporal/Interference)**：测试对一系列事件顺序的记忆（首因/近因效应）。
            8.  **保留曲线 (Temporal/Interference)**：测试记忆随时间（1小时到1年）的遗忘速率。
        *   **方法论贡献**：引入了**箔-增强（foil-augmented）**的探针构造方法，即在yes/no问题中加入跨场景的明确不存在项，以消除系统回答的“是”偏置。
*   **对比方法**：
    *   主要对比是**纯RAG基线（flat_rag ablation）**，即一个没有多层存储和整合的简化版本。
    *   在表格中，也与Generative Agents, MemGPT, A-MEM, Mem0, Zep等LLM代理记忆系统在功能（空间、时序、整合、多模、嵌入性）上进行了定性对比。

## 6. 主要结论与发现

*   **整体性能**：eMEM在eMEM-Bench v1上获得了 **80.8** 的加权平均分。
*   **保留曲线**：在模拟延迟 **1小时至1年** 的范围内，对于房间唯一的项目，**保留曲线平坦且达到天花板**，证明了系统在长时间运行中几乎没有遗忘，这是一个主要贡献。
*   **多层整合与存储的贡献**：消融实验证明，纯RAG（无多层存储和整合）在“情境依赖检索”上性能损失 **30分**，在“DRM诱饵拒绝”上损失 **29分**。这表明：
    *   **多层存储**（保留原始观察）对情境依赖检索至关重要。
    *   **整合机制**（Gist摘要）能有效抑制语义相关错误记忆。
*   **系统诊断价值**：范式基准确立了任务失败的认知功能根源（如“情境依赖检索”低分主要是代理工具选择问题，而非记忆表示问题）。

## 7. 优点

*   **方法亮点**：
    1.  **多索引融合**：在单一图模型下优雅地融合了语义、空间和时间检索，解决了具身代理的核心痛点。
    2.  **生物启发设计**：分级的、模拟海马-新皮层整合的流水线设计不仅在理论上合理，且在实践中工作良好。
    3.  **工具化接口**：将复杂的记忆操作分解为原子化的LLM工具，使高阶行为（如`recall`）可以从简单工具的链式调用中衍生，设计巧妙。
    4.  **空间即基础**：坚持以空间坐标作为第一类检索轴，使系统天然适合室内移动操作。
*   **实验亮点**：
    1.  **范式基准的创新**：使用认知心理学范式构建基准是最显著的实验亮点。它不仅测试“能不能”，还能解释“为什么失败”，诊断价值远超传统表面任务基准。这对于推动记忆系统研究具有方法论意义。
    2.  **箔增强探针**：提出并验证了箔增强技术对揭示系统偏置的重要性，提高了基准的严谨性。

## 8. 不足与局限

*   **代理模型限制**：当前评估使用了较小的开源模型（27B），性能天花板很大程度上受限于代理的**查询构建能力、工具选择能力和多步推理能力**，而非记忆系统本身。例如，情境依赖检索的低分直接归因于代理的`spatial_tool`选择问题。
*   **整合机制不足**：当前的整合（Consolidation）对所有观察均匀加权，可能导致花费时间多的区域主导摘要。生物学上，整合受新奇性和奖励调节，这一特性未被建模。
*   **坐标层级粗糙**：系统记录的是机器人的位姿，而非物体自身的坐标。这限制了“物体在哪”的精度，需要更深的感知融合。
*   **无共享记忆**：不支持多代理间的共享记忆和冲突解决。
*   **实验环境的局限**：基准基于ProcTHOR-10K的合成场景（20套房子），在真实机器人轨迹、更复杂环境和自然语言问题上可能无法直接泛化。
*   **潜在偏置**：虽然用了LLM作为法官，但“实体提取器”和“代理人”都可能存在从模型训练数据中带来的偏置。系统的高频节点（厨房）可能因训练数据中的常见分布而被容易地回忆，而非真实场景的频率。
