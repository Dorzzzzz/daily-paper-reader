## 摘要
持久化的LLM智能体需要记忆表示，以便在长期交互中明确形成人物理解。现有智能体记忆方法强调信息保留与检索，但对累积的交互证据如何抽象为人物理解的过程关注有限。我们将这一过程视为图式形成，即情境证据被抽象为可复用的模式与稳定的人物层面断言。我们提出PersonaTree，一个结构化生命周期记忆框架，通过三级人物树实现这一视角，并提供了从证据到断言的显式支持路径。PersonaTree通过保守写入、置信度引导的巩固以及查询条件路径检索来维护该树，仅返回每个查询所需的证据深度。在六个人物理解与持久记忆基准测试中，使用三种回答骨干网络，PersonaTree在18个紧凑分数中的12个上排名第一，并在16个设置中进入前两名。消融实验表明，层次结构在KnowMe上改善了抽象人物理解，而在可比上下文预算下，支持路径检索提高了RealPref的对齐效果。

## Abstract
Persistent LLM agents require memory representations that make the formation of person understanding explicit across long term interaction. Existing agent memory methods emphasize information retention and retrieval, yet give limited account of how accumulated interaction evidence is abstracted into person understanding. We view this process as schema formation, where situated evidence is abstracted into reusable patterns and stable person level claims. We introduce PersonaTree, a structured lifecycle memory framework that realizes this view as a three level persona tree with explicit support paths from evidence to claims. PersonaTree maintains the tree through conservative writing, confidence guided consolidation, and query conditioned path retrieval, returning only the evidence depth required by each query. Across six person understanding and persistent memory benchmarks with three answer backbones, PersonaTree ranks first in 12 of 18 compact scores and reaches the top two in 16 settings. Ablations show that hierarchy improves abstract person understanding on KnowMe, while support path retrieval improves RealPref alignment under a comparable context budget.

- **理论视角**：本文受认知心理学图式理论启发，将人物理解视为**图式形成**过程——情境证据逐步抽象为可复用的模式，再提升为稳定的人物主张。
- **重要性**：若没有这种结构化、可追溯的抽象，回答模型即使检索到相关事实，也难以解释为何某个抽象解释能从交互历史中推导出来。因此，需要一种记忆表示，使得人物层面的判断能显式地锚定在底层证据上。

## 2. 方法论：核心思想、关键技术细节

### 核心思想：三层人物树（Three-Level Persona Tree）

- **叶子节点（Leaf）**：存储带时间戳的单个交互事件证据（如“用户说对花生过敏”）。
- **中层节点（Mid）**：捕获可复用的行为模式或状态（如“用户有强食物过敏边界”、“喜欢户外活动”）。
- **根节点（Root）**：代表稳定的人物层面断言（如“用户重视安全边界”、“偏好低通勤负担”）。
- **支持边（Support Edges）**：连接低层证据到高层抽象，使得每个抽象主张的推理依据在记忆中可见。

### 关键技术流程（生命周期操作）

1. **在线证据插入**：
   - 从新交互中提取带类型特征的叶子节点。
   - 通过**模式兼容性检查**（基于属性向量）、**嵌入相似度**和**证据验证器**（支持/冲突/无关三元分类）匹配已有中层节点。
   - 只有匹配得分超过阈值才附着；若验证器判为冲突，叶子保持独立并传递负证据权重。

2. **置信度更新与短期激活**：
   - 使用对数几率空间更新置信度，包含时间衰减（反映时效性）和证据权重（支持为正、冲突为负）。
   - 公式：`L_t = (L_{t-1} - L_base)e^{-λΔt} + L_base + ω_E`，再通过sigmoid映射到[0,1]。
   - 不同模式类型可使用不同衰减率（持久属性衰减慢，行为模式衰减快）。

3. **离线巩固**：
   - 周期性处理未附着的孤立叶子，通过属性、时间、语义聚类形成候选模式。
   - 合并兼容的中层节点，将成熟的中层提升为根节点（需要高置信度、足够支持数、时间覆盖）。
   - 同时进行修剪：删除陈旧/低置信度的节点，限制中层支持的叶子数量。

4. **查询条件路径检索**：
   - 使用路由模型预测查询所需的抽象层级（叶子/中层/根）和关键属性。
   - 提取支持路径（根→中层→叶子），智能选择渲染深度（只返回根、根+中层、或完整链），并在**标记预算**下选择最优上下文子集（平衡相关性得分与token开销）。
   - 公式中通过最大化 `Σ(r(q,x) - λ_b tok(x))` 选择最终上下文，确保紧凑且证据充分。

1. **层次结构显著提升抽象理解**：在KnowMe上，完整三人树比仅叶子检索高4.3分，尤其在需要综合分散证据的用户洞察任务（T6、T7）上提升最明显（T7从16.2提升至24.3）。
