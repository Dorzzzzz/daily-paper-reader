## 摘要
基于大型语言模型（LLM）的智能体日益依赖记忆从持续交互中积累经验。然而，将经验存储为独立的扁平单元会导致大量冗余和检索冲突，因为相似回合重复重叠内容，且细微场景变化会导致检索到的记忆提供矛盾指导。为解决这一问题，我们引入残差经验概念，认为新获取的经验通常是已有知识的增量变化。我们提出DeltaMem框架，该框架将经验记忆组织为两个独立的残差树：一个存储以目标为导向的任务经验作为可复用技能，另一个存储场景级环境知识。每棵树使用一个根节点表示泛化基础经验，并使用增量节点表示后续变化，使得相关经验能够共享共同基础而无需重复。在检索时，采用失败惩罚的相似度扫描定位最佳匹配，并通过根到匹配链组合重建完整经验。自主整合机制将高频路径蒸馏为新的根节点，使得树能够从通用启发式到专门变体进行自组织。在多种交互环境中的实验表明，DeltaMem始终优于现有基线。为促进未来研究，我们在https://github.com/import-myself/DeltaMem上公开代码。

## Abstract
Large Language Model (LLM)-based agents increasingly rely on memory to learn from experiences over continual interactions. However, storing experiences as independent, flat units leads to substantial redundancy and retrieval conflicts, as similar episodes repeat overlapping content and subtle scene variations cause retrieved memories to offer contradictory guidance. To address this, we introduce residual experience, positing that newly acquired experience is often an incremental variation of existing knowledge. We propose DeltaMem, a framework that organizes experience memory into two independent residual trees, one storing goal-conditioned task experience as reusable skills and another for scene-level environment knowledge. Each tree uses a root node for generalized base experiences and incremental delta nodes for subsequent variations, allowing related experiences to share a common foundation without duplication. For retrieval, a failure-penalized similarity scan locates the best match, reconstructing the full experience via root-to-match chain composition. An autonomous consolidation mechanism distills high-frequency paths into new root nodes, enabling the trees to self-organize from general heuristics to specialized variants. Experiments across diverse interactive environments show that DeltaMem consistently outperforms existing baselines. To facilitate future research, we release the code at https://github.com/import-myself/DeltaMem.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：现有基于LLM的智能体记忆机制通常将经验存储为独立的平坦单元（完整轨迹或提取的洞察），导致两大缺陷：
  - **冗余**：相似场景的完整回合重复存储重叠内容，记忆库线性增长。
  - **检索冲突**：不同场景的细微差异导致检索到的记忆提供矛盾指导，降低决策质量。
- **核心思想**：提出“残差经验”概念，认为新经验是已有知识的增量变化。通过结构化存储增量差异而非完整内容，实现无冗余经验共享，并解耦任务策略与环境知识，避免跨任务干扰。
- **整体意义**：为LLM智能体提供高效、可扩展的持续学习记忆框架，使其能在多轮交互中自组织地从通用启发式进化到专门变体。

## 2. 方法论：核心思想、关键技术细节

### 2.1 核心架构：双树残差记忆

- **双树结构**：
  - **Task-Tree（任务树）**：存储以目标为导向的过程性经验（可复用技能）。每个节点内容：`Skill = ⟨α, π, ω⟩`，其中α为激活条件，π为执行动作序列，ω为终止条件。
  - **Env-Tree（环境树）**：存储场景级声明性知识（对象布局、交互规则等）。每个节点内容：`Knowledge = ⟨α, κ⟩`，α为场景触发描述，κ为声明性事实。
- **残差树结构**：每个节点类型分为ROOT（根节点，存储完整泛化基础经验）和RESIDUAL（增量节点，仅存储相对于父链的差异Δ）。相同场景变体共享根节点，仅记录增量变化，消除冗余。

### 2.2 关键技术细节

- **写入决策**：根据检索相似度 `s(v*)` 与阈值 `τ_base` 比较：若低于阈值（冷启动），插入新根节点；否则（热启动），追加增量节点到最佳匹配链。
- **挂载规则**：为避免链无限增长，若最佳匹配节点深度已达最大深度 `D_max`，则将新节点作为其兄弟节点挂载。
- **检索与链重构**：
  - 全局扫描所有节点，计算调整后余弦相似度 `s(v) = cos(e_q, e_v) - ε·I(label=FAILURE)`，其中 `ε` 为失败惩罚（默认0.05）。
  - 选出最高分节点 `v*`，若 `s(v*) ≥ τ_base`，则重构根到该节点的完整链：`C = ⟨P_root, ΔP_v1, ..., ΔP_vmatch⟩`。
  - 将任务链和环境链拼接，作为LLM决策的注入上下文。
- **经验提取协议**：每个回合后，LLM根据原始轨迹、节点类型和回合结果（成功/失败）提取结构化节点。对Task-Tree有4种模板（根成功、根失败、残差成功、残差失败），对Env-Tree有2种（根、残差）。
- **自主整合机制**：
  - 跟踪非根节点的成功命中计数 `c(v)`。
  - 当 `c(v) ≥ K_cons`（整合阈值）时，LLM将根到该节点的完整链蒸馏为一个新的根节点 `P*`，替换原链。
  - 原节点标记为“已整合”，避免重复触发。该机制使树从通用启发式自组织到专门变体。

## 3. 实验设计

### 3.1 数据集/场景（Benchmark）

- **ALFWorld**：文本家务环境，6类任务（如拾放、加热/冷却、在灯下检查物品）。两个分片：Seen（140集）和Unseen（134集），每集上限30步。
- **ScienceWorld**：文本科学实验环境，24类任务（如测熔点、导电测试、物种分类）。两个分片：Seen（194集）和Unseen（211集），步数依任务而定。
- **WebShop**：模拟电商环境，智能体需根据自然语言指令搜索和购买产品。200集。

### 3.2 对比方法

- **No Memory**：无记忆，仅系统提示+1个ICL示例。
- **Synapse**：检索最相似的成功轨迹作为少样本示例。
- **AWM**：从成功轨迹中提取可复用工作流描述，按任务类型维护文件。
- **ReasoningBank**：累积蒸馏的教训（成功策略/失败警告），注入决策提示。

所有方法使用相同底层LLM（DeepSeek-V4-flash，温度0）和ReAct框架，节点嵌入用E5-base-v2。

主要指标为平均奖励（AvgRew），在ALFWorld上等效于成功率。

为每个基准从小样本子集中经验性确定相似度阈值 `τ_task_base`, `τ_env_base` 和整合阈值 `K_cons`。最终值见附录A（如ALFWorld: 0.75, 0.85, 5）。

## 6. 主要结论与发现

- **主结果**：DeltaMem在所有基准的所有分片上均达到最佳或并列最佳的平均奖励，尤其在Unseen场景中提升显著，体现了跨场景泛化能力。
- **冗余消除**：残差节点平均token数仅为根节点的约56%，存储效率高。
- **双树互补**：消融实验表明任一树的去除都会导致性能下降，两者耦合提供最大增益。
- **整合机制的作用**：当 `K_cons` 有限时，性能对阈值变化不敏感；当整合关闭时，最优区域变窄，说明整合具有正则化效应。
- **离线迁移性**：预构建的记忆库可直接迁移到新任务，且在线更新不会引入冲突（对比AWM和ReasoningBank）。

## 7. 优点

- **增量存储**：通过残差Δ节点避免完整轨迹的重复存储，大幅压缩内存同时保留语义信息。
- **双树解耦**：独立管理任务策略与环境知识，避免跨任务干扰，检索时提供无冲突的上下文。
- **失败惩罚检索**：将失败节点标记为低分但不丢弃，使错误经验成为检索的“护栏”。
- **自主整合**：将高频路径蒸馏为根节点，实现记忆层次的自组织，从通用到专门。
- **系统评估**：在多种环境、多种基线、多参数设置下验证了方法的有效性和鲁棒性。
