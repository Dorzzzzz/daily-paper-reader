## 摘要
在边缘服务器上部署轻量级大语言模型（LLM）智能体可以降低延迟并将智能体服务更靠近用户，但资源受限的边缘模型在处理需要持久记忆、子目标追踪和反思的长时域任务时往往面临困难。部署后对边缘模型进行微调成本高昂且难以在异构节点上扩展，而纯本地记忆则导致智能体经验孤立且提示上下文不断增长。我们提出\textsc{CoMIC}，一种无参数更新的云边框架，用于协作记忆与洞察循环。\textsc{CoMIC}遵循“集中反思、分散执行”的设计：边缘智能体使用面向子目标的分层记忆和选择性重扩相关历史进行本地执行，而云端LLM批评者异步评估已完成轨迹、过滤可重用经验，并聚合以语义子目标标识符为键的跨智能体指导。在涵盖符号规划与文本交互的五项长时域智能体任务中，\textsc{CoMIC}提升了弱边缘智能体的进度率和动作基础性，并在不更新模型参数的情况下获得了依赖于任务的成功率提升。

## Abstract
Deploying lightweight Large Language Model (LLM) agents on edge servers can reduce latency and move agentic services closer to users, but resource-constrained edge models often struggle with long-horizon tasks that require persistent memory, subgoal tracking, and reflection. Fine-tuning edge models after deployment is costly and difficult to scale across heterogeneous nodes, while purely local memory leaves agents with isolated experience and growing prompt context. We propose \textsc{CoMIC}, a parameter-update-free cloud-edge framework for Collaborative Memory and Insights Circulation. \textsc{CoMIC} follows a \textit{Centralized Reflection, Decentralized Execution} design: edge agents execute locally using subgoal-oriented hierarchical memory and selective re-expansion of relevant histories, while a cloud-side LLM critic asynchronously evaluates completed trajectories, filters reusable experience, and aggregates cross-agent guidance keyed by semantic subgoal identifiers. Across five long-horizon agent tasks spanning symbolic planning and text interaction, \textsc{CoMIC} improves progress rate and action grounding for weak edge agents and yields task-dependent success-rate gains without updating model parameters.

### 2. 论文提出的方法论

- **核心思想**：采用 **“集中反思，分散执行”（Centralized Reflection, Decentralized Execution）** 范式。云端 LLM 作为全局批评者（critic）异步评估并聚合跨边缘智能体的轨迹经验，生成可泛化的全局指导；边缘智能则维持轻量级、面向子目标的分层记忆，并在决策时**动态检索**本地历史与云端指导，实现高效行动。

  - **云端单轨迹规范化与评估**：云端接收轨迹后，规范化其上下文特征为统一语义标识符，并串行化生成评估输入 \( x_t^i \)。批评者输出包含摘要、洞察、建议及自报告置信度 \( s_{\text{self}} \) 的评估记录 \( C_t^i \)。

### 6. 论文的主要结论与发现

- **核心发现**：CoMIC 在不更新模型参数的前提下，显著提升弱边缘智能体（Mistral-7b）在长时域任务中的进展率（PR 从 5.87 提升至 15.99）和动作基础性（GA 从 32.53 提升至 73.94），同时减少平均执行步数和上下文 token 消耗（减少 27.88%）。
- **成功率提升是任务依赖的**：在 Blocksworld、Tyreworld、Barman 上获得非零成功率（最高 20%），但在 Gripper、Jericho 上仍为 0。
- **异构混合场景（Scenario B）**：高质量轨迹产生更好的全局指导，但弱模型的理解能力限制整体收益，仅在部分任务上小幅提升。
- **云端反思有效缓解了弱模型本地记忆不足**，但无法完全弥补基础规划能力的缺陷。

### 7. 优点

- **无需参数更新**：完全基于记忆组织与经验分布，避免了边缘模型微调的高成本与扩展难题。
- **异步协作设计**：云端评估与边缘执行解耦，不阻塞实时决策，适合真实云-边系统。
- **跨智能体经验共享**：通过语义子目标标识符聚合指导，将单个智能体的成功经验泛化到整个群体。
- **系统化指标**：不仅评估任务完成率，还量化了上下文节省、动作有效性、云端负载等多维度表现。
- **清晰的消融实验**：通过对比无云、同构云、异构云，揭示了云端组件的关键贡献以及异构协作的局限性。

### 8. 不足与局限

- **基础模型能力瓶颈**：极弱的边缘模型（如 Mistral-7b）即使获得高质量云端指导，仍难以生成有效子目标或正确解读指导，导致成功率增益有限。
- **任务覆盖有限**：仅测试 5 个任务，且其中 2 个成功率为 0，未涵盖更复杂的现实世界任务（如 Web 导航、机器人控制）。
- **上下文节省对具体设置敏感**：在消融实验中（Table 2），w/ Cloud 的上下文消耗反而略高于 w/o Cloud（+6.64%），说明节省效果依赖于记忆准入和指导压缩的精度。
- **异构对齐问题**：Scenario B 显示弱模型与强轨迹指导之间存在“理解鸿沟”，云端缓存命中率和 ACK 比例显著下降。
- **泛化性未验**：仅使用 single cloud model (deepseek-chat) 和 single weak model (Mistral-7b)，未测试其他组合（如更小的 LLaMA、Phi 系列）。
- **未讨论延迟与通信开销**：虽然提到了云端延迟（~68s），但未分析在真实网络条件下的端到端延迟或带宽消耗。
- **缺乏随机性控制**：未报告多次重复实验的标准差或置信区间，难以判断结果稳定性。
