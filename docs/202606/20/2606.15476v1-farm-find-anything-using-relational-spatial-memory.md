## 摘要
在家庭、仓库等物体丰富的环境中运行的机器人需要记忆系统来按需找到特定物体实例。仅靠物体级记忆往往不够：场景中包含许多看似匹配的物体，用户通过与地标和周围物体的关系来指代目标（例如，“飞镖盘下方、海报左侧的高灯”），这需要一种关系空间记忆，支持通过语义、外观和物体空间谓词进行检索。为此，我们提出了FARM（利用关系空间记忆找到任何物体），它以5-10 Hz的频率实时构建一个紧凑的、开放词汇的、包含几何、视觉-语言描述符和视角证据的物体级记忆。在查询时，FARM使用VLM解析查询并对视觉证据进行评分，同时通过物体符号和关系谓词显式地约束空间条件。这种对VLM的结构化使用比基于帧历史或场景图上下文的端到端推理实现了更准确和鲁棒的检索。在涵盖67个室内外场景（面积从15到15,000平方米）的44k语言查询实验中，FARM在Recall@5和Recall@10上分别比先前方法提高了164%和224%，最终的VLM重排序阶段将Accuracy@1提高了35%，同时实时运行。我们进一步展示了在四足机器人上使用机载传感器和计算进行的闭环部署。

## Abstract
Robots operating in homes, warehouses, and other object-rich environments need memory systems that can find specific object instances on demand. Object-level memory alone is often insufficient: scenes contain many plausibly matching objects, and users refer to the target through relations to landmarks and surrounding objects (e.g. ``the tall lamp below the dartboard and to the left of the poster''), demanding a relational spatial memory that supports retrieval through semantic, appearance, and spatial predicates over objects. To achieve this, we present FARM (Find Anything using Relational Spatial Memory), which builds, in real time at 5-10 Hz, a compact, open-vocabulary, object-level memory with geometry, visual-language descriptors, and viewpoint evidence. At query time, FARM uses VLMs to parse the query and score visual evidence, while grounding spatial constraints explicitly through object symbols and relational predicates. This structured use of VLMs enables more accurate and robust retrieval than end-to-end reasoning over frame histories or scene-graph context. In experiments on 44k language queries spanning 67 indoor and outdoor scenes, ranging from 15 to 15,000 m^2, FARM improves Recall@5 and Recall@10 over prior methods by 164% and 224%, and a final VLM reranking stage improves Accuracy@1 by 35%, while running in real time. We further demonstrate closed-loop deployment on a quadrupedal robot using onboard sensors and compute.

# 2. 方法论：核心思想、关键技术细节、算法流程

- **核心思想**：FARM将记忆构建与检索解耦，在线构建紧凑的物体中心场景图，存储每个物体的3D高斯几何、视觉-语言描述、嵌入以及少量视角证据；查询时利用LLM解析自然语言查询为符号化规范，通过**软谓词评估器**（soft predicate evaluators）显式评分空间与语义约束，最后用VLM对top-5候选进行重排序。
- **关键技术细节**：
  - **记忆构建**（5-10 Hz在线）：每帧执行“检测→3D提升→关联→融合”同步循环。检测使用YOLOE（开放词汇分割与特征）；每个物体用单个3D高斯表示（均值+协方差），支持O(1)在线更新和尺度不变匹配（Hellinger距离）。此外，异步执行VLM（Qwen3.5-9B）对物体视角进行描述和嵌入生成。
  - **检索**：三步流程：
    1. **LLM解析**（Qwen3.5-9B）将查询转换为目标变量、锚变量、开放词汇描述和关系谓词的图结构。
    2. **候选评分**：通过多模态嵌入融合（文本、图像、描述）得到语义相似度；显式计算空间谓词（如 `Below`, `LeftOf`, `Near`）的软分数，使用3D高斯之间的几何评估器（如Hellinger距离、虚拟观察者框架等）。最终结合语义和空间分数（几何平均+加权混合）。
    3. **VLM重排序**：对top-5候选渲染候选为中心的局部场景示意图，由Qwen3.5-9B重新评分。
- **算法特点**：谓词是软的而非硬过滤，避免目标被错误锚点直接删除；保持候选召回，仅影响排名。

# 6. 主要结论与发现

- FARM在所有基准上超越先前方法：在ScanNet-30上Acc@1达35.9%（相对提高23%）；HM3D-30上Acc@1达7.9%（相对提高30%）；R@10分别达74.6%和26.9%，显著优于BBQ（提升2-3倍）。
- 消融表明：显式谓词评分比端到端VLM推理更有效，多嵌入融合优于单一嵌入；VLM重排序对复杂大场景有帮助，但对简单场景可能无效甚至降低。
- 记忆构建速度约8 Hz，与DAAAM相当，内存占用小（ScanNet上约23 MiB），适合机载部署。
- 失败分析显示：ScanNet主要瓶颈在top-1区分，HM3D主要瓶颈在候选召回（检测/记忆质量）。

# 7. 优点

- **结构化VLM使用**：将VLM的灵活性与显式空间谓词结合，避免端到端黑箱失效。
- **尺度不变性**：使用3D高斯表示物体，无需调整超参数即可从室内到室外跨尺度部署。
- **实时性与紧凑性**：同步+异步设计实现5-10 Hz映射，内存占用小，支持机载部署。
- **全面实验**：覆盖多种场景、多种指标、多个IoU阈值，包含消融和失败分析，结论可信。
- **新benchmark**：FARM-Scenes填补了大尺度室外关系查询的空白。

# 8. 不足与局限

- **谓词设计**：空间谓词是手工指定且未标定，参数（如`Near`的sigma）可能过于敏感。使用固定权重，在语义相近但空间不符的干扰物下可能失误。
- **锚推理局限**：不支持需要先在锚之间推理关系（如“人形机器人坐着的沙发”）再定位目标的复杂查询。
- **基准范围**：当前基准主要关注目标-锚关系，未覆盖更复杂的多跳推理。
- **HM3D上的候选召回瓶颈**：检测质量受限，导致许多正确物体未被收录，需改进在线物体发现。
- **实验可重复性**：虽然提供了算法细节，但未开源代码（截至论文提交），影响验证。
