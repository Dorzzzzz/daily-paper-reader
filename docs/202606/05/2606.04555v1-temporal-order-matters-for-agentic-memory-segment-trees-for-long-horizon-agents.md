## 摘要
长程对话智能体需要通过与用户交互来应对不断变化的事件、任务和目标。此类历史记录天然具有时间顺序，然而许多现有记忆系统主要按主题相似性组织信息，可能忽略事件发生的顺序。我们提出分段树记忆（SegTreeMem），一种将对话历史表示为按时间顺序排列的话语分段树的记忆架构。SegTreeMem通过在线最右前沿更新规则增量插入新话语，在形成层级记忆分段的同时保留时间顺序。检索时，SegTreeMem通过树传播相关性分数，将局部语义匹配与层级时间上下文相结合。在三个长程记忆基准测试和两个大语言模型主干上，SegTreeMem在答案质量上优于平面检索、图结构记忆和树结构记忆基线。额外的时间顺序排列分析表明，性能提升依赖于记忆构建过程中时间顺序的保留，支持了时间顺序是智能体记忆关键结构的观点。

## Abstract
Long-horizon conversational agents need to interact with users through evolving events, tasks, and goals. Such histories are naturally temporal, yet many existing memory systems organize information primarily by topical similarity and may ignore the order in which events occur. We introduce Segment Tree Memory, or SegTreeMem, a memory architecture that represents conversation history as a temporally ordered Segment Tree over utterances. SegTreeMem incrementally inserts new utterances through an online rightmost-frontier update rule, preserving chronological order while forming hierarchical memory segments. For retrieval, SegTreeMem propagates relevance scores through the tree to combine local semantic matching with hierarchical temporal context. Across three long-horizon memory benchmarks and two LLM backbones, SegTreeMem improves answer quality over flat retrieval, graph-structured memory, and tree-structured memory baselines. Additional temporal-order permutation analysis shows that the performance gain depends on preserving temporal order during memory construction, supporting the claim that temporal order is a key structure for agentic memory.

### 2. 论文提出的方法论：核心思想、关键技术细节
- **核心思想**：将对话历史表示为一棵**分段树（Segment Tree）**，其中每个节点对应一个连续的话语区间，按时间顺序组织。内部节点递归划分区间，叶子节点是单个话语。通过**在线最右前沿更新规则**增量插入新话语，保持时间顺序和局部连贯性；检索时通过**树结构感知的相关性传播**将局部语义匹配与层级时间上下文结合。
- **关键技术细节**：
  - **在线构造**：对新到达的话语 \(x_{t+1}\)，计算其与**最右前沿节点**（即右端点当前为 \(t\) 的节点）的兼容性，选择最兼容的非叶子节点作为父节点，将新话语作为最右子节点插入，并更新祖先节点。若没有兼容节点，则创建新根。兼容性模型可选：余弦相似度、逐点LLM或批处理LLM。
  - **节点注释**：每个内部节点由LLM生成摘要，覆盖其区间内所有话语。
  - **检索**：首先用嵌入模型计算每个节点与查询的局部相关性分数，归一化为初始分布 \(s_q^{(0)}\)。然后通过**传播矩阵** \(W_P\) 进行多步传播（自顶向下或自底向上），得到结构感知分数 \(\tilde{s}_q = \frac{\sum_{k=0}^H \alpha^k s_q^{(k)}}{\sum_{k=0}^H \alpha^k}\)，其中 \(\alpha\) 为衰减因子，\(H\) 为传播步数。最终选择Top-K节点。
- **算法流程**（文字说明）：
  - 构造：获得当前树的最右前沿节点集 → 调用兼容性模型选择附着点 → 创建新叶子和内部链 → 更新区间和注释。
  - 检索：计算所有节点本地分数 → 归一化 → 重复应用传播矩阵（可选方向） → 混合初始与传播分布 → 输出Top-K。

### 7. 优点
- **方法创新**：首次将分段树引入智能体记忆，同时满足在线增量构建和时间顺序保持，融合主题与时间层次。
- **检索机制新颖**：通过有限步的树结构相关性传播，能够灵活控制检索粒度（从细粒度到全局上下文），而不是简单的扁平或单一路径遍历。
- **实验设计严密**：控制变量严格（如证据预算、LLM主干、嵌入模型一致），包含置换实验、消融、效率分析，充分剥离时间顺序的影响。
- **实用性**：余弦相似度变体无需LLM调用，效率高，适合实际部署。

### 8. 不足与局限
- **极端输入退化**：当每个新话语都与所有前沿节点不兼容时（如极端主题切换），树会退化为级联结构，导致节点数二次增长和注释冗余。虽然自然对话不会频繁出现，但未提供鲁棒处理机制。
- **长程主题重复**：当同一主题在长时间间隔后再现，由于只按时间顺序插入，两个相关话语可能分布在远距离子树中，有限步传播可能无法连接它们。
- **内部节点摘要丢失细节**：LLM生成的摘要可能省略精确细节（如日期、名称），导致即使检索到正确区域，答案质量仍受限。
- **传播依赖固定参数**：未实现查询自适应的传播方向和步数，最佳参数需针对数据集调节，通用性受限。
- **实验覆盖**：仅测试了两个商业LLM主干，未覆盖开源模型；数据集中对话长度有限（最多700+话语），未在极长对话（数千轮）上验证。
- **可扩展性**：虽然在线构建是O(log N)复杂度，但LLM调用成本（尤其是批处理变体）可能成为实际瓶颈；没有讨论长期部署时的压缩或清理策略。
