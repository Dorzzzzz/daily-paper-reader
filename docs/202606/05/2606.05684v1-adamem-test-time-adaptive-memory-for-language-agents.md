## 摘要
语言代理面临的核心挑战是如何利用过往经验来适应动态的测试时条件。尽管近期工作展示了代理记忆机制的潜力，但大多数系统将检索限制在情节开始时。因此，代理被迫依赖静态指引，随着长周期任务的展开，这种指引会越来越不匹配。为解决这一僵化问题，我们提出自适应记忆代理（AdaMEM），一种用于代理测试时自适应的新框架。无需在线更新模型参数，AdaMEM通过混合记忆架构调整代理行为：维护一个离线收集原始经验的长时轨迹记忆，同时动态生成短时策略记忆以指导决策。这种机制能够在不同推理时计算量水平下实现令牌效率与适应性之间的权衡。实验表明，AdaMEM显著优于静态记忆基线，在ALFWorld上相对提升高达13%，在WebShop上达11%，在HotpotQA上的代理搜索中也保持领先性能。为进一步增强这种适应性，我们开发了STEP-MFT，一种逐步记忆微调技术，训练策略从检索到的经验中合成高质量策略，从而获得额外性能提升。我们的工作为代理记忆建立了新的扩展维度，支持在真实世界环境中持续推理和部署后自我进化。我们的代码可在 https://github.com/yunx-z/AdaMEM 获取。

## Abstract
A central challenge for language agents is utilizing past experience to adapt to dynamic test-time conditions. While recent work demonstrates the promise of agentic memory mechanisms, most systems restrict retrieval to episode initiation. Consequently, agents are forced to rely on static guidance that becomes increasingly misaligned as long-horizon tasks unfold. To address this rigidity, we propose the Adaptive Memory Agent (AdaMEM), a novel framework for agent test-time adaptation. Without updating model parameters online, AdaMEM adapts agent behavior via a hybrid memory architecture: it maintains a long-term trajectory memory of raw experiences collected offline while generating dynamic short-term strategy memory on-the-fly to guide decision-making. This mechanism enables the trade-off between token efficiency and adaptability across varying inference-time compute levels. Empirically, AdaMEM significantly outperforms static memory baselines, achieving relative gains of up to 13% on ALFWorld and 11% on WebShop, with consistent leading performance extending to agentic search on HotpotQA. To further enhance this adaptation, we develop STEP-MFT, a Step-wise Memory Fine-Tuning technique that trains the policy to synthesize high-quality strategies from retrieved experiences, yielding additional performance gains. Our work establishes a new scaling dimension for agentic memory, supporting continuous reasoning and self-evolution post-deployment in real-world environments. Our code is available at https://github.com/yunx-z/AdaMEM.

## 2. 方法论
### 核心思想
- 将记忆存储与抽象解耦：离线维护一个**长时轨迹记忆**（Long-Term Trajectory Memory, M），储存原始成功轨迹；在线动态合成**短时策略记忆**（Short-Term Strategy Memory, z_t），根据当前状态定制化指导决策。
- 提供两种推理模式：
  - **ADA MEM-LOW**：保留策略作为持久变量，仅在检测到状态偏移时触发刷新（refresh），平衡效率与适应性。
  - **ADA MEM-HIGH**：每一步都重新合成策略（丢弃旧策略），最大化适应性但消耗更多令牌。
- 进一步引入**STEP-MFT**（Step-wise Memory Fine-Tuning）：基于**过程级奖励**的拒绝采样微调，训练策略模型生成高质量策略。

### 关键技术细节
- **长时轨迹记忆构建**：仅收集成功轨迹 (τ)，对每一步存储 (state_embedding, (state, action, remaining_trajectory))。使用预训练嵌入模型编码状态，通过HNSW索引实现语义检索。
- **策略合成**：在推理时，模型先根据当前状态决定是否检索记忆（或是否刷新策略）。若触发，则检索 top-1 相关经验并合成一条简洁的自然语言策略（1-3条要点）。
- **STEP-MFT 数据收集**：在训练集上运行 ADA MEM-HIGH，记录 (state, retrieved_context, strategy, memory_conditioned_action, baseline_action, final_reward)。
- **过程级过滤**：双重过滤条件：
  1. 最终轨迹成功（r=1）。
  2. **动作改变**：记忆条件化的动作与无记忆基线动作不同（a_t ≠ a'_t）。该条件保证策略对决策有**因果贡献**。

  作者证明该条件是策略优势严格为正的必要条件。
- **训练目标**：对过滤后的 (s, E_ret, z*) 进行监督微调（交叉熵损失），最大化高质量策略的似然。使用同一个微调模型完成策略合成和行动生成（统一模型）。

## 6. 主要结论与发现
- **ADA MEM**在三个Benchmark上均超越了静态记忆基线，在ALFWorld unseen上提升11.4个绝对百分点（+13%相对提升），WebShop上+2.8分（+4%相对）。HotpotQA上+1.4点。
- **静态记忆导致负迁移**（WebShop上Synapse和ReasoningBank反而不如无记忆），而动态检索利用状态丰富时点（如搜索后）纠正了这一点。
- **混合架构支持跨模型通用**：Gemma使用Qwen的记忆仍能获得显著提升（+6.5分），证明策略被当前模型动态合成适应其自身能力。
- **策略抽象使记忆规模可扩展**：随k从1增至16，ADA MEM单调提升（+10点），而Synapse因上下文过长而退化。
- **STEP-MFT优于结局基监督**：过滤“动作改变”的微调比仅过滤“成功”的策略获得更高性能（WebShop上+1.3, ALFWorld上+5.3），而结局基监督反而可能下降。
- **更多测试时计算转化为有效收益**：ADA MEM的计算-效果呈正相关，而基线则停滞或负面。

## 7. 优点
- **创新性**：首次提出将长时轨迹记忆与短时动态策略合成解耦，克服静态记忆僵化性。
- **实用性**：无需在线参数更新，可无缝部署于已有LLM；提供计算自适应选项（LOW / HIGH）适用于不同资源场景。
- **训练方法高效**：利用简单的动作变化条件实现过程级奖励，无需价值模型或额外rollout，计算开销低。
- **实验设计严谨**：
  - 涵盖多种任务类型（导航、搜索、购物）。
  - 包含同策略和异策略评估，验证记忆共享。
  - 对检索预算、计算效率、令牌消耗进行了细致分析。
  - 用案例研究直观展示成功与失败模式。
- **开源**：提供代码，便于复现和扩展。

## 8. 不足与局限
- **策略惰性**（Strategy Inertia）：ADA MEM-LOW依赖模型自我评估决定刷新时机，当模型过度自信时可能拒绝刷新（即使计划已失效），导致循环失败（附录C.3案例）。
- **仅使用成功轨迹**：长时记忆M只填充成功轨迹，失败轨迹被排除。作者承认需要更原则性的方法来利用失败经验，因为当前模型难以从中提取一致指导。
- **依赖检索质量**：检索基于状态嵌入的语义相似度，若高维空间中相似状态但语义不同可能导致误导性策略。实验未深入分析检索失败案例。
- **训练数据收集成本**：ADA MEM-MFT需要先在训练集上运行完整的ADA MEM-HIGH来收集 (state, strategy, action, baseline action) 对，这在超大规模场景下可能较昂贵。
- **缺乏超大规模验证**：实验限于4B/7B模型，未在更大模型（如70B+）上测试；任务步数相对较短（<15步），更长期的任务中记忆维护机制未知。
- **闭环风险**：从未提及记忆中毒或隐私风险，仅呼吁部署时需人类监督和数据治理，未提供具体防御措施。
