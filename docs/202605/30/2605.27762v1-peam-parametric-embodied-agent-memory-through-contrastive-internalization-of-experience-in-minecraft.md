## 摘要
我们提出了PEAM，一种在Minecraft中实现的参数化具身智能体记忆框架，它将智能体记忆从推理时检索转变为通过经验内化的参数驻留技能。PEAM将用于开放式推理的缓慢深思型LLM与用于反射性执行整合技能的快速参数化模块配对。快速模块是一种多模态专家混合LoRA架构，具有按类别物理隔离的适配器，实现参数级持续学习而不会灾难性遗忘。我们将失败视为第一类训练信号：通过联合行为克隆和对比目标内化失败-修正轨迹对，使智能体不仅学习成功之处，还学习被修正的动作与失败动作的差异。为了管理整合，PEAM引入了参数化价值分数，用于决定哪些经验应被内化，以及一种无尺度自触发整合机制，用于决定何时内化而无需任务特定的手动调整阈值，使智能体能够自我进化，因为触发器可以在任务分布间转移而无需重新调整。在Minecraft中的实验表明，PEAM提高了长时程任务性能，减轻了对先前整合技能的遗忘，并在与基于检索的具身智能体和参数化记忆变体相比时，提高了参数化与检索的效率。

## Abstract
We present PEAM, a Parametric Embodied Agent Memory framework in Minecraft that transforms agent memory from inference-time retrieval into parameter-resident skills internalized through experience. PEAM pairs a slow deliberative LLM for open-ended reasoning with a fast parametric module for reflexive execution of consolidated skills. The fast module is a multimodal Mixture-of-Experts LoRA architecture with per-category physically isolated adapters, enabling parameter-level continual learning without catastrophic forgetting. We treat failure as a first-class training signal: failure--correction trajectory pairs are internalized through a joint behavioral-cloning and contrastive objective, so the agent learns not only what succeeds but also how corrected actions differ from failed ones. To govern consolidation, PEAM introduces a parameterization-worthiness score for deciding which experience should be internalized, and a scale-free self-triggered consolidation mechanism for deciding when to internalize without task-specific hand-tuned thresholds, making the agent self-evolving as the trigger transfers across task distributions without re-tuning. Experiments in Minecraft show that PEAM improves long-horizon task performance, mitigates forgetting on previously consolidated skills, and improves parametric-versus-retrieval efficiency over retrieval-based embodied agents and parametric memory variants.

### 1. 论文的核心问题与整体含义（研究动机和背景）

现有基于 LLM 的具身智能体通常依赖**非参数化记忆**（如外部技能库、反思日志），在推理时通过检索注入上下文。这种设计导致三个问题：
- **效率低**：每次调用都需要重新注入历史轨迹，消耗上下文预算，增加延迟和 tokens。
- **无法内化**：经验始终停留在外部存储，无法成为智能体自身参数的一部分，导致策略不变，难以实现持续学习。
- **灾难性遗忘**：若尝试对全模型微调，新任务会覆盖旧技能。

认知神经科学中的**互补学习系统**（CLS）理论指出，持久记忆由快速稀疏的情景存储和缓慢分布的参数化存储两个系统耦合而成，并通过离线巩固（如睡眠）将情景痕迹写入分布式表征。PEAM 受此启发，旨在将具身智能体的经验从**推理时检索**转变为**参数内化技能**，实现高效、抗遗忘的持续学习。

### 2. 论文提出的方法论：核心思想、关键技术细节

#### 2.1 核心思想：双层架构 + 经验内化管道

PEAM 采用**双层级**架构：
- **慢思考层（π_slow）**：使用 GPT-4o 进行开放式推理、规划、代码合成与结果验证。
- **快参数层（π_fast）**：基于 Qwen3-VL-8B-Instruct 的多模态 MoE-LoRA 架构，包含按类别物理隔离的适配器（ crafting、gather、combat），用于反射式执行已巩固的技能。

两个层级通过**巩固管道**耦合，包含三个核心问题：
1. **巩固什么（What）**：通过**参数化价值分数（PV）** 筛选值得内化的候选经验。
2. **何时巩固（When）**：通过**无尺度自触发巩固机制（STC）** 基于自身失败统计决定触发时机，无需手动阈值。
3. **如何巩固（How）**：通过**联合行为克隆（BC）+ 对比偏好优化（DPO）** 目标，在对应的隔离适配器上进行参数更新。

#### 2.2 关键技术细节

- **失败-修正轨迹对**：情景记忆存储成功轨迹 \( D_{succ} \) 和失败-修正对 \( D_{cpair} \)。修正轨迹 \(\tau_c\) 作为选中（chosen），失败轨迹 \(\tau_f\) 作为拒绝（rejected），用于 DPO 训练。
- **联合损失函数**：
  \[
  \mathcal{L}_{PEAM}(\theta_c) = \mathcal{L}_{BC}(\theta_c; D_{succ}^{(c)}) + \lambda \mathcal{L}_{PEAM-DPO}(\theta_c; D_{cpair}^{(c)})
  \]
  其中 BC 提供绝对模仿信号（确保代码格式正确），DPO 提供相对偏好信号。
- **参数化价值分数（PV）**：
  \[
  PV(s) = w_1 U_{cost} + w_2 U_{stab} - w_3 P_{redun} - w_4 R_{forget}
  \]
  分量包括：检索成本节省潜力、上下文一致性稳定性、与已有技能的重叠度、类别级干扰风险（结构二进制代理）。
- **自触发巩固（STC）**：使用统计检验（z 检验）比较近期失败率与历史基线，当 \( Z(s) > z_\alpha \) 且 PV 在 top-q 分位时触发。超参数（W=B=10, α=0.05, q=0.5）无需跨任务分布重新调整。
- **MoE-LoRA 隔离**：每个技能类别拥有独立的 LoRA 适配器，物理上不共享参数，从根本上避免跨类别遗忘。
