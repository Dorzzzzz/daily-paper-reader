## 摘要
全模态大语言模型实现了统一的音频视频理解，但长联合令牌序列导致推理成本高昂，且现有基准测试未能完全隔离嘈杂用户生成视频中的视听关联。我们提出了UGC-AVQA，这是一个包含1000个视频和4816个问答对的公开UGC基准测试，其中音频移除测试确保基准问题需要同时依赖声学和视觉证据。为降低推理成本，我们提出了OMAC——一种免训练的即插即用压缩方法，能够保留显著的视觉记忆和基于时间锚定的音频锚点。进一步地，为使紧凑模型对压缩输入保持鲁棒性，我们引入了O-MARC——一种基于记忆压缩多模态上下文的压缩蒸馏框架。在Qwen2.5-Omni-3B上，O-MARC将四个基准测试的平均分提升至45.8，优于全令牌推理的44.1分和OmniZip的41.0分。与全令牌推理相比，OMAC还保持了高效的推理性能，延迟降低34.6%（加速比1.53倍），内存减少34.7%。

## Abstract
Omnimodal large language models enable unified audio video understanding, but long joint token sequences make inference costly, and existing benchmarks do not fully isolate audio visual association in noisy user generated videos. We introduce UGC-AVQA, a public UGC benchmark with 1,000 videos and 4,816 QA pairs, where an audio removal test ensures that benchmark questions require both acoustic and visual evidence. To reduce inference cost, we propose OMAC, a training free plug in compression method that preserves salient visual memory and temporally grounded audio anchors. To further make compact models robust to compressed inputs, we introduce O-MARC, a compression distillation framework for learning with memory compressed multimodal contexts. On Qwen2.5-Omni-3B, O-MARC improves the average score across four benchmarks to 45.8, outperforming full token inference at 44.1 and OmniZip at 41.0. OMAC also keeps inference efficient, reducing latency by 34.6\% (1.53$\times$ speedup) and memory by 34.7\% compared with full token inference.

## 1. 核心问题与整体含义

- **研究动机**：全模态大语言模型（如 Qwen-Omni 系列）能够同时处理视频、音频和文本，实现统一的视听理解。但在处理长视频时，音频和视频均产生大量token，导致推理成本高昂（内存和延迟）。现有的 token 压缩方法多针对纯视觉或纯文本，扩展到音视频联合场景时，必须考虑两种模态的不同冗余模式和时间特性，且跨模态证据可能因独立压缩而丢失。
- **核心问题**：如何在不显著牺牲性能的前提下，高效压缩长视频的全模态输入，并确保压缩后的序列仍保留关键的视听联合推理证据？此外，现有基准未能充分隔离用户生成视频（UGC）中的音频-视觉关联。
- **整体意义**：论文通过构建专门的 UGC 音视频关联基准（UGC-AVQA），并提出两种压缩方法（免训练的 OMAC 和基于强化学习蒸馏的 O-MARC），旨在实现高效且鲁棒的 omnimodal 推理。这为降低全模态大模型在视频理解场景中的部署成本提供了可行路径。

## 2. 方法论

### 2.1 核心思想
- **OMAC（Omni Memory-Augmented Compression）**：一种免训练的即插即用压缩方法，借鉴视频记忆压缩的思想（类似 MARC）。它保留紧凑的视觉记忆（关键帧+帧内显著 token）和音频锚点，并利用视觉记忆分布动态调整音频预算，不修改骨干模型。
- **O-MARC（Omni Memory-Augmented RL Token Compression Distillation）**：基于 GRPO（Group Relative Policy Optimization）的压缩蒸馏框架。通过在线采样全 token 分支（教师）和压缩分支（学生），利用两者奖励差距重塑 GRPO 优势函数，训练模型在压缩输入下仍能保持强推理能力。

### 2.2 关键技术细节

#### OMAC 流程
1. **帧评分与视觉记忆**：
   - 对每个帧计算帧表示 $\bar{v}_t = \frac{1}{P}\sum_p v_{t,p}$。
   - 通过余弦相似度 $s_t = \cos(\bar{v}_t, q)$ 评估帧与查询的相关性，选择高分的帧作为关键帧（受压缩率 $\rho_v$ 控制）。
   - 在选中的帧内部，计算 token 对比分数 $\alpha_{t,p} = 1 - \cos(v_{t,p}, c_t)$（$c_t$ 为帧中心），保留高对比度的 token 作为显式视觉记忆，并生成一个紧凑帧记忆 token $z_t$（加权池化）。
2. **音频记忆预算调整**：
   - 对音频 token 保留高重要性分数的锚点，并将附近被丢弃的 token 合并到锚点中（公式5），形成紧凑声学记忆。音频压缩率受 $\rho_a$ 控制。
   - 利用视觉记忆的时间重要性权重 $w_t$（基于各帧保留的视觉记忆量），重新分配音频预算：$b_t = B_a \cdot \frac{n_t w_t}{\sum_\tau n_\tau w_\tau}$。不增加总预算，仅将更多音频容量分配到视觉记忆充裕的时间区域。

#### O-MARC 蒸馏框架
- 对每个查询 $q$，从当前策略 $\pi_\theta$ 采样两个 rollout：全 token （教师）和压缩（学生）。
- 计算压缩引发的奖励降级：$\Delta_i = \text{ReLU}(R_i^{\text{full}} - R_i^{\text{comp}}) / (|R_i^{\text{full}}| + \tau)$。
- 定义压缩感知权重：$w_i = \text{ReLU}(A_i) \cdot \Delta_i$，其中 $A_i$ 为原始 GRPO 优势。
- 形状化优势：$\tilde{A}_i = A_i + \lambda w_i$。
- 将 $\tilde{A}_i$ 替换 C-GRPO 目标中的原始优势，进行策略优化（公式11）。

## 7. 优点

- **新颖的免训练压缩方法 OMAC**：不需额外训练，即插即用，且保留多级记忆（帧级、帧内 token、音频锚点），并通过视觉记忆交叉引导音频压缩，思路巧妙。
- **压缩蒸馏框架 O-MARC**：首创将压缩感知奖励差距融入 GRPO 优势塑造，实现全 token 教师对压缩学生的オンライン蒸馏，提高压缩后模型鲁棒性。
- **高质量基准 UGC-AVQA**：通过音频移除测试确保问题必需双模态，且公开视频链接和标注，聚焦用户生成视频的实际挑战（噪声、场景切换），弥补现有基准不足。
- **实验充分公平**：多模型规模、多压缩率、多基准、与同期最强方法（OmniSIFT）对比，结果客观。效率实验验证 OMAC 不牺牲速度优势。
- **开源态度**：项目网页公开，数据集以 URL 形式发布，遵守平台访问条件。

## 8. 不足与局限
