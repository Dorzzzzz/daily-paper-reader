## 摘要
视频时刻检索（VMR）旨在从未修剪的视频中检索与句子查询对应的特定时刻。尽管近期工作在该任务上取得了显著进展，但它们隐含地基于闭集假设，即所有给定的查询都与视频相关\footnote{本文中，我们将“与视频相关的查询”视为“分布内（ID）查询”，将“与视频无关的查询”视为“分布外（OOD）查询”。}。在开集场景下，给定一个OOD查询，它们仍然会用于错误的检索，这可能在高风险场景（例如，犯罪活动检测）中导致不可挽回的损失。为此，我们创造性地探索了一种全新的VMR设置，称为开集视频时刻检索（OS-VMR），其中我们不仅要基于ID查询检索精确的时刻，还要拒绝OOD查询。在本文中，我们首次尝试迈向OS-VMR，并提出了一种新颖模型\textbf{OpenVMR}，该模型首先基于归一化流技术区分ID和OOD查询，然后基于ID查询进行时刻检索。具体来说，我们首先通过构建归一化流来学习ID分布，并假设ID查询分布服从多元高斯分布。然后，我们引入不确定性得分来搜索ID-OOD分离边界。之后，通过拉近ID查询特征来细化ID-OOD边界。此外，设计了视频-查询匹配和帧-查询匹配，分别用于粗粒度和细粒度的跨模态交互。最后，引入正类-无标记学习模块进行时刻检索。在三个VMR数据集上的实验结果表明了我们的OpenVMR的有效性。

## Abstract
Video Moment Retrieval (VMR) targets to retrieve the specific moment corresponding to a sentence query from an untrimmed video. Although recent works have made remarkable progress in this task, they implicitly are rooted in the closed-set assumption that all the given queries as video-relevant\footnote{In this paper, we treat ``video-relevant query'' as ``in-distribution (ID) query'' and ``video-irrelevant query'' as ``out-of-distribution (OOD) query''.}. Given an OOD query in open-set scenarios, they still utilize it for wrong retrieval, which might lead to irrecoverable losses in high-risk scenarios, \textit{e.g.}, criminal activity detection. To this end, we creatively explore a brand-new VMR setting termed Open-Set Video Moment Retrieval (OS-VMR), where we should not only retrieve the precise moments based on ID query, but also reject OOD queries. In this paper, we make the first attempt to step toward OS-VMR and propose a novel model \textbf{OpenVMR}, which first distinguishes ID and OOD queries based on the normalizing flow technology, and then conducts moment retrieval based on ID queries. Specifically, we first learn the ID distribution by constructing a normalizing flow, and assume the ID query distribution obeys the multi-variate Gaussian distribution. Then, we introduce an uncertainty score to search the ID-OOD separating boundary. After that, we refine the ID-OOD boundary by pulling together ID query features. Besides, video-query matching and frame-query matching are designed for coarse-grained and fine-grained cross-modal interaction, respectively. Finally, a positive-unlabeled learning module is introduced for moment retrieval. Experimental results on three VMR datasets show the effectiveness of our OpenVMR.

## 1. 核心问题与整体含义（研究动机和背景）

- **传统 VMR 的局限**：现有视频时刻检索（VMR）方法均基于**闭集假设**，认为所有输入的查询语句都与视频相关。在实际开放场景中，用户可能输入与视频无关的查询（Out-of-Distribution, OOD），但闭集方法仍会强行进行错误检索，在高风险应用（如犯罪检测）中可能造成不可逆损失。
- **问题定义**：本文首次提出 **开放集视频时刻检索（Open-Set VMR, OS-VMR）** 任务，要求模型同时满足两个目标：
  - 对与视频相关的 ID（In-Distribution）查询，准确检索出对应的视频片段；
  - 对与视频无关的 OOD 查询，予以拒绝（不输出任何片段）。
- **研究价值**：该设置更贴近真实多媒体检索场景，避免了闭集假设带来的安全隐患，具有重要的理论与应用意义。

## 2. 论文提出的方法论

### 核心思想
- 构建一个可同时区分 ID/OOD 查询并执行精确检索的端到端框架 **OpenVMR**。
- 利用**归一化流（Normalizing Flow）** 学习 ID 查询的特征分布，通过不确定性分数推理 ID-OOD 分离边界，并通过对比学习拉近 ID 特征、推远 OOD 特征以细化边界。
- 仅对判定为 ID 的查询进行跨模态匹配和正-无标记学习（Positive-Unlabeled Learning, PUL），实现精确的时刻定位。

### 关键技术细节（四个模块）

#### (I) ID 知识获取（ID Knowledge Acquisition）
- 使用多层耦合块（Coupling Block）构建归一化流，将 ID 查询特征映射到潜在空间，并假设潜在变量服从**多元高斯分布**。
- 通过最大化 ID 查询的对数似然来训练归一化流，损失函数为：
  \[
  \mathcal{L}_1 = \mathbb{E}_{q \in Q_{id}} \left[ \frac{1}{2} \Phi_\omega(q)^\top \Phi_\omega(q) - \sum_{c=1}^{C} \log \det \mathbf{J}_{\Phi_c}(k^{c-1}) \right]
  \]

#### (II) 不确定性驱动的 OOD 边界推理（Uncertainty-aware OOD Boundary Reasoning）
- 利用归一化流计算每个查询的对数似然 \(\log p(q)\)，进一步转化为不确定性分数 \(u(q)\)。
- 基于 ID 查询的对数似然分布，选取 \(\alpha\)-百分位数（如 5%）作为 ID 边界 \(b_{id}\)，并设置一个边距 \(\Delta\)，得到 OOD 边界 \(b_{ood} = b_{id} - \Delta\)。

#### (III) ID-OOD 边界细化（ID-OOD Boundary Refinement）
- 使用**三元组损失**（Triplet Loss）拉近 ID 特征（对数似然低于 \(b_{id}\) 的样本）并推远 OOD 特征（对数似然高于 \(b_{ood}\) 的样本）：
  \[
  \mathcal{L}_2 = \sum_{i=1}^{N_{id}} |\min(\log p_i - b_{id}, 0)| + \sum_{j=1}^{N_{ood}} |\max(\log p_j - b_{id} + \Delta, 0)|
  \]
- 通过归一化系数 \(h_{id}\) 将对数似然压缩到 \([-1, 0]\) 范围，便于边界学习。

#### (IV) 跨模态交互与检索（Cross-modal Interaction and Retrieval）
- **视频-查询匹配（Video-Query Matching）**：通过全局表示计算余弦相似度，并采用对比损失（\(\mathcal{L}_3\)）对齐视频与查询。
- **帧-查询匹配（Frame-Query Matching）**：为每一帧计算与查询的匹配概率，产生帧级注意力权重，增强关键帧特征。
- **正-无标记学习（Positive-Unlabeled Learning）**：将检索问题视为半监督二分类：查询相关帧为正样本，背景帧为未标注样本。选取高置信度正样本和可能负样本，计算二元交叉熵损失（\(\mathcal{L}_{BCE}\)）和回归损失（\(\mathcal{L}_{reg}\)），最终总损失为：
  \[
  \mathcal{L} = \mathcal{L}_1 + \lambda_1 \mathcal{L}_2 + \lambda_2 \mathcal{L}_3 + \lambda_3 \mathcal{L}_4
  \]
- 推理阶段：先判别查询是否为 ID，若是则通过预定义提案和回归头定位时刻边界；若不是则直接拒绝。
