## 摘要
大语言模型智能体越来越依赖持久化记忆来存储过去的交互、检索相关演示并改进长时任务执行。然而，这种记忆机制也带来了实际的安全漏洞：对抗性用户可能通过普通交互向智能体记忆注入恶意记录，这些记录随后可能被检索以引导智能体的推理和行动。现有防御主要关注在线干预（如提示过滤或输出阻断），但未能解决在有害行为已被观察到后，哪些存储的记忆应负责的事后问题。我们提出MemAudit，一种用于记忆增强型LLM智能体的事后因果记忆审计框架。该框架结合两种互补信号：（1）反事实记忆影响得分，衡量每个记忆对有害输出的因果贡献；（2）记忆一致性图，在整体记忆存储中识别结构异常的记忆。我们在MINJA（一种通过正常智能体交互而非直接修改记忆库生成并存储恶意记录的仅查询式记忆注入攻击）上评估MemAudit。在问答和推理智能体设置中，MemAudit在现实的事后审计场景下显著降低了攻击成功率。结果显示，问答攻击成功率从70%降至0%，而RAP攻击成功率从83.3%降至0%。

## Abstract
Large language model agents increasingly rely on persistent memory to store past interactions, retrieve relevant demonstrations, and improve long-horizon task execution. However, this memory mechanism also creates a practical security vulnerability: an adversarial user may inject malicious records into the agent's memory through ordinary interaction, and these records can later be retrieved to steer the agent's reasoning and actions. Existing defenses primarily focus on online intervention, such as prompt filtering or output blocking, but they do not address the post-hoc question of which stored memories are responsible after harmful behavior has already been observed. We propose \textbf{MemAudit}, a post-hoc causal memory auditing framework for memory-augmented LLM agents. The framework combines two complementary signals: (1) a counterfactual memory influence score that measures each memory's causal contribution to harmful outputs, and (2) a memory consistency graph that identifies structurally anomalous memories within the broader memory store. We evaluate MemAudit against MINJA, a query-only memory injection attack in which malicious records are generated and stored through normal agent interactions rather than direct memory-bank modification. Across both QA and reasoning-agent settings, MemAudit substantially reduces attack success rates under realistic post-hoc auditing scenarios. The results show that QA attack success is reduced from $70\%$ to $0\%$, while RAP attack success drops from $83.3\%$ to $0\%$.

### 2. 方法论：核心思想、关键技术细节、算法流程
- **核心思想**：有害记忆具有两个互补属性：① 对有害输出具有可测量的因果影响；② 在全局记忆分布中通常表现为结构不一致。
- **关键技术细节**：
  - **反事实记忆影响得分（CMIS）**：对于每个有害事件e=(q*, y*, R*)，通过从记忆库中移除候选记忆mi并重放事件，计算移除前后Harm Score的差值：CMIS(mi) = h(q*, y*) - h(q*, f(q*, R(q*, M \ {mi})))。值越大说明该记忆对有害行为的因果贡献越大。
  - **记忆一致性图（MCG）**：构建语义图G=(V,E)，节点为记忆条目，边基于语义相似度和自然语言推理（NLI）的矛盾/蕴含关系。定义结构异常得分CAS(mi) = ∑_{mj∈N(mi)} w(mi, mj)·sim(mi, mj)，其中w捕捉矛盾或不一致性。异常可通过全局分布阈值（如CAS > μ+2σ）识别。
  - **解毒得分融合**：DS(mi) = α·^CMIS(mi) + (1-α)·gCAS(mi)，其中α控制因果证据与结构证据的平衡，默认α=0.6。
- **算法流程（Algorithm 1）**：
  1. 对每个有害事件，遍历其检索到的记忆，通过重放移除该记忆并计算CMIS，累加所有事件的CMIS。
  2. 构建全量记忆图，计算每个记忆的CAS。
  3. 归一化CMIS和CAS，计算DS。
  4. 按DS降序排列，选择Top-k记忆作为移除集合S。
  5. 最终移除S，并在纯净记忆上重新评估。

### 3. 实验设计
- **任务/场景**：采用MINJA攻击中的两个设置：
  - **QA**：短文本问答，攻击目标是当查询包含触发词“food”时，记忆中的恶意规则将正确答案映射为错误标签。检索基于Levenshtein距离，top-5记忆+3个上下文示例。
  - **RAP**：长时推理代理（WebShop购物任务），攻击目标是当查询涉及“toothbrush”类别时，将代理重定向至指定产品（DenTek）并完成购买。
- **基准方法**：
  - 随机删除（RD）：随机移除相同数量的记忆。
  - 检索频率删除（RF）：移除在攻击评估集中最常被检索的记忆。
  - 最近邻矛盾过滤（NNC）：移除与局部语义邻居最矛盾的记忆。
- **模型**：GPT-4o、GPT-4o-mini、DeepSeek（DeepSeek-V3）。
- **评估指标**：攻击成功率（ASR），在QA中对应错误率（因攻击目的是出错），在RAP中对应成功购买目标产品。污染比ρ = |Mpoison|/(|Mbenign|+|Mpoison|)。
- **实验设计**：采用三阶段事后批审计协议：1) 重放被攻击代理收集有害事件；2) 在原始记忆上运行MemAudit得到可疑集S；3) 移除S后在纯净记忆上重新评估。所有结果平均10次运行。

### 6. 主要结论与发现
- MemAudit在QA和RAP上均显著降低ASR：QA上GPT-4o从70%降至0%，GPT-4o-mini从50%降至0%，DeepSeek从70%降至10%；RAP上三个模型均从80%以上降至0%。
- 双信号融合（CMIS + MCG）优于任意单信号，融合权重α=0.6最优。
- MemAudit在稀疏污染（ρ≤0.20）下完全防御，但当污染密度超过阈值（QA上ρ=0.25，RAP上ρ=0.24）时性能急剧下降，因为毒化记忆互相支持形成一致性集群，削弱了因果和结构检测信号。
- 相比随机删除、检索频率删除和最近邻矛盾过滤等基线，MemAudit优势显著，证明增益来源于针对性审计而非简单删除。

### 7. 优点
- **新颖性**：首次将事后记忆审计作为独立的安全问题提出，区别于传统的在线防御。

- **轻量级**：不依赖模型训练，本地计算开销低，可实用部署。
- **实验设计周全**：包含多种消融实验、污染分析、权重敏感性测试，结果统计稳定（10次平均）。

### 8. 不足与局限
- **场景覆盖有限**：仅测试了MINJA的QA和RAP两个场景，未涵盖更广泛的内存攻击（如AgentPoison、MemoryGraft、环境注入攻击）和更复杂的智能体交互（如多智能体、动态记忆）。
- **依赖可观测失败信号**：如果系统不记录检索记忆、监控未发现有害行为，或有害信号有噪声，则审计可能失效。

- **潜在假阳性**：框架可能误判良性且结构独特的记忆为可疑，导致性能或个性化退化。
- **仅事后审计**：不能实时预防，需与在线防御结合。
