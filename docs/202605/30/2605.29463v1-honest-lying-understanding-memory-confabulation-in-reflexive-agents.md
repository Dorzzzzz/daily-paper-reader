## 摘要
反射风格的代理依赖于自我生成的反思作为记忆，隐式地假设代理可以准确诊断自己的失败。我们表明这种假设可能会系统性地失败：在ALFWorld和HumanEval中，代理存储了对任务的自信但不正确的解释，并继续在多次试验中基于这些解释行动，尽管每次环境都会重置到正确的任务。我们将这种失败模式称为记忆虚构，并提出了重复反射率（RRR），这是一种基于日志的指标，用于检测对不正确的反射内容的重复依赖。使用RRR，我们在ALFWorld中识别了16个冻结环境，其中121个反射中有0个提到正确的目标对象，在HumanEval中有4个类似案例。我们的缓解措施用程序化提取轨迹级别的失败信号替代了开放式自我诊断，将正确对象提及率从0%提高到86%，将RRR从0.64降低到0.10，并解决了ALFWorld中16个冻结环境中的3个，表明反射记忆可能强化错误信念而非纠正它们。

## Abstract
Reflexion-style agents rely on self-generated reflections as memory, implicitly assuming that agents can accurately diagnose their own failures.We show that this assumption can fail systematically: across ALFWorld and HumanEval, agents store confident but incorrect interpretations of the task and continue acting on them across trials,even though the environment resets to the correct task each time. We call this failure mode memory confabulation and introduce the Reflection Repetition Rate (RRR), a log-based metric that detects repeated reliance on incorrect reflective content.Using RRR, we identify 16 frozen environments in ALFWorld, where 0 of 121 reflections mention the correct target object, and 4 analogous cases in HumanEval. Our mitigation replaces open-ended self-diagnosis with programmatic extraction of trajectory-level failure signals, increasing correct object mention from 0% to 86%, reducing RRR from 0.64 to 0.10, and solving 3 of 16 frozen ALFWorld environments, suggesting that reflective memory can reinforce false beliefs rather than correct them.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：反思型代理（如 Reflexion）依赖自我生成的反思作为记忆，假设代理能够准确诊断自身失败。但该假设可能系统性失败——代理会存储自信但错误的解释，并在每次环境重置到正确任务后仍持续依赖这些错误信念行动。作者将这种多轮次、自我强化的虚假信念称为**记忆虚构（memory confabulation）**。
- **背景**：Reflexion 是代表性代理架构，失败后写自然语言反思并检索用于后续尝试。代理记忆的写–管理–读循环中，若反馈信号是二元的（通过/失败），且任务涉及多步操作，反思步骤容易产生不准确的因果诊断，且这些错误被存储、检索并反复强化。
- **整体含义**：揭示了反思记忆可能强化而非纠正错误信念，对依赖自生成记忆的自主代理设计提出了根本性警示——写路径验证与检索质量同等重要。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
- 识别并量化记忆虚构现象，通过程序化提取轨迹级失败信号替代开放式自我诊断来缓解该问题。

### 关键技术细节
#### (1) 操作定义记忆虚构
- 对于任务 $\tau$，反射 $r_t$ 如果未能提及正确的目标对象（即 $\text{obj}(\tau) \notin r_t$），则定义为被虚构化。可从日志（游戏文件目录名和反射文本）中直接检测。

#### (2) Reflection Repetition Rate (RRR)
- 公式：  
  $$RRR = \frac{|\{ r_i : i \ge 1, \exists j < i, \text{sim}(r_i, r_j) \ge 0.85 \}|}{|M| - 1}$$
  其中 $\text{sim}$ 使用 SequenceMatcher 字符串相似度。  
- RRR=0 表示所有反思完全新颖；RRR=1 表示所有反思都是早期反思的近似重复。  
- **冻结环境**定义：RRR ≥ 0.5，即至少一半的反思是近重复。

#### (3) 两种失败类别
- **记忆有害（memory-harmful）**：移除记忆后代理能更快解决任务，证明存储的反思具有误导性。
- **任务困难（task-hard）**：即使无记忆代理也失败，表明能力鸿沟独立于记忆质量。

#### (4) 缓解策略
- **程序化反馈提取（Programmatic Feedback Extraction）**：取代开放式自我诊断，从轨迹中自动解析“Nothing happens”响应或重复动作等失败步骤，并直接注入反思提示中。例如在 ALFWorld 中提取失败动作和环境响应，在 HumanEval 中提取失败的 assert 语句和错误类型。
- **结构化反思（Grounded Reflection）**：强制代理按“失败步骤→根本原因→新计划”格式输出，但仅提高提及率，未改善任务困难环境。

## 6. 论文的主要结论与发现

1. **记忆虚构普遍存在**：在 ALFWorld 的 50 个需要反思的环境中有 16 个（32%）冻结，121 条反思中**0 条提到正确目标对象**。  
2. **RRR 与试验次数强相关**：Spearman 相关系数 r=0.808，p<0.0001。
3. **因果证据**：2 个环境在无记忆时 1 轮解决，有记忆需 7-8 轮，证明存储记忆具有直接危害。
4. **反馈粒度是关键瓶颈**：二元反馈（通过/失败）导致高冻结率（32%-82%），单元测试级反馈（HumanEval）将冻结率降至 17%。
5. **程序化反馈提取有效**：正确对象提及率从 0% 提至 86%，RRR 从 0.64 降至 0.10，并解决 3/16 冻结环境（包括一个其他条件均失败的 env 35）。
6. **更强模型不解决根本问题**：gpt-4o-mini 完全消除任务身份虚构（100% 对象提及），但仅解决 2/16 环境，且引入新虚构类型（记忆格式虚构和动作空间虚构）。
7. **结构脆弱性泛化**：任何满足“二元反馈 + 自生成反思 + 持久检索”的代理（如 ExpeL）都面临类似风险。
